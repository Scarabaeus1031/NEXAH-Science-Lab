# Grey Lens / AXIOM-0 Core Contract Candidate

Date: `2026-10-03`

Status: `CORE_FACING_CONTRACT_CANDIDATE / DOCUMENTATION_ONLY / NOT_CANONICAL / NO_ACTIVATION`

Working name: **Frame–Cut–Trace–Residual–Return Contract** (`FCTRR`)

## Decision in scope

The AXIOM-0 material and Grey Lens share a durable method core. The candidate is not the historical axiom stack as a whole, not Greyspace as ontology, and not the Navier–Stokes bridge. The bounded candidate is a contract for declaring how one situated representation produces a record, a boundary and a typed remainder, and how another representation may be requested without pretending that the first record was the world.

This file prepares an exact Core-facing proposal. It does not override Structure Freeze or perform canonical Core adoption.

## Why this is Core-shaped

The contract applies before domain interpretation while remaining formally expressible:

```text
DECLARED CARRIER
  -> CONTEXT / OBSERVER / INSTRUMENT
  -> SELECTION OR REPRESENTATION MAP
  -> TYPED BOUNDARY
  -> TRACE / RECORD
  -> PRESERVED + LOST + UNRESOLVED
  -> COMPARISON / RETURN / REVISION
```

It supplies common discipline to TOP, Grey Lens, representation agreement, ORION and bounded scientific adapters. That cross-domain role makes it Core-shaped; it does not make every domain mechanism identical.

## Minimal contract

For each admitted view `r`, declare:

```math
F_r : D_r \subseteq \Omega \to Y_r
```

and record:

1. `Omega`: declared carrier or source class; never an unnamed total reality;
2. `D_r`: admitted domain and exclusions;
3. `r`: frame, context, observer, instrument or representation choice;
4. `F_r`: map, restriction or measurement procedure;
5. `B_r`: typed boundary/failure record;
6. `y_r = F_r(x)`: produced trace or record;
7. `P_r`: declared preserved properties;
8. `L_r`: declared information loss;
9. `U_r`: unresolved set or uncertainty class;
10. `T_{r->s}`: admitted change of representation, where defined;
11. `delta_{r,s}`: named disagreement/commutation defect;
12. `Return`: typed state, numerical, renormalization, algebraic or epistemic return, including the Human or protocol decision to retain, revise, compare, abstain or stop.

`Return` is not assumed to be an inverse. `U_r` is not automatically the set-theoretic complement of the record, a hidden substance or the complete unknown world.

Return types and residual types must be declared independently. A return to a prior state, a return to identity, a stationary rescaled profile and a Human revision are not interchangeable.

## Seven contract rules

| Rule | Requirement |
|---|---|
| C0 — declaration | carrier, domain, codomain and context are named |
| C1 — situated access | every record is indexed by a declared view or procedure |
| C2 — explicit cut | selection, restriction, threshold or naming rule is inspectable |
| C3 — typed boundary | analytic, physical, numerical, semantic and governance boundaries are not conflated |
| C4 — non-exhaustion | `record != source` unless injectivity/completeness is established on the declared domain |
| C5 — typed residual | loss, missingness, non-identifiability, error and unresolved alternatives remain distinct |
| C6 — accountable return | representation change, revision, acceptance, abstention or STOP is recorded with authority |

## AXIOM-0 and Grey Lens

| AXIOM-0 contribution | Grey-Lens contribution | Contract expression |
|---|---|---|
| conditions for distinction and measurement | ambient carrier is not exhausted by one record | `Omega`, `D_r`, `F_r` |
| orientation before interpretation | situated observer and frame | representation index `r` |
| threshold and persistence | cut, seam and boundary | typed `B_r` plus continuation rule |
| projection and comparison | trace, shadow and record | `y_r`, provenance and comparison rule |
| limit of a description | residual and unseen remainder | `L_r`, `U_r`, rejection/failure record |
| reorientation | Return and Human revision | `T_{r->s}`, decision and STOP |

The relation is complementary: AXIOM-0 supplies the preconditions and discipline of description; Grey Lens supplies the audit posture that asks what the resulting record excludes and whether the cut should be revised.

## Relation to Navier–Stokes

NS is a **domain adapter and stress test**, not the Core module itself:

| Core field | NS adapter |
|---|---|
| `Omega`, `D_r` | domain, initial data, forcing and admitted solution class |
| `F_r` | velocity, vorticity, spectral, weak or numerical representation |
| `B_r` | regularity threshold, physical validity limit or numerical reliability boundary |
| `P_r` | incompressibility, stated balances and proved invariants |
| `L_r`, `U_r` | unresolved scales, non-identifiability, discretization loss or unknown continuation |
| `T_{r->s}` | declared translation between representations |
| Return | refine the representation, reject the run, change the physical model, or STOP |

The adapter is useful precisely because it forces three boundaries to remain separate: analytic blow-up, physical-model breakdown and numerical failure. No result about one follows merely from naming another.

## Compatibility with the existing Mathematical Core

The candidate specializes existing Core requirements rather than replacing them:

- `F_r`, `D_r`, `Y_r` and `T_{r->s}` reuse the current representation system;
- `delta_{r,s}` reuses the declared comparison/commutation defect;
- `L_r` and `U_r` refine the existing separation of missingness, censoring, non-identifiability, model error and rejection;
- Human Return adds responsibility and workflow semantics, not a mathematical inverse;
- no geometry is inferred until a comparison structure or metric is declared.

## Explicit exclusions

- `Greyspace` is not adopted as ether, substance, universal state space or complete world.
- `Q°` is not adopted as a validated universal operator.
- the pre-geometric reconstruction hypothesis is not adopted as a theorem.
- visual closure, topology imagery and recurrence do not prove an invariant.
- one common grammar does not establish one common physical mechanism.
- historical AXIOM-0 numbers or NS symbolic operators do not enter this contract.

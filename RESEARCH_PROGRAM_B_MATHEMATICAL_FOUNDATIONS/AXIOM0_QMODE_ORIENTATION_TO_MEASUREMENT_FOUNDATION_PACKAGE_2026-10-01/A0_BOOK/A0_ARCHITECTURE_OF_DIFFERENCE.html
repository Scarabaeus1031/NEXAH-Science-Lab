The Architecture of Difference

Unterschied wird zur Architektur, wenn er gehalten und durchlaufen werden kann.

Die zehn Begriffe sind keine neue Naturgleichung. Sie bilden eine Lesesequenz, mit der unterschiedliche Fälle getrennt beschrieben und anschließend verglichen werden können.

01

Difference

Zwei deklarierte Zustände oder Records sind nicht gleich.

02

Boundary

Eine Grenze hält die Unterscheidung lokal aufrecht.

03

Potential

Die gehaltene Differenz beschreibt eine Möglichkeit zur Änderung.

04

Gradient

Im gewählten Modell erscheint eine Änderungsrichtung.

Architektur erlaubt Passage; ein Prozess realisiert einen möglichen Weg.

07–09
Transformation · Trace · Return

Rückkehr ist nicht dasselbe wie Zurücksetzen.

Dieselbe Adresse, Phase oder Projektion kann mit verschiedener Weggeschichte erreicht werden. Der Return bilanziert deshalb Endpunkt, Pfad und Rest getrennt.

Return = endpoint + path + residual

Endpoint: Wo endet der Operator?

Path: Welche gerichtete Geschichte führte dorthin?

Residual: Was blieb, ging verloren, kam hinzu oder bleibt offen?

Red Balloon bindet hier an: Er bleibt der vorhandene source-bound Tracer einer begrenzten Weggeschichte — kein Universalmechanismus.
10
Closing figure · Return with continuation

Die Screw verbindet Wiederkehr und Fortsetzung.

Eine Schraubenlinie entsteht, wenn zur Rotation eine Translation entlang einer Achse kommt.

H(t) = (r cos t, r sin t, p t)

Nach einer Umdrehung:

H(t+2π) = (x(t), y(t), z(t)+2πp)

Same angular address. New axial position.

Das ist präzise Geometrie — keine automatische Theorie von Zeit, Erinnerung oder Natur.

The circle returns.The line advances.The screw does both.
B2-01
Beta Return · one rule, three feedback views

Rückführung verändert den nächsten Schritt — nicht rückwirkend den Frame.

Ein bewusst kleines Rechenmodell trennt die klassische quadratische Iteration von einer expliziten lokalen Rückführung. Drei synchronisierte Ansichten zeigen β_feedback < 0, = 0 und > 0.

zₙ₊₁ = zₙ² + c + β_feedback(zₙ−zₙ₋₁)

Bei β_feedback = 0 bleibt die klassische quadratische Iteration unverändert. Die Seitenansichten zeigen nur, wie derselbe lokale Rückführungsterm die Folgeschritte verändert.

Return is a relation between states — not a reversal of history.

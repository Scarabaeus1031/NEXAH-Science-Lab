## Mandatory operating contract

1. Keep one A0 Owner frame. Open candidate pages, Desk returns and release
   receipts inside this frame; do not create a second Owner portal.
2. Resolve the canonical repository and source path before editing. A0 may
   embed or project a website, but does not become a second editable copy.
3. Do not present a standalone HTML, temporary server, ChatGPT Site or browser
   tab as the accepted version. Diagnostic previews are explicitly
   non-authoritative.
4. Every candidate must show its channel, repository, branch, commit or dirty
   state, preview class, acceptance state and intended deployment target.
5. Human Owner acceptance applies only to the exact framed revision.
6. Commit, push and deployment are separate states. Never infer one from
   another.
7. After deployment, verify the normal production URL and return the commit,
   deployment revision, rollback point and smoke result to A0.
8. If source, A0 projection, build artifact and live site disagree, stop with
   `VERSION_AMBIGUOUS` before making further visual edits.

Science Desk retains scientific authority. Builder Desk retains build routing.
Mission Control retains currentness, priority and release governance. Public
channel repositories retain implementation authority. Placement inside A0
does not merge these roles.

## Science Desk binding

For every public-surface candidate, Science Desk reviews only the scientific
meaning, evidence status, source/provenance and claim ceiling for the exact
A0-framed revision. It does not approve implementation, deployment or
publication by implication. Its return names the reviewed revision and any
scientific STOP condition; a later source change invalidates that review until
the candidate is reframed.

## NSNavigator binding

Every material Science Desk or Builder Desk return must state whether it:

- reuses an existing NSNavigator identity or binder;
- changes only source hashes or currentness;
- proposes a semantic identity or typed-relation change; or
- has no Source Graph effect, with a concrete reason.

The return names canonical source and receipt paths, affected binder/index or
projection paths, node/relation/alias count effects and applicable validator
outcomes. These are operational return fields, not new Source Graph
vocabulary. Science Desk retains evidence and Claim-Ceiling authority;
Navigator governance controls graph admission; Builder may implement and route
but cannot create graph identity by implication; Mission Control records the
validated currentness result. Navigation placement, visual similarity, an
HTML/GLB connection or a working demonstrator alone creates no identity or
relation.

## Builder Desk binding

Builder Desk receives the framed candidate and source pointer, performs work in
the canonical repository, and returns the built revision to the same A0 frame.
It may not replace the frame with a standalone preview or treat staging as
production. Its closeout distinguishes build, commit, push, deployment and live
verification.

Was kann einzeln
bedient werden?

Ein Modul oder Tool ist eine vorhandene, einzeln adressierbare Funktion. Es liest Sources, verändert einen erklärten View- oder Kontrollzustand und besitzt einen begrenzten Rückweg. Erst eine Auswahl mehrerer Tools wird zur Bench Configuration.

MODULE / TOOLInput lesen + eine Funktion bedienen + Zustand sichtbar halten≠ SOURCE · ≠ CONFIGURATION · ≠ DEMONSTRATOR · ≠ DELIVERY

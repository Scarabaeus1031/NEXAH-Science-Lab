How NEXAH
works.

NEXAH behandelt eine Antwort nicht als Endpunkt, sondern als begrenzten Record: entstanden aus Quelle, Frage, Position, Auswahl und Transformation. Orientierung beginnt dort, wo dieser Weg wieder sichtbar wird.

Methode durchlaufenZum Laboratory
Working proposition
Eine gute Frage kann länger tragen als ihre Antwort.SITUATION → CUT → RECORD → COMPARISON → RESIDUAL → HUMAN RETURN

Das ist eine Untersuchungs- und Dokumentationsgrammatik. Keine universelle Naturgleichung, keine automatische Wahrheit und keine Entscheidungshoheit.

01
Orientation trace · seven declared moments

Die Antwort öffnen.

Die Methode folgt nicht einer mystischen Gesamtformel. Sie stellt sieben einfache, aber unbequeme Fragen an einen Record. Wähle einen Schritt, um seinen Zweck und seine Grenze zu lesen.

01 · Situation / source

Nothing begins as a neutral answer.

Orientation begins with a situated source: an event, document, measurement, model, image or software output. Its version, custody and availability belong to the record.

Connection grammar · existing CF:F1–F7

Schritte laufen. Families beschreiben Funktionen.

Die sieben Methodenschritte bilden einen Arbeitsweg. Die sieben Families klassifizieren dagegen, welche relationale Funktion in einem Schritt tatsächlich verwendet wird. Eine Family kann mehrfach auftreten; ein Schritt kann mehrere Families benötigen. Die gleiche Zahl bedeutet keine feste Zuordnung.

02
Pattern Toolbox v0.1 · frozen bounded signatures

Drei wiederverwendbare Fugen.

Die Toolbox komprimiert einen großen visuellen und konzeptuellen Bestand auf drei gebundene Signaturen. Häufigkeit oder Schönheit eines Musters reicht nicht für seine Aufnahme.

PT-SIG-01

Aperture / Boundary

Legt fest, was eintreten darf, was zurückgehalten wird und unter welchen Randbedingungen Beobachtung möglich ist.

Input
Quelle, Auswahlregel, Kontext, Rand
Audit
admitted / withheld / unavailable
Grenze
Sichtbare Übereinstimmung schließt unbekanntes U nicht.
PT-SIG-02

Projection

Überführt eine Quelle in eine Darstellung und hält Kollision, Verlust und Nicht-Injektivität ausdrücklich fest.

Input
Source, Map, Zielraum, Parameter
Audit
retained / lost / added / unresolved
Grenze
Eine Projektion ersetzt ihre Quelle nicht.
PT-SIG-03

Relation

Gibt einer Verbindung eine eigene getypte Identität mit Rollen, Richtung, Bindungsgrund und Provenienz.

Input
Endpunkte, Rollen, Typ, Basis
Audit
exact / method / open / non-identity
Grenze
Relation ist weder Gleichheit noch Kausalität.
Toolbox boundary: Die drei Signaturen sind die heute eingefrorenen, evidence-bound Werkzeuge. Karten, Spiegel, Janus, Euler-, Clockwork- oder Prime-Ansichten können Fixtures oder Kompositionen sein; sie werden dadurch nicht automatisch zu weiteren Grundoperatoren.

05
The Machine · current meaning

Eine Kette von Verantwortungen.

„The Machine“ bezeichnet hier keine fertige Universalmaschine. Es ist die Assembly-Idee, mit der eine begrenzte Frage durch nachvollziehbare Rollen zu einem Human Return geführt werden kann.

01SourceVersion, Custody, Provenance
02CarrierState space and frame
03OperatorTyped change or map
04RecordTrace, I/L/A/U, residual
05EvidenceControls, replay, ceiling
06ViewInspectable representation
07ReturnHuman judgment and STOP

Was bereits trägt

  • eine konsistente Orientation- und Record-Grammatik;
  • drei gebundene Toolbox-Signaturen;
  • begrenzte Prozessoren, Replays und Instrumentpfade;
  • Source Graph, Claim Ceilings, negative Resultate und STOP.

Was daraus nicht folgt

  • keine Universaltheorie oder gemeinsame Naturursache;
  • kein universeller Runtime und keine fertige Gesamtmaschine;
  • keine automatische Entscheidungshoheit;
  • keine extern belegte allgemeine Human Utility.
Current interpretation: Die Human View ist der stabile Zweck. Method und Toolbox sind die Kompression. Die Machine bleibt die begrenzte Assembly-Aufgabe.

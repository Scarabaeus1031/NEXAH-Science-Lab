Geordnete Passage

Öffnung, Seite, Spur und Rückkehr.

Die Folge ist eine Leseregel für begrenzte Records. Sie behauptet nicht, dass Zeit aus einer geometrischen Faltung entsteht.

T1

Aperture

Eine gehaltene Öffnung setzt einen begrenzten Zugang zum Feld.

T2

Gate

Grenze plus Regel unterscheiden geschlossen, gefiltert und passierbar.

T3

Outside / Inside

Der Übergang hält Seite und Orientierung als eigenen Record.

T4

Trace

Eine Folge gerichteter Abschnitte wird zum Wegzeugen, noch nicht zum Naturoperator.

T5

Return

Die Rückkehr wird gegen Quelladresse, Orientierung und Rest geprüft.

ρ

Residual

Die Differenz zwischen sichtbarer Schließung und vollständigem Zustand bleibt erhalten.

Projection return

Der Winkel schließt. Die Höhe erinnert.

Eine Schraubenlinie liefert ein präzises, begrenztes Beispiel: Die Kreisprojektion kann nach einer vollen Umdrehung dieselbe Adresse zeigen, während die Höhenkoordinate fortgeschritten ist.

CIRCULAR VIEW

Geschlossene Winkeladresse

E(t) = (R cos t, R sin t)
E(t + 2π) = E(t)

Die Projektion in die Ebene kehrt nach einer Periode zur selben Ansicht zurück.

HELIX CARRIER

Offene Fortsetzung

H(t) = (R cos t, R sin t, bt)
H(t + 2π) − H(t) = (0,0,2πb)

Für b ≠ 0 bewahrt der Carrier ein Höhenresiduum.

TORSION

Geometrische Kennzahl

τ = b / (R² + b²)

Die Torsion beschreibt diese Helixgeometrie; sie ist kein universeller Zeit- oder Bewusstseinsparameter.

RETURN RECEIPT

Drei Fragen statt einer

{view_return, carrier_return, residual}

Eine geschlossene Ansicht darf nicht als vollständige Zustandsrückkehr ausgegeben werden.

Der View kann zurückkehren, während der Carrier die Passage erinnert.

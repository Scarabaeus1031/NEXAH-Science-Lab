## Question

Three distinct impressions from Check 61 needed explicit operators:

1. Does the strong free-search witness `(P1,1111) -> A7` survive repeated mapping searches?
2. Does the global Euler ledger return locally through a discrete Gauss-curvature calculation?
3. Does the Blue Body shell satisfy the standard Ramanujan bound for a finite regular graph, and what does the Ihara–Bass operator say?

## Result 1 — A7 does not survive as an invariant

Sixteen deterministic unconstrained searches were run with seeds `0..15` and
`120000` iterations per seed. The middle state `(P1,1111)` landed on fourteen
different host labels. `A7` occurred only twice:

```text
seed 5  -> A7, wirelength 296
seed 7  -> A7, wirelength 280
```

The minimum wirelength `280` was reached by two runs, but their middle hosts
were different:

```text
seed 7  -> A7
seed 11 -> D4
```

Therefore `A7` is a valid mapping witness for the frozen seed-7 candidate, but
not an intrinsic address of the `1111` fiber and not an invariant of the search
objective.

## Result 2 — the Gauss handle closes exactly

For a cubic spherical map, the combinatorial face charge is

```text
sum_k (6-k) f_k.
```

For `O2-P16-H8`:

```text
16 pentagons: 16 * (6-5) = +16
 8 hexagons:   8 * (6-6) =   0
 2 octagons:   2 * (6-8) =  -4
total                              12
```

Using the interior angles of regular `k`-gons at every incident shell vertex,
the summed angular defect is numerically `12.566370614359158 = 4*pi`. This is
the local Gauss–Bonnet return of the same Euler characteristic `chi=2`.

This is an intrinsic calculation on the declared shell combinatorics. It does
not assert that the current canvas projection is a rigid regular-faced 3D
realization.

## Result 3 — numerical Ramanujan pass

The shell graph is connected, non-bipartite and 3-regular with `V=48` and
`E=72`. A symmetric Jacobi diagonalization gives:

```text
largest trivial eigenvalue         3
max |nontrivial eigenvalue|        2.7313013160030897
Ramanujan bound 2*sqrt(3-1)        2.8284271247461903
margin                             0.09712580874310062
trace check                        -8.88e-16  (target 0)
sum-of-squares check               144        (target 2E=144)
solver max off-diagonal residual   9.87e-14
```

The finite shell therefore satisfies the standard adjacency-spectral
Ramanujan inequality numerically.

A control ensemble of 24 connected cubic graphs generated by deterministic
degree-preserving 2-switches produced 22 passes and 2 failures. The Blue Body
passes, but this small ensemble does not support a rarity or optimality claim.

## Result 4 — Ihara–Bass becomes an explicit operator

For a `d`-regular graph the declared operator is

```text
Z_G(u)^-1 = (1-u^2)^(E-V) det(I-uA+(d-1)u^2 I).
```

The 94 poles associated with the 47 nontrivial adjacency eigenvalues lie
numerically on

```text
|u| = 1/sqrt(d-1) = 1/sqrt(2) = 0.7071067811865475,
```

with maximum radius error `1.11e-16`. This is the finite graph-theoretic Ihara
statement corresponding to the Ramanujan pass. It is not a claim about the
Riemann zeta function or the Riemann hypothesis.

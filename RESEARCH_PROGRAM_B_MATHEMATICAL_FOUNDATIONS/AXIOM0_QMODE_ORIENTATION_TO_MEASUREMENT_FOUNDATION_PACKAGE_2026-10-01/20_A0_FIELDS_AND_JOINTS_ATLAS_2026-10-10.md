## 1. Purpose

This atlas maps the fields touched by the A0 Field Notes and, more
importantly, the joints between them. It does not propose that the fields are
one mechanism. It records where a translation, comparison, projection,
boundary or Return would have to be declared before two records may be joined.

The governing distinction is:

> The fields are the stones. The research is in the joints.

A recurring symbol, number, shape or word is not itself a joint. A scientific
joint requires typed objects, a declared map and an inspectable account of
what is preserved, lost, added or unresolved.

## 4. Field map

| Field lane | Objects currently touched | A0 use | Boundary that must remain visible |
|---|---|---|---|
| Formal / pre-empirical mathematics | sets, numbers, groups, frames, charts, topology, operators, state and relation spaces | supplies typed carriers, maps, invariants and counterexamples | mathematical validity does not establish physical instantiation |
| Representation and computation | encodings, grids, projections, algorithms, masks, readouts, cost and information loss | makes records and transformations inspectable | a display or successful program is not automatically a model of nature |
| Physics | states, observables, fields, dynamics, forces, boundary conditions and measurement records | tests where a model applies and what its residual means | shared notation or geometry is not shared physics |
| Chemistry | composition, bond, reaction, interface, exchange and transformation | provides an empirical lane for persistence through material change | chemical identity and mathematical equivalence are different relations |
| Biology / living systems | boundary maintenance, metabolism, repair, reproduction, adaptation and historical identity | candidate middle lane for organization across physical and chemical exchange | biology is not assumed to be a literal zero, centre or universal binder |
| Observation and instrumentation | source, medium, aperture, sensor, calibration, observer and produced record | states how an appearance becomes available for comparison | observation is conditioned; absence in a record is not non-existence |
| Navigation and action | local alignment, constraint, path, decision window, motion and feedback | studies how a route can emerge from local comparisons | an operational route does not prove a universal geometry |
| History, visual archaeology and Human View | images, metaphors, source lineage, selection and interpretation | preserves how questions were found and where judgment enters | provenance can generate a question but cannot validate its answer |

Mathematics acts across all lanes as formal language and control. It is not
silently identified with an empirical domain.

## 5. Mathematical perspective tiles

The retained `Pattern of Orientation` Masterplate provides a useful map of
mathematical views. The tiles are not twelve A0 axioms. They are twelve places
from which an orientation problem may be described:

| Tile | Bounded role | Typical joint question |
|---|---|---|
| Direction | normalized or otherwise declared directional record | what defines sign, magnitude and reversal? |
| Frame | basis or coordinate frame | which changes of frame preserve the statement? |
| Handedness | orientation class under a declared frame | is reflection allowed, detected or quotiented out? |
| Rotation | transformation in a declared rotation representation | what is rotating, relative to which frame? |
| Spin / periodic state | loop, phase or periodic representation | is the cycle geometrical, dynamical or only graphical? |
| Local maps | charts or local representations | what is the overlap domain? |
| Transition | map between compatible local descriptions | is the domain, codomain and inverse declared? |
| Transport | comparison along a path or connection | what path and connection determine the comparison? |
| Holonomy / Return | accumulated transform around a loop | what returns: point, state, frame or relation? |
| Dynamics | state change under a declared evolution rule | what is the state, time parameter and update law? |
| Gluing | compatibility and construction from local pieces | which cocycle or consistency condition is required? |
| Navigation | path selection under a cost and constraint model | is the route computed, observed or metaphorical? |

The established mathematics of these tiles remains distinct from exploratory
NEXAH mappings placed between them.

## 6. Minimal joint record

Every proposed seam should be expressible as a typed record:

```text
J = (
  left object,
  right object,
  left and right carriers,
  transformation or comparison map,
  compatibility conditions,
  preserved content,
  lost content,
  added or inferred content,
  unresolved residual,
  evidence source,
  epistemic status,
  Return or STOP condition
)
```

A compact working table is:

| Field | Required question |
|---|---|
| Left / right object | What exactly is being related? |
| Carrier and units | Where do both records live, and are they comparable? |
| Map | What operation moves or compares one record with the other? |
| Compatibility | Under which conditions is the map valid? |
| Preserved | Which invariant or content survives? |
| Lost | Which distinctions are collapsed or hidden? |
| Added | Which interpolation, prior, convention or inference enters? |
| Residual | What remains unmatched or unknown? |
| Evidence | Which source supports the relation rather than only each endpoint? |
| Return / STOP | What bounded conclusion is allowed, and when must comparison stop? |

## 7. Joint vocabulary

The following terms name different operations and must not be collapsed:

| Joint type | Meaning | Non-identity boundary |
|---|---|---|
| Cut / aperture | selects what may enter a record | not the source itself |
| Projection | maps an object into a representation, often with loss | not identity unless proved injective on the declared domain |
| Translation | changes notation, coordinates, representation or domain language by a declared rule | not semantic equivalence by appearance alone |
| Comparison | places compatible records under one criterion | not combination or causal interaction |
| Transition map | maps overlapping local descriptions | not physical motion unless a dynamical interpretation is added |
| Transport | compares an object along a declared path or connection | not ordinary translation without the required structure |
| Gluing | constructs or checks a global object from compatible local data | not collage or visual adjacency |
| Weighting / binding | combines compatible contributions under declared coefficients | not a world-centre or fifth quaternion component |
| Readout | produces an observable or reported record from a state or model | not the complete underlying state |
| Residual | records mismatch after a declared comparison | not automatically noise, error or new physics |
| Return | states what can be recovered or re-related after a path | not necessarily return to an identical point or state |

## 8. Epistemic status vocabulary

Each joint receives exactly one current status:

```text
ESTABLISHED_STRUCTURE
SOURCE_BOUND_EXACT_RELATION
BOUNDED_METHOD_CONTRACT
NEXAH_WORKING_SYNTHESIS
ANALOGY_OR_VISUAL_HEURISTIC
OPEN_QUESTION
UNKNOWN_OR_UNDEFINED_MAP
REJECTED_OR_FAILED_JOINT
PROVENANCE_ONLY
```

Status belongs to the relation, not automatically to either endpoint. Two
well-established fields can still be connected by an undefined or false map.

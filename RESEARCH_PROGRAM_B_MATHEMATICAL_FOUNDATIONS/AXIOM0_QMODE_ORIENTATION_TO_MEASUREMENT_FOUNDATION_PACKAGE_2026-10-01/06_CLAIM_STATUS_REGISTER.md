# Claim-status register

Status: `INITIAL RECONCILIATION REGISTER`

## Status vocabulary

| Status | Meaning |
|---|---|
| `DEFINITION` | a stipulated term within a declared scope |
| `ESTABLISHED_MATHEMATICS` | standard result or construction owned by its field |
| `DERIVED_IN_PACKAGE` | derived from declared premises inside a future reviewed package |
| `OPEN_FORMAL_CLAIM` | mathematically expressible but not yet proved here |
| `CONCEPTUAL_HYPOTHESIS` | proposed explanatory or dependency principle |
| `VISUAL_INTUITION` | image or metaphor that motivates a question |
| `PHYSICAL_SPECULATION` | physical interpretation without sufficient evidence |
| `EXCLUDED_FROM_CORE` | retained historically but not adopted into the foundation |

`DERIVED_IN_PACKAGE` is currently unused. No historical derivation has yet
passed a package-level proof review.

## Initial classification

| Claim family | Initial status | Note |
|---|---|---|
| observation uses a frame or representation | `CONCEPTUAL_HYPOTHESIS` | can be made definitional in a bounded method contract |
| projections may lose distinctions | `ESTABLISHED_MATHEMATICS` | requires a declared map and equivalence/property |
| different representations require an explicit comparison map | `CONCEPTUAL_HYPOTHESIS` | central NEXAH methodological rule |
| mutual reachability induces SCC classes | `ESTABLISHED_MATHEMATICS` | use reflexive-transitive closure |
| SCC quotient of a finite directed graph is acyclic | `ESTABLISHED_MATHEMATICS` | standard graph theory |
| order alone gives topology, metric or space | `OPEN_FORMAL_CLAIM` | false without added constructions/hypotheses as a general claim |
| orientation necessarily generates fold | `CONCEPTUAL_HYPOTHESIS` | terms and necessity not defined |
| fold necessarily generates curvature | `CONCEPTUAL_HYPOTHESIS` | depends on formal carrier and fold definition |
| measurement universally requires closure | `OPEN_FORMAL_CLAIM` | must define both terms and domain |
| a third axis necessarily creates an observer | `CONCEPTUAL_HYPOTHESIS` | not established mathematics or physics |
| HM necessarily emerges as a carrier field | `PHYSICAL_SPECULATION` | no bound physical model or evidence |
| `-1/12`, `13`, `sqrt(2)`, `pi`, `phi` are universal root conditions | `EXCLUDED_FROM_CORE` | exact identities may be retained only in bounded contexts |
| proof-layer visuals establish theorems | `VISUAL_INTUITION` | architecture is not proof |
| planets or cosmology instantiate AXIOM-0 | `EXCLUDED_FROM_CORE` | outside this foundation package |
| a boundary may be represented as a typed state-frame-side relation | `OPEN_FORMAL_CLAIM` | bounded record schema exists; no universal ontology is inferred |
| an escape is a guarded crossing of a declared local boundary | `CONCEPTUAL_HYPOTHESIS` | guard, carrier, threshold, direction and failure semantics remain method-specific |
| `Ramanujan Escape` identifies a historical NEXAH visual lineage | `DEFINITION` | source-local role label only; not an attribution of a theorem or operator to Ramanujan |
| `Q < P < Q` is a strict partial order | `EXCLUDED_FROM_CORE` | inconsistent as written; process reading must distinguish `Q_0 -> P -> Q_1` |
| `The Room Looks Back` establishes agency or consciousness of space | `EXCLUDED_FROM_CORE` | retained only as a mnemonic for frame- and boundary-conditioned observation/return |
| `ALG°` or `ALGO` is identical to the boundary/escape grammar | `OPEN_FORMAL_CLAIM` | unsupported; a separate `LANG-ALGO` lineage uses `ALGO` as an even-residue / square-root-five rail |

## Register rule

Every later extracted claim must identify:

- exact source;
- exact wording or faithful paraphrase;
- intended domain;
- definitions and premises;
- present status;
- failure or downgrade condition;
- possible current NEXAH destination.

## 1. Purpose

This record preserves the remaining gaps of the **A0 Orientation Controller
Bench (OCB)** after the `v0.17.0` implementation pass. It is a documentary
attachment to the canonical
[A0 Research Backlog and Open Joints](24_A0_RESEARCH_BACKLOG_AND_OPEN_JOINTS_2026-10-10.md),
not a second backlog, a new Study, a Run Contract or authorization to continue
development during Structure Freeze.

The register distinguishes four states:

| State | Meaning |
|---|---|
| `BUILT` | present in OCB `v0.17.0` and covered by the local deterministic test suite |
| `PARTIAL` | a bounded mechanism or view exists, but the intended instrument or its evidence/interaction contract is incomplete |
| `SOURCE_ONLY` | supplied visual or historical HTML informs the design, but no OCB implementation or exact source reconstruction is yet bound |
| `OPEN` | no accepted implementation or formal contract exists |

## 3. Priority 0 — make aperture measurement inspectable

### OCB-GAP-01 — one trace, three measures, four projections

Status: `BUILT / ENGINEERING_PASS / BROWSER_ACCEPTANCE_OPEN` (2026-10-18)

The present iris-to-octagon projection is visually working, but it is not yet
an explicit three-coordinate measurement instrument. Add one declared trace

```text
M3(t) = (h(t), A(t), I(t))
```

with:

1. `h(t)` — height/elevation coordinate;
2. `A(t)` — azimuth/orientation coordinate;
3. `I(t)` — aperture/opening coordinate.

The same samples must be inspectable in four representation modes:

```text
UNROLLED TRACE → ROLLED/CYLINDRICAL TRACE → TOP VIEW → APERTURE SLICE
```

Acceptance boundary:

- sample count, ordering and values remain unchanged across all four views;
- every view declares its coordinate map and units or explicitly states
  `NORMALIZED / UNIT NOT ESTABLISHED`;
- switching view changes representation only, not the carrier record;
- the exported record contains the three measures, active view, cut and
  residual;
- a deterministic test proves representation invariance and records any
  information hidden by the selected cut.

Source cue: owner-supplied visual `CEEA9960-8FC7-4FAE-A532-35088CF210EF_1_105_c.jpeg`
(`Eine Spur · Vier Projektionen`). The image is a design reference, not an
executable specification.

Completion return: the existing P×A Blue Iris now feeds one deterministic
48-sample `M3(t)=(h,A,I)` engineering record. `h` and `I` are explicitly
normalized; `A` is radians. Unrolled, cylindrical, top and aperture-slice
views retain the same source ordering and fingerprint. The UI cycles all four
views, exposes every coordinate at the active sample and exports the view map,
cut, source fingerprint and exact zero-residual source Return. This closes the
bounded representation-invariance build; empirical calibration and physical
units remain outside scope.

### OCB-GAP-03 — observing cut and difference record

Status: `BUILT / ENGINEERING_PASS / BROWSER_ACCEPTANCE_OPEN` (2026-10-18)

OCB already separates source, view, residual and Return in several modules.
What is missing is one compact comparison instrument:

```text
SOURCE S(t)
  → APERTURE / CUT
  → VIEW A + VIEW B
  → Δ(A,B)
  → RETAINED / LOST / INTRODUCED / UNRESOLVED
  → BOUNDED RETURN OR STOP
```

Acceptance boundary:

- `A` and `B` are separately parameterized views of a declared source;
- `Δ(A,B)` states its metric or remains `UNDEFINED`;
- the I/L/A/U ledger is exported with the state record;
- equal-looking views do not imply equal carriers;
- Return does not erase the recorded gap.

Source cue: `399FCBC1-C50D-4721-B004-7D3B938B6B22_1_105_c.jpeg`
(`The Observing Cut`).

Completion return: the M3 instrument compares any ordered pair of its four
declared projections using an explicit normalized 2D display RMSE and maximum
distance. The exported I/L/A/U ledger distinguishes source fields retained in
the record from fields merely hidden by a projection, declares display
coordinates and RMSE as introduced, and keeps physical calibration and
cross-view meaning unresolved. Return restores the source fingerprint without
erasing the comparison ledger. Equal-looking views remain non-identifying.

# Required Expertise

| Question | Primary expertise | Review role |
|---|---|---|
| FQ-01, RQ-01, RQ-03 | inverse problems, observability, applied linear algebra | verify identifiability, map domains, rank/nullspace limits, and loss claims |
| FQ-02 | transition systems, graph theory, formal methods | review typing, composition, identity, censoring, and path semantics |
| FQ-03 | partial information, missing-data methods, scientific computing | separate epistemic unknown, underdetermination, censoring, and solver failure |
| FQ-04, RQ-04 | estimation, aggregation, graph invariants | define compatible carriers, weights, stability, and encoding equivalence |
| RQ-02 | state estimation and time-varying observability | review mask controls, history dependence, thresholds, and baselines |
| RQ-05 | directed graph reduction, network science, dynamical systems | evaluate sparsification/coarse-graining claims and preserved quantities |
| H-06 | Koopman/operator methods and statistical comparison | test whether cross-method alignment exceeds null structure |
| RQ-06 | nonlinear dynamics and statistical validation | freeze diagnostics, nulls, held-out events, calibration, and sensitivity |
| all questions | research software engineering and reproducibility | pin environments, seeds, manifests, tests, and replay commands |

## Minimum review composition

For the recommended starting point:

1. one inverse-problems or applied-linear-algebra reviewer;
2. one repository researcher who can reconstruct source provenance;
3. one independent reproducibility reviewer.

Domain experts become necessary only when a question is transferred from synthetic data to a physical, biological, chemical, or engineering application.

## Not required initially

- a new OLS working group;
- Library or publication review;
- topology, manifold, sheaf, or category expertise before the source object demands that structure;
- cross-domain application expertise for the initial synthetic representation problem.

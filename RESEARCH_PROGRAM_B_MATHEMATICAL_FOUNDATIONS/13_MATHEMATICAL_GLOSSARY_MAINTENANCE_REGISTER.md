## Intake rule for future discoveries

When a new mathematical-looking term appears, record at least:

```text
term
exact source and version
carrier or object class
domain and codomain, if a map
definition or explicit unresolved status
nearest established terminology
what it must not be confused with
claim status
owning evidence package
```

If these fields cannot be supplied, retain the original token as
`UNRESOLVED PROVENANCE`. Do not invent an expansion or operator semantics.

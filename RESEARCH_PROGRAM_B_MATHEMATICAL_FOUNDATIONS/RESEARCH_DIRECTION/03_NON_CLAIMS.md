# Non-Claims

Status: `PROTECTIVE RESEARCH BOUNDARY`

## Current non-claims

NEXAH does not currently claim:

1. a Theory of Everything;
2. a universal theory;
3. a universal geometry;
4. a new mathematical field;
5. mathematical novelty;
6. scientific priority;
7. a mathematical model of Reality;
8. that visual similarity proves equivalence;
9. that circles, spirals and cyclic motion form one universal class;
10. that IRIS or aperture is a mathematical operator;
11. that membrane language defines a boundary condition;
12. that category theory validates the framework merely because diagrams can
    be drawn;
13. that information geometry applies without a declared statistical
    manifold;
14. that invariance implies truth, causality, importance or physical identity;
15. that representation preserves source identity;
16. that architectural coherence establishes domain validity.

## Metaphor boundary

Metaphors may guide question formation. They do not enter formal definitions
without independent specification.

| Repository language | Required scientific replacement before formal use |
|---|---|
| shadow | declared projection or observation map |
| aperture | mask, domain restriction, sampling operator or field-of-view model |
| membrane | declared interface, boundary and exchange law |
| transversal transition | typed map with source, target, domain and composition rule |
| scale translation | declared scale spaces and coarse-graining or refinement map |
| orientation operator | exact function, relation, estimator or transformation |
| circle, spiral or cycle | exact geometric curve or dynamical definition |
| Reality | declared source object or model; never an assertion that the model is Reality |

## Claim discipline

- A protocol is not a theorem.
- A replay is not independent scientific validation unless independence is
  established.
- A finite classification is not a general law.
- A counterexample establishes failure only within its declared scope.
- A structurally certified artifact is not a scientifically validated claim.
- An internal working name is not a recognized disciplinary term.
- Absence of a literature match is not evidence of novelty.

## Public terminology

`Transversal Geometry` shall not be presented as an established or new
mathematical field.

If retained internally, it remains historical working language for crossing
representations and carries no mathematical authority.

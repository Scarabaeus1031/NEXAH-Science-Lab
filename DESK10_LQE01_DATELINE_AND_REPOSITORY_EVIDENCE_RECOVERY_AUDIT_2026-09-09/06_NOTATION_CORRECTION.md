# Notation Correction

The prior file remains unchanged. Correct notation:

\[
\hat v_{\mathrm{air}} = \frac{2\Delta L}{\Delta\bar t}
\]

\[
\hat c_0 = n_g\,\hat v_{\mathrm{air}}.
\]

ΔL = L₂ − L₁ is independently surveyed; Δ\bar t = \bar t₂ − \bar t₁ is the measured differential round-trip mean. The first is an effective optical group-speed estimate for the measured path. The group index n_g requires uncertainty/covariance binding. The second is a corrected consistency estimate—not a redefinition, improved determination, or calendar derivation of exact SI c.

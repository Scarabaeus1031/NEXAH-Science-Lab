# A1 Independent Scientific-Contract Review Checklist

**This checklist is for an independent reviewer. A1 does not self-approve execution.**

## Authority and locality

- [ ] V1 remains authoritative outside A–C.
- [ ] No frozen plant/action/target/representation/population/threshold/model/sensitivity/ceiling rule changed.
- [ ] Every new choice is labeled prospectively rather than misrepresented as uniquely implied by V1.

## N5

- [ ] Two tiers have distinct purposes and failure states.
- [ ] Synthetic fixture is fully deterministic and nonregistered.
- [ ] N5-RUN uses the fixed original jointly supported query population and does not condition on transformed success.
- [ ] Q, B, target metadata, support, refits, inverse registration, ranking comparison, undefined tau, count, and threshold are executable without author judgment.
- [ ] N5 failure cannot be treated as P1 nonreplication.
- [ ] Twelve deterministic transforms once per tier is consistent with V1's 200-repetition rule for stochastic nulls.

## Per-seed dominance

- [ ] Row-weighted signed contributions algebraically equal aggregate held-out log-loss improvement.
- [ ] Negative gains are preserved.
- [ ] Zero/nonpositive aggregate, nonvarying seeds, zero-row seeds, ties, and the exact 50% boundary are fully defined.
- [ ] Formula does not optimize for likely passage.

## Null/P1–P3 mapping

- [ ] P1 remains agreement, P2 remains coefficient/interval, and P3 remains incremental prediction.
- [ ] “Primary predictive gain” is unambiguously held-out log-loss improvement.
- [ ] N1–N4 statistics, 200 repetitions, tie direction, exact Monte Carlo p-value, and failure mapping are complete.
- [ ] Coefficient null results remain mandatory diagnostics without silently adding a P2 criterion.
- [ ] N5 remains validity-only.

## Machine-readable artifact

- [ ] YAML parses.
- [ ] YAML and prose agree on every enum, population, formula, threshold, dependency, and failure state.
- [ ] No implementation default or scientific judgment is still required for A–C.

## Nonexecution

- [ ] No V3 implementation or freeze hash is present.
- [ ] No authorization exists.
- [ ] No registered scientific data/result was accessed or generated.

## Reviewer decision

- [ ] ACCEPT A1 FOR USE AS A PROSPECTIVE CONTRACT AMENDMENT.
- [ ] REJECT A1; list exact scientific-contract defect.

Acceptance of A1 is not authorization to execute EXP-00-R.

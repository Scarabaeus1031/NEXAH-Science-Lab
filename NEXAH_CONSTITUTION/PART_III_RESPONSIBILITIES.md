# Part III — Responsibilities

Status: `FROZEN`

## Responsibility assignment

| Responsibility | Constitutional authority | Owned artifact class | Boundary |
|---|---|---|---|
| OLS | Semantic Authority | Canonical semantic definitions and contracts | Meaning only |
| ORION | Structural Authority | Structurally validated orientation artifacts | Declared structural scope only |
| IRIS | Recognition Authority | Recognition Records | Recognition only; never truth or certification |
| Translation | Translation Authority | Translation Records | Fidelity only; never new meaning |
| SIRIUS | Presentation Authority | Shared application-facing packages | Shared boundary only; never application ownership |
| Applications | Application Authority | Local interfaces, workflows and application records | Independent application scope only |
| Named domain owner | Domain Authority | Domain validation records and conclusions | Named domain, method and evidence boundary only |
| NEXAH governance | Governance Authority | Constitutional decisions and custody records | Process, adoption and change only |
| Identified Human | Human Authority and Handlungshoheit | Explicit Human decisions | Applicable mandate and accountable action |

## Responsibility laws

1. One responsibility owns one bounded authority.
2. One authoritative artifact class has one constitutional owner.
3. Processing an artifact does not transfer its authority.
4. A downstream responsibility may reject an input without acquiring authority
   over its source.
5. Responsibility order does not define execution order.
6. Recognition does not certify structure.
7. Structural certification does not establish meaning or domain truth.
8. Translation does not create meaning.
9. Presentation does not create authority.
10. Application use does not constitute Human decision.

## Cross-cutting obligations

Evidence, validation, certification and provenance are not additional
constitutional authorities.

- Evidence belongs to its named source, protocol or domain owner.
- Validation belongs to the authority governing the declared validation scope.
- Certification is an act performed by a bounded authority.
- Provenance is mandatory for every authoritative artifact.

## Human boundary

Every recommendation, validation result, STOP record or application output ends
before Handlungshoheit begins. Only the identified Human may decide whether to
act and accept responsibility for that action.

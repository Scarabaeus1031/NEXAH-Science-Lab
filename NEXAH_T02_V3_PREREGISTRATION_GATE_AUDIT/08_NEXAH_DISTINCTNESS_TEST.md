# NEXAH Distinctness Test

## Candidate components

The prior design names multiple certificates, collision witnesses, cross-stage
uncertainty, structured pooling, explicit `UNKNOWN` and decision routing. These
describe an operational workflow, not yet a unique estimator.

## Redundancy matrix

| Candidate term | Closest established machinery | Residual distinction currently shown |
|---|---|---|
| certificate evidence | engineered statistics/features; sufficient-statistic tests | none without exact statistic and update rule |
| collision accounting | state aggregation, classification confusion, graph collisions | bookkeeping form only |
| cross-stage pooling | hierarchical/sequential models | none yet |
| adequacy uncertainty | calibrated risk intervals, Bayesian posterior risk | none yet |
| `UNKNOWN` | selective classification/abstention | none |
| remeasurement routing | value of information, active sensing/POMDP decision | none |
| representation preservation | lumpability, bisimulation, information/task sufficiency | established alternatives are often stronger |

## Six-test result

1. **Mathematically different from strongest B8:** `UNCLEAR`; no complete mapping
   is specified after B8 receives full conventional capabilities.
2. **Same information:** yes by contract.
3. **Can change a decision:** possible, not demonstrated independently of tuning.
4. **Can be wrong:** yes in principle through biased certificates and abstention.
5. **Can B8 outperform it:** yes in principle.
6. **Measurable outside terminology:** yes through common external loss, if Gates
   1–3 are completed.

## Required pre-preregistration proof of distinction

Write a design-only method specification and a component-to-prior-art crosswalk.
For every operation, state whether B8 may perform the same operation. Define
ablations and demonstrate analytically—without benchmark outcomes—that at least
one common-input case can yield different actions. If the only difference is
parameterization, reporting, thresholds or a subset of B8 features, classify the
candidate as `T02_V3_REDUCES_TO_ESTABLISHED_METHODS`.

Current conclusion: NEXAH distinctness is unproven, not presumed. This alone
prevents a Gate-3 pass and preregistration.

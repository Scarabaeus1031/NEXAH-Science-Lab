# Term and Non-Identity Matrix

| prompt term | admissible operational reading | prohibited collapse | status |
|---|---|---|---|
| SELF | estimated internal/model state plus authorized control policy | organismal, conscious, immunological, or moral self | candidate bookkeeping label |
| NON-SELF | environment state, exogenous input, and unmodeled residual | enemy, pathogen, moral other, or everything uncontrolled | candidate bookkeeping label |
| BOUNDARY | time-dependent assignment and controlled exchange contract | literal membrane or fixed geometric wall | bounded formal object |
| FISH | unresolved visual/observer marker | animal biology or fisheye transform without source | unresolved |
| CUTS | declared partition, projection, sampling, or segmentation operator | tissue incision or causal mechanism by resemblance | unresolved until typed |
| CODE | representation and rule encoding | genetic code | documentary unless explicitly typed |
| CELL | selective-transport comparison | mechanical joint, controller, or SELF identity | biology comparator only |
| axis | oriented line/vector in a declared frame | path, torque, or causal channel | standard geometry |
| X° | angle interval, corridor coordinate, transform parameter, or event guard | privileged universal optimum | candidate parameter |
| 90° | standard rotation or orthogonal relation | new effect or natural law | standard geometry |
| pressure | normal traction/force per area with units and area | load, energy, stress in general, or effort | physical only when measured/modelled |
| T / BP / split-T | possible labels for contact/base pressure, load path, moment arm, constraint, or event marker | meaning inferred from word, glyph, position, or color | unresolved |
| release | declared guard/event changing control or boundary mode | guaranteed return or energy liberation | bounded event |
| return | observed terminal criterion or next-trial record | geometric roundness, recurrence, or success | comparator-dependent |
| LIFE/LIVE/EVIL | string/reversal/viewpoint markers | biology, ethics, agency, or natural law | linguistic/visual only |

Required statements:

`MECHANICAL COUPLING ≠ CELLULAR TRANSPORT`  
`SELF/NON-SELF MODEL ≠ IMMUNOLOGICAL IDENTITY`  
`SHARED ARCHITECTURE MAY EXIST`  
`CROSS-DOMAIN IDENTITY IS NOT ESTABLISHED`

The shared architecture is limited to state, selective exchange, channels, constraints, response, and observation. Similar graph shapes do not establish common mechanism.

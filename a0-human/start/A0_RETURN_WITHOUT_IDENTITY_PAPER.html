Return without identity

Finite carriers, representation recovery and typed residuals. Five closed studies show why an endpoint can return while structure, operator, route history or full identity does not.

Abstract

Return is not one predicate. Across five exact finite Pascal-carrier studies, endpoint recurrence, structural recovery, representation recovery, operator inversion, route history and full identity separate. The positive connector is an injective quaternion representation with an exact cyclic intertwiner and inverse conjugation for every finite carrier PN. Nearby negative results show that terminal equality does not recover history, collision-free description need not compress, and algebraic return neither selects a global seam nor guarantees metric isometry.

1 · The missing connector

A Return claim must name its level.

The shared method is not a universal mechanism. It is a typing discipline: declare the carrier, representation, operator, comparison and residual before saying that something “returned”.

2 · Exact positive connector

The quaternion realizes the cyclic three-coordinate action.

For PN={(a,b,c)∈ℤ³≥0:a+b+c≤N}, set Φ(a,b,c)=(a+b+c)1+ai+bj+ck and u=(1+i+j+k)/2. The scalar depth is fixed, while conjugation cycles the imaginary channels.

Adᵤ(i)=j,  Adᵤ(j)=k,  Adᵤ(k)=i
Adᵤ(Φ(a,b,c)) = Φ(c,a,b)

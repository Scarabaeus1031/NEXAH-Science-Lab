# Readiness Levels

## Demonstrated

| ID | Demonstrated boundary | Not demonstrated |
|---|---|---|
| AP-01 | Frozen IEEE-9/14 geometry, provenance, no-retuning route, G3 operator equivalence | Exact clean replay at G4; conventional-baseline advantage; operational validity |
| AP-02 | Typed structural reports over chain and branched-cycle fixtures | Supply-chain, ecological, or other real-world validity |
| AP-03 | Reproducible Lorenz geometry and bounded Gate behavior | Universal transition detection or control |
| AP-04 | Exact arithmetic and frozen sequence comparisons with positive and negative results | Physical dynamics or universal modular effects |
| AP-05 | Synthetic record separation, failed blind reconstruction, and projection collapse | Empirical generalization or a general theorem |
| AP-14 | Deterministic bounded structural artifact generation | Reasoning, hosted orchestration, or scientific validation |

## Validation required

| ID | Existing base | Missing gate |
|---|---|---|

| AP-08 | Feasible bounded protocol | Frozen implementation and result |
| AP-11 | Gate implementation and JANUS exploratory code | One aligned statistic, nulls, baselines, held-out evaluation |

## Mathematics required

| ID | Existing base | Missing definition |
|---|---|---|
| AP-09 | Frozen reconstruction counterexamples | Representation equivalence, information-loss measure, and identifiability conditions |
| AP-10 | Field/relation/output handoff | Relation rule, output, encoding equivalence, stability, and baseline |

## Blocked

| ID | Blocking condition |
|---|---|
| AP-12 | No normative machine representation, validator, conformance suite, governed mapping, or two independent implementations |
| AP-13 | No observed operational input/outcome chain, classical baseline comparison, domain validation, or safety case |

## Public demonstration boundary

Suitable now for bounded public demonstration:

- AP-01 through the existing IEEE Geometry V1 Showcase, with prohibited claims visible;
- AP-02 using only declared illustrative fixtures;
- AP-03 as a reference visualization with the Gate limitation visible;
- AP-04 as an offline frozen research replay.

AP-05 is suitable for method-boundary review, not general public application claims. AP-14 is a software-core demonstration, not a scientific application demonstration.

## Result

Fourteen evidence-bound application candidates survive reduction:

- 6 demonstrated;
- 4 require validation;

`Demonstrated` means a bounded implementation or reproducible research object exists. It does not mean external validity, operational readiness, or measured user benefit.

## Reduction rule

Candidates were admitted only when an existing repository object addresses a practical problem and can be connected to a Program A or B research question, a Program C claim, or a maintained validation record. Historical scenarios, visual motifs, books, and unsupported capability language were excluded.

## Readiness classes

Each admitted application has exactly one readiness class:

| Readiness | Meaning |
|---|---|
| `DEMONSTRATED` | Bounded implementation or replayable research object exists. |
| `VALIDATION REQUIRED` | Method or prototype exists, or a bounded protocol is recoverable, but the claimed use has no sufficient outcome evidence. |
| `MATHEMATICS REQUIRED` | The necessary observable, map, equivalence, or preservation condition is not defined well enough for an application test. |
| `BLOCKED` | A required capability, evidence source, safety boundary, or implementation is absent. |

## Evidence method

- All 80 source files were recursively inventoried with byte size and SHA-256.
- The three reports were read in authoritative order and rendered to 97 temporary pages (62 + 19 + 16) for documentary review.
- HTML instruments were retained as distinct interactive/source representations; PNG/SVG files were retained as visual exports.
- Screenshots were treated as contextual evidence only.
- Exact duplicates were identified by SHA-256; representation counterparts and derivative views were grouped without deletion.
- File modification times were used only to order artifacts after Report III, not as proof of conceptual priority.

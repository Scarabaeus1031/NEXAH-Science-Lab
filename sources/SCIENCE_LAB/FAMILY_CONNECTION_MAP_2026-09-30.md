## 1. Why this map exists

The Lab is increasingly reusing the same typed operations across arithmetic,
representation, transition analysis, dynamical systems and control:

```text
select -> encode -> observe transitions -> compare structure
       -> derive coordinates -> test events -> retain residuals
```

This is genuine methodological compression. It does not imply that all source
systems share one mechanism, one geometry or one physical ontology.

The map therefore records both:

- where families are joined by an exact map or a reproducible result;
- where they share only an analysis method;
- where the proposed bridge remains untested;
- where two visually similar objects must remain non-equivalent.

## 2. Connection types

| Code | Meaning | Scientific consequence |
|---|---|---|
| `EXACT_MAP` | Declared deterministic map between typed objects | The output follows from the input and map; no empirical novelty by itself |
| `EMPIRICAL_LINK` | Reproduced relation under a bound test contract | Valid only for the registered data, operator and scope |
| `METHOD_BRIDGE` | Same comparison method can be used in both families | Shared language, not shared mechanism |
| `OPEN_BRIDGE` | Testable connection has been formulated but not admitted | No result or architecture promotion |
| `NON_EQUIVALENCE` | Similar representations have been explicitly separated | Prevents silent collapse of distinct objects |

## 3. The seven families

### F1 — Observation, representation and residual

Core objects:

```text
carrier, cut, frame, projection, record, fiber, reconstruction, residual
```

This family supplies the general comparison grammar. It includes
Representation Fidelity, Records/Return/Residual, Observer/Frame/Aperture/Cut
and RTTG-style provenance.

Current status: strongest as a method and in bounded representation audits;
external incremental utility remains separately gated.

GEN01 adds one bounded exact implementation of the T5/T6/T7 relation path:
typed objects are lifted to stored relation objects, adjacent relation objects
are compared through one independently recomputed meta-level, and lossless
base representations return exactly. Endpoint-only projection is formally
non-injective in the registered expanded history space. The
`mathcal G_0/mathcal G_1/mathcal G_2` notation remains case-local and stops at
one meta-level.

GEN02 extends that evidence from one recurrence family to four authored
relation families under one exact field contract: directed successor,
symmetric equivalence, role-ordered incidence and a ternary-intersection
holdout. All stored records, meta-relations, destructive controls and three
lossy baselines passed with byte-identical replay. This is an `EMPIRICAL_LINK`
between heterogeneous typed-relation fixtures and the shared record grammar,
not proof of shared semantics: the semantic registry remains family-specific,
and the `n+1` Binder remains a separate unvalidated candidate.

### F2 — Finite arithmetic, address and boundary

Core objects:

```text
prime value, prime index, residue class, CRT address, finite state grammar,
cube boundary pair, Shadow-Cube lift
```

This family supplies exact discrete carriers and feature maps. Root7, Mod6,
Zero/Glyph/Iota, Vendessimal grids, palindrome half-edges and cubic boundary

Current status: much of the local arithmetic is exact or finitely auditable;

### F4 — Phase, drift and flow coordinates

Core objects:

```text

unwrapping, drift, winding diagnostic, embedded field
```

This family supplies continuous or circular coordinates for ordered motion.
Lorenz, Roessler, Halvorsen and modular prime sequences can all be represented
with phase coordinates, but those coordinates are not thereby identical.

Current status: phase is an available comparative coordinate. A
projection-independent universal phase has not been established.

recovers `p` on `p>=0`, while `w=floor(p/2pi)` and
`alpha=p mod 2pi` split the same state into winding/shell and residual phase.
This is not a prime-specific effect: ORION already records the historical
exceptional-prime reading as failed/demoted. CURVE00 verified the exact and
numerical fixture with 15/15 checks and byte-identical replay. It also separates
the centered K°-Grid from both the historical `kappa=56` layer channel and the
later ordinal Kappa path.

CURVE01 completed its fully frozen V0.10/V7 200,000-draw production path as a
`VALID_NEGATIVE`. Representation, controls, replay and independent finalization
passed, while the registered directional effect failed its effect-size,
permutation, block and leave-one-out support conditions. The case is closed
without a prime law, capability or automatic successor. The finalized

`5a02d638d31036e0d4ec442623de0c04887b2221e563f08cb1bc41d8eb15985b`.

### F7 — Validation, replay and claim governance

Core objects:


This family is transversal. It does not provide another mechanism; it governs
every bridge between F1–F6.

Current status: operational and repeatedly used. It is the reason negative,
mixed and withheld results remain part of Lab knowledge.

## 6. What has actually compressed

The following concepts can now be treated as one reusable methodological
spine:

```text
typed source
  -> declared observation or encoding
  -> transition or relation operator
  -> invariant and residual comparison
  -> independent null and replay
  -> bounded result or fail-closed stop.
```

This compression is supported across multiple Lab families.

The following concepts must not yet be compressed into identities:

```text
residue phase != physical phase
operator subspace != sheet alphabet
cycle drawing != unique cycle decomposition
phase embedding != emergent torus
shared phase notation != common mechanism
event coincidence != synchronization
synchronization != causal coupling
Shadow-Cube lift != new within-modulus information
prime-labelled grid != Coxeter root system
similar polygon != shared reflection group
projected hedron != physical object
```

## 9. Claim boundary

Permitted:

> Several previously separate NEXAH research lines now share a typed
> observation–operator–comparison–validation spine. Their family relations
> can therefore be registered without merging their evidence or mechanisms.

Not permitted:

- all NEXAH families are one discovered natural law;
- the family spine proves a universal phase or topology;
- visual similarity closes an open bridge;
- PMR01A already validates synchronization;
- family compression promotes a demonstrator into an empirical result.

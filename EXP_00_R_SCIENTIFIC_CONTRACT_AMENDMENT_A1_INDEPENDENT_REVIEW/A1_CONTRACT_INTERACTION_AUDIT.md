- N5-RUN fixes its query population before transformed fits, so support changes cannot favorably alter membership.
- N5-RUN happens before outcome generation and classification, so invalidity cannot occur after an official label.
- Per-seed dominance uses the same primary carrier probability rows as aggregate P3, so its algebraic dependency is coherent.
- Shared P1 and carrier-specific P3 are not contradictory: agreement is one pair statistic, while intervention reliability is carrier-specific.
- The unresolved N1–N4 population/outcome handling can make P3 use a different estimand from observed P3. This is blocking.
- The contract has correctly typed the primary inference population and the separate nonzero support-validity population; those are not conflated.

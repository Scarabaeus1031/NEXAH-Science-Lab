# NEXAH Distinctness Audit

| NEXAH term | Established technical translation |
|---|---|
| Pull | likelihood/information weighting, localization or restoring force—must choose one |
| Structure | state parameterization, graph, geometry, manifold or covariance |
| Flow | process/transition/dynamics model |
| Stillpoint | equilibrium, fixed point, mechanical zero or minimum-risk decision |
| Collision | non-identifiability, aliasing, data-association collision or equivalence class |
| Certificate | confidence/credible interval, conformal set, residual test or observability condition |
| Translation fidelity | pose/reconstruction error, sufficiency, mutual information or downstream task risk |
| UNKNOWN | abstention/selective prediction |
| Remeasurement | value-of-information/active sensing action |

The terms are not interchangeable until equations fix their meaning. In the
current physical concept, every operationally relevant function maps to standard
estimation, observability, calibration or decision theory. No complete NEXAH map
from synchronized sensor data to an estimate/action has been specified, and no
operation is shown to be unavailable to the strongest conventional comparator.

`NEXAH_METHOD_DISTINCTNESS_NOT_ESTABLISHED`

This finding does not invalidate an ORION bench instrument. It means the MVP must
be motivated and evaluated as a standard observability/sensor-fusion platform.
NEXAH may enter only later as a frozen candidate estimator with operation-level
differences, equal information and resource budgets, ablations, and permission to
lose. Symbolic terminology, a ledger or visual coherence is not distinctness.

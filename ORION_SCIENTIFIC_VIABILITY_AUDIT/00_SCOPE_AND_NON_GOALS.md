# Scope and Non-goals

This is a design-only scientific viability audit of the proposed ORION Compass /
Multimodal Probe. It does not build hardware, implement an estimator, simulate or
run an experiment, generate measurements/results/figures, order components,
freeze a protocol or modify canonical NEXAH.

The audit treats the existing CNC coordinates, manufacturing prose and rendered
visuals as design material, not evidence. “Certified,” numerical tolerances and a
photorealistic prototype image do not establish manufacture, calibration,
performance or scientific validity.

The admissible question is whether a reproducible physical platform can relate a
latent state to heterogeneous observations, state reconstruction and an external
decision. Symbolic names and constants—`pi`, `phi`, `sqrt(2)`, Relation Dot 1032,
Stillpoint, Gauss, Dirac and related vocabulary—have no physical role unless an
observation, dynamics or loss equation derives one.

ORION is kept separate from T02. Neither T02 nor NEXAH evidence validates this
instrument, and a useful conventional sensor-fusion platform would remain useful
even if NEXAH has no distinct estimator.

# Ledger Scientific Object

The primary object is a directed translation edge

`R_i --T_ij--> R_j`.

A representation class says what kind of object may occur. An artifact is a concrete instance. An operator specifies what happened. Evidence states why an assertion is accepted. These four objects are not interchangeable.

The smallest useful record must answer:

1. Which typed source artifacts entered?
2. Which operator, version, parameters, and assumptions acted?
3. Which typed target artifacts resulted?
4. Which named structures were preserved, lost, or introduced, at what evidence level?
5. What uncertainty and invertibility classification applies?
6. What provenance and negative evidence bounds the edge?
7. Is task relevance undefined or independently anchored?

Human interpretation is an operator kind but cannot masquerade as computation. A conceptual edge may be documented, but it cannot be upgraded to verified without new technical evidence.

# Scope and Evidence Boundary

This is a design-only specification and falsification audit. It defines no new transformation, executes no experiment, builds no runtime, and changes no canonical NEXAH artifact.

## Admissible evidence

- canonical source inspected at commit `724814ea40351141350a1822d7c559a308ac0cfa`;
- frozen data, hashes, replay records, and completed audit findings;
- mathematical definitions and external references when directly applicable;
- conceptual records only when unmistakably marked non-technical.

Historical terminology, diagrams, symbolic material, and visual resemblance cannot verify an edge. Unknown values remain `UNKNOWN` or `NOT_QUANTIFIED`; they are not inferred from neighboring records.

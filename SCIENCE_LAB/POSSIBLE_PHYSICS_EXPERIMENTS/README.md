# Possible Physics Experiments

Maintained through: `2026-09-26`

Status: `CANDIDATE_NAVIGATION / NO_RESEARCH_ACTIVATION`

This is the Science Lab waiting room for bounded physical experiments that
have a testable question and an evidence package but are not yet authorized or
equipped for physical execution. It is a pointer index, not a second evidence
store.

Candidate status does not activate physical execution.

## Admission and clean-desk rules

1. An entry needs a falsifiable physical question, an owning package, a
   declared evidence state and one explicit next gate.
2. The index links to evidence; it does not copy results or create a second
   experimental identity.
3. `POSSIBLE` is not `ACTIVE`, `EXECUTED` or `VALIDATED_PHYSICALLY`.
4. Buying equipment, collecting data or changing the protocol requires a
   separate Human Owner authorization.
5. Candidates that close or are rejected retain their original evidence path
   and receive a terminal disposition rather than disappearing.

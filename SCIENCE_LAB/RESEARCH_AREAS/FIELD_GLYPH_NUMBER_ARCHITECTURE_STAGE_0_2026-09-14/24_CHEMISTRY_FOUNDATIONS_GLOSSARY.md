# NEXAH Chemistry Foundations Glossary

Date: `2026-09-17`

Status: `FOUNDATION_GLOSSARY / ESTABLISHED_CHEMISTRY_SEPARATED_FROM_NEXAH_READING`

Operational effect: `NONE`

## 1. Purpose

This glossary fixes the chemical vocabulary used by the NEXAH research
records. It keeps three layers separate:

1. established chemical meaning;
2. a bounded representation or RTTG use;
3. an open analogy or hypothesis.

The periodic table may be used as a relational carrier. Arithmetic or visual
relations on that carrier do not by themselves transfer chemical properties,
establish reactions or create a new chemical law.

## 2. Claim labels

| Label | Meaning |
|---|---|
| `ESTABLISHED_CHEMISTRY` | standard chemical definition or accepted model |
| `EXACT_INDEX_RELATION` | exact arithmetic using chemical identifiers such as atomic number |
| `REPRESENTATION_MODEL` | declared view, window, graph, fold or comparison scheme |
| `MEASURED_RESULT` | observation with sample, method, units, controls and uncertainty |
| `OPEN_HYPOTHESIS` | testable proposal not yet established |
| `EXPRESSION_ONLY` | mnemonic, visual genealogy or symbolic language |

## 3. Matter and identity

| Term | Chemical meaning | NEXAH boundary |
|---|---|---|
| Element | substance defined by one atomic number `Z` | a node in a periodic-table carrier; not reducible to its symbol or number pattern |
| Atom | electrically neutral or specified atomic species with a nucleus and electrons | may be represented by a record, but the record is not the atom |
| Atomic number `Z` | number of protons in the nucleus; fixes elemental identity | valid discrete address for arithmetic windows and translations |
| Mass number `A` | number of protons plus neutrons in one nuclide | must not be confused with atomic number or atomic mass |
| Isotope / nuclide | species with declared proton and neutron numbers | same element may have several nuclides with different physical properties |
| Ion | atom or molecular species with net electric charge | charge state must be explicit; the element symbol alone is insufficient |
| Molecule | discrete bonded collection of atoms | visual proximity does not establish a bond |
| Compound | substance with a defined chemical composition involving more than one element | a shared number or shape does not establish a compound |
| Chemical species | precisely specified atom, ion, molecule, radical or other chemical entity | preferred unit of identity for a measurement record |
| Sample | actual material portion under observation | requires provenance, preparation, matrix, container and time |
| Matrix | surrounding material in which the target species occurs | part of the measurement conditions, not background decoration |

## 4. Periodic-table coordinates

| Term | Chemical meaning | RTTG use |
|---|---|---|
| Periodic table | arrangement of elements by atomic number and recurring electronic structure | relational carrier with several coordinate systems |
| Period | horizontal row associated with successive principal electronic shells | one possible territory or window coordinate |
| Group | vertical column whose members often share valence patterns | chemical family coordinate; similarity is not identity |
| Block | `s`, `p`, `d` or `f` region defined by the subshell being filled | typed regime, not merely a colored area |
| Transition metal | element in the `d`-block under the adopted chemical definition | local relay windows may be compared, but index shifts do not transfer properties |
| Lanthanide | conventional series associated with filling of the `4f` subshell | part of, but not synonymous with, all rare-earth material |
| Actinide | series associated with filling of the `5f` subshell | includes distinct elements and nuclides with different hazards and behavior |
| Rare-earth elements | scandium, yttrium and the lanthanides in common chemical usage | family register; every experiment must name the actual element and compound |
| Periodic window | declared finite selection of neighboring table addresses | NEXAH representation term, not a standard chemical object |
| Atomic-number translation | map `Z -> Z + k` on selected addresses | exact index relation; does not imply chemical equivalence or transmutation |
| Reflection / midpoint | pairing of addresses around a declared center | exact arithmetic when sums are fixed; no chemical causality follows |
| Local order | ordering retained within a translated or shifted window | a trace of the representation, not a preserved material property |

## 5. Structure, phases and boundaries

| Term | Chemical meaning | Important distinction |
|---|---|---|
| Phase | homogeneous region with specified physical and chemical properties | not every visual region is a thermodynamic phase |
| Phase transition | change between phases under declared conditions | requires observables such as temperature, pressure or composition |
| Crystal | solid with long-range ordered atomic or molecular structure | crystal geometry is material structure, not a universal symbolic grid |
| Crystal lattice | periodic mathematical description of translational order | the lattice is an idealized carrier; a real crystal also contains boundaries and defects |
| Unit cell | repeating cell used to describe a crystal structure | representation choice; not necessarily an isolated physical cell |
| Defect | vacancy, interstitial, substitution, dislocation or other departure from ideal order | may retain preparation history and affect measured properties |
| Domain | region sharing an order parameter or orientation | must be typed; not identical to a generic NEXAH territory |
| Grain boundary | interface between crystalline grains of different orientation | real material boundary with transport and mechanical consequences |
| Interface | boundary between two phases or materials | may be idealized as a surface |
| Interphase | finite region near an interface with changed composition, structure or dynamics | measurable candidate for the NEXAH “space in between” |
| Salt | electrically neutral ionic compound assembled from cations and anions | not one chemical class with one behavior; exact composition and phase are required |
| Hydration | association with water or incorporation of water into a material structure | hydration state may change mass, phase, conductivity and crystal form |
| Dissolution | process by which a solute becomes dispersed in a solvent | distinct from melting and from chemical decomposition |
| Crystallization | formation or growth of an ordered solid phase | requires declared solution, temperature history, rate and readout |

## 6. Composition and chemical change

| Term | Chemical meaning | Record requirement |
|---|---|---|
| Concentration | amount of a component per declared amount or volume | units and basis must be stated |
| Mole | SI amount-of-substance unit | not a geometric count or visual cluster |
| Molar mass | mass per mole of a specified substance | chemical identity and units required |
| Stoichiometry | quantitative relation among reactants and products | balanced equations do not by themselves specify kinetics or mechanism |
| Speciation | distribution among chemical forms of an element or component | crucial for iodine, sulfur, mercury and solution chemistry |
| Oxidation state | formal electron-accounting number assigned by rules | not a measured charge on an isolated atom by default |
| Redox | coupled oxidation and reduction involving electron transfer accounting | not interchangeable with pH, color or temperature |
| pH | logarithmic measure related to hydrogen-ion activity in solution | requires temperature, medium and method; not a universal polarity axis |
| Reaction | chemical transformation with identified reactants and products | needs material evidence; number adjacency is insufficient |
| Catalyst | substance that changes reaction rate while being regenerated in the reaction cycle | a central diagram node is not automatically a catalyst |

## 7. Energy, potential and memory

| Term | Chemical or physical meaning | NEXAH boundary |
|---|---|---|
| Energy | physical quantity with units, reference and measurement or model | do not use as a synonym for importance, color or activity |
| Chemical potential | thermodynamic quantity governing transfer and equilibrium tendencies | distinct from the NEXAH use of “potential” as admissible next states |
| Potential-energy landscape | model assigning energy to states or configurations | requires declared coordinates and energy function |
| Stored energy | quantified energy retained relative to a reference state | may occur in strain, fields, composition or interfaces; not identical to memory |
| History dependence | present response depends on the path by which the state was reached | minimum formal content of material memory |
| Hysteresis | different response paths under increasing and decreasing control variables | measurable form of history dependence |
| Material memory | reproducible present-state information about prior forcing or preparation | requires state variables, write process, read process and persistence time |
| Residual | measured or computed remainder after a declared comparison | must be typed: material, energetic, geometric, statistical or unresolved |
| Return | comparison with or reconstruction into a declared earlier frame | not automatic restoration of the earlier material state |

Stored energy and memory may coexist, but neither implies the other.

## 8. Observation and evidence

| Term | Definition |
|---|---|
| Observable | quantity that a declared method can record |
| Excitation | controlled input such as temperature change, electric field, light or mechanical drive |
| Detector | instrument or method that converts an observable into a record |
| Calibration | relation between instrument response and known references |
| Blank | control lacking the target component or treatment |
| Comparator | reference state, material or model used for a declared difference |
| Detection limit | smallest amount distinguishable under a specified method and confidence rule |
| Uncertainty | quantified limitation of a measured or derived result |
| Trace | time-ordered or address-ordered measurement record |
| Color observation | optical record dependent on illumination, path, detector and material state; not chemical identification by itself |
| Receipt | provenance record binding sample, method, data, transformation and result |

Minimum empirical record:

```text
sample + identity/form + environment + boundary/container
+ excitation + detector/calibration + time + comparator
+ observation + uncertainty + residual + provenance
```

## 9. RTTG translation for chemistry

| RTTG term | Chemistry-safe reading |
|---|---|
| Carrier | periodic table, sample set, composition space or measured state space |
| Relation | typed adjacency, similarity, bond, comparison or correlation |
| Territory | declared group, period, block, phase region or selected data window |
| Boundary | selection edge, phase boundary, interface or measurement threshold |
| Cut | finite element window, sample selection or observation event |
| Transition | index map, phase change, reaction, transport step or measurement update |
| Trace | preserved order, midpoint, trajectory or detector history |
| Residual | what the map, measurement or return does not close |
| Memory | retained path dependence in the carrier or its record |
| Return | reconstruction or comparison under a declared reference |

The same RTTG word may therefore denote different mechanisms. The carrier and
transition type must be stated every time.

## 10. Moon and external forcing

The Moon is not part of the chemical element register. It may enter a chemical
or material experiment only through a declared physical variable, for example:

```text
lunar phase/time coordinate
tidal acceleration or deformation
illumination geometry
environmental covariate
```

“Shapes the field” is admissible only after the field and coupling are named.
“Keeps the memory” is not a scientific property of the Moon by itself. Memory
belongs to a material or record that measurably retains a prior interaction.

## 11. Historical and visual influences

Russell-inspired periodic layouts may be preserved as design genealogy and as
prompts for alternative views. They are not an authority for element identity,
electron structure, chemical behavior or reaction mechanisms. Modern chemical
definitions and measurements control those claims.

## 12. Current NEXAH examples

| Example | What is exact | What remains open or excluded |
|---|---|---|
| `C(22,2)=231` and `Pa-231` | shared integer in two registers | no derivation of Pa from combinatorics |
| `Ce/Pr/Nd + 32 -> Th/Pa/U` | atomic-number translation | no chemical equivalence |
| reversed pairs around `Re, Z=75` | fixed midpoint with changing gaps | no reaction or material coupling |
| `Dy/Ho/Er +29/+32` windows | translated three-position order | properties do not transfer with the indices |
| `Fe/Co/Ni -> Ru/Rh/Pd -> Os/Ir/Pt` | declared `+18`, then `+32` address relay | chemical similarity must be evaluated separately |
| salts / water / oil | valid candidate interface system | experiment and dataset not yet completed in this record |
| crystals as memory carrier | plausible when defects, domains, phase or hysteresis are measured | no general crystal-memory law established |
| Russell X-Tensions | alternative views of one periodic carrier; see `25_RUSSELL_X_TENSIONS_MULTI_VIEW_CARRIER.md` | representation audit, not an alternative atomic model |

## 13. Writing rule

Every cross-domain chemical statement must name:

```text
chemical identity
+ active register
+ carrier and coordinates
+ operation or mechanism
+ observable and units
+ retained relation
+ residual
+ claim status
```

If any of these is missing, preserve the statement as an expression or open
hypothesis rather than upgrading it to chemistry.

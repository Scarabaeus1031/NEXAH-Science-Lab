# Cut / Double Cut and Dynamical-Systems Interface

The number/grid/fold/return line and the dynamical-systems line meet at a method,
not at an asserted shared ontology.

```text
carrier -> declared cut A -> record A
carrier -> declared cut B -> record B
records -> registration/comparison -> I/L/A/U + typed residual -> return
```

For numeric and glyph carriers, the cut may be a page, grid, residue map,
coordinate frame or decoder. For dynamical carriers, it may be a time window,
section, projection, parameter setting, density field or transition rule. The
common requirement is provenance-preserving comparison.

The historical Double Cut Lab 0.2 retains its narrower temporal-cut plus
spatial-mask meaning. The A/B comparative form is a Stage-0 method extension,
documented in:

`SCIENCE_LAB/RESEARCH_AREAS/DYNAMICAL_SYSTEMS_TRANSITION_FIELDS_STAGE_0_2026-09-14/02_CUT_DOUBLE_CUT_RESIDUAL_METHOD.md`.

The interface supports the working spine:

```text
NUMBER -> GRID -> STRIP -> FOLD -> SPIRAL
       -> ORIENTATION -> PROJECTION -> RETURN
```

and the dynamical spine:

```text
DYNAMICS -> SAMPLE -> FIELD -> TRANSITION CANDIDATE
         -> ORIENTATION/COMPARISON -> RESIDUAL -> RETURN
```

No cross-domain mechanism is inferred from the shared method.

## Register rules

1. Only the Human Owner admits a new maintained row.
2. Existing names are retained; this register does not invent retroactive Lab
   identities.
3. A row contains links and bounded disposition only, never copied evidence.
4. Native status and common Lab status remain separate.
5. `CLOSED` requires a Labreport and closure gate.
6. Historical packages are not bulk-imported. Add one only when it becomes
   necessary for active navigation or an owner-selected retrospective closure.
7. Changes to question, owner, canonical home or final disposition require a
   recorded owner decision.

# `LAB CLOSE <branch>` protocol

This is a controlled procedure, not autonomous mutation authority.

1. Locate all candidate evidence, review, replay, theory, and integration
   packages for `<branch>`.
2. Verify recorded hashes/provenance without changing source evidence.
3. Read controlling final reports and resolve authority/supersession order.
4. Determine one final classification using the controlled vocabulary.
5. Update or create the capability ledger with exact scope.
6. Update the eliminated-questions ledger, including negative/invalid branches.
7. Update architecture/interface records only where evidence requires it.
8. Generate a canonical Labreport using every schema field.
9. Add one entry to `LABREPORT_INDEX.md` with report hash.
10. Run the closure gate and declare `CLOSED`; otherwise report the exact
    missing item and assign `BLOCKED`, `AWAITING_AUDIT`,
    `AWAITING_INTEGRATION`, or `READY_FOR_LABREPORT`.

Safety rules:

- never execute or rerun science as part of closure;
- never repair evidence after result exposure;
- never overwrite historical reports;
- never promote claims through summary language;
- never modify external/canonical repositories without explicit authority;
- prefer additive records and explicit supersession;
- require user authorization for materially destructive or external actions.

Required files: evidence map, capability update, eliminated-questions update,
canonical Labreport, Labreport Index entry, and hash manifest.

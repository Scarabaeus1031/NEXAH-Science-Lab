# Final AREV-01 Decision

The recurring motifs can be reduced to a small representation-safe grammar using ordinary graph theory, Euclidean geometry, coordinate frames, metrics and observation maps. The useful gain is consolidation: an anchor, ray, edge, junction, embedding, metric angle and view are now typed separately, and an embedding path can represent changing geometry while graph relations remain fixed.

The grammar is sufficiently precise to inform a future Rust-facing interface, especially by requiring every angle to cite its embedding and metric and every view to cite its source embedding. This is interface usefulness, not implementation readiness or a scientific claim delta.

The historical `i/j/l`, Iota and Yugo names do not improve the type boundary enough to justify canonical interface aliases. They remain expression or documentary vocabulary. Wheel and coil survive only as conditional standard geometric/representation roles. No quaternion, physical or symbolic semantics is admitted.

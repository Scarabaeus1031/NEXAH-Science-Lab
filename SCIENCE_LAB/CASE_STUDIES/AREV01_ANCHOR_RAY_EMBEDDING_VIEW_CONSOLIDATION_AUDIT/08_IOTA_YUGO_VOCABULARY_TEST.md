# Iota / Yugo Vocabulary Test

## Criteria

An interface alias would need one stable typed referent, low collision risk, neutral-relabel survival, reduced ambiguity and no semantic dependency.

## Iota

The proposed bundle “local orientation / directed cut / ray-level relation” contains multiple distinct roles. `Iota` is also established mathematical vocabulary and risks collision with `i`. Standard names such as `Ray`, `Direction` and `Cut` are more precise.

`IOTA_ROLE_STATUS=REJECT`

This rejects it as an interface alias, not as historical expression.

## Yugo

The proposed bundle “junction / integration / multi-ray relation” likewise combines graph incidence with an interpretive process. `Junction` or `Degree3Junction` already names the recoverable role without extra semantics.

`YUGO_ROLE_STATUS=REJECT`

This rejects it as an interface alias, not as historical expression.

Both names may remain in documentary records with explicit local glosses. Neither becomes a canonical mathematical type.

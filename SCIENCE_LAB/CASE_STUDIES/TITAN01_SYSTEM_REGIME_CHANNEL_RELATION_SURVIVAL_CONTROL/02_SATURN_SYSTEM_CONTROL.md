# Saturn System Control

[NASA's Cassini ring summary](https://science.nasa.gov/mission/cassini/science/rings/) treats Saturn, moons and rings as primary Saturn-system components and reports ring-moon material exchange and gravitational interaction.

SATURN_SYSTEM_VIEW_SUPPORTED=YES. This supports typed members and interactions, not metaphor.

SYSTEM != OBJECT
SYSTEM_MEMBERSHIP != CAUSATION
INTERACTION != MESSAGE
PHYSICAL_INFLUENCE != SEMANTIC_INFORMATION
TRACE != INTENTION

SATURN_AS_MESSAGE_SENDER_SUPPORTED=NO. No semantic sender/message/receiver contract is supplied.

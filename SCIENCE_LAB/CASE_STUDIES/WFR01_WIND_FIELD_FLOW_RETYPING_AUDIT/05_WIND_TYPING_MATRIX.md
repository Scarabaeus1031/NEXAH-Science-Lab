# WIND typing matrix

WIND starts as unknown label W and receives a type only from bounded context.

| Candidate role | Valid when | Boundary |
|---|---|---|
| External forcing | Declared input | Not resulting change |
| Boundary condition | Boundary values encode influence | Not evolution |
| Environmental regime | Label selects conditions | Not one event |
| Vector field | Vectors defined over domain | Not automatically observed flow |
| Transport medium | Moving air is carrier | Not transported object |
| State variable | Quantity in state schema | Not whole state |
| Observed flow | Measurements support bounded flow | Not universal mechanism |
| Figure/Gestalt/Interpretation | Only representation/reading exists | Not physical claim |
| Expression only | Poetic/symbolic use | Zero formal evidence |
| Underdefined | No criterion | No forced typing |

Some winds can be modelled as flow; label identity does not establish type identity. `WIND_SINGLE_UNIVERSAL_TYPE=NO`; `WIND_DISTINCT_FROM_FLOW=YES`.

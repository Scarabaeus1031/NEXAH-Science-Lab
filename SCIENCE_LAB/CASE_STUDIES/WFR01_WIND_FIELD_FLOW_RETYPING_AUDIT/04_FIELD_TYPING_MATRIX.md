# FIELD typing matrix

FIELD is not a universal primitive.

| Use | Bounded type | Needed context | Not identical to |
|---|---|---|---|
| Physical field | Quantity over domain | Units, domain, model, evidence | Metaphor |
| Vector/scalar field | Typed assignment | Frame, scale, definition | Trajectory |
| Environment/regime | Conditions | Regime/provenance | Flow event |
| Parameter field | Configuration | Schema | Physical field by default |
| Constraint/state space | Admissible relations/states | Definition | Dynamics or one state |
| View field | Readout region | Observation map/frame | Source structure |
| Data field | Record attribute | Schema | Physical field |
| Metaphorical field | Narrative/analogy | Expression provenance | Formal object |
| Unresolved | `UNDERDEFINED` | Missing definition | Any adopted type |

Globally: `FIELD != WIND`, `FIELD != FLOW`, `FIELD != STRUCTURE`, `FIELD != VIEW`. A bounded wind may be a velocity field or field-derived input without merging categories.

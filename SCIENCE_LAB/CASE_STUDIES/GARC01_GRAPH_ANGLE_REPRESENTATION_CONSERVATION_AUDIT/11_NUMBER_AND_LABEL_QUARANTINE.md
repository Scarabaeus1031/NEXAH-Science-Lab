# Number and Label Quarantine

The following have zero evidential force for graph topology or Euclidean angle unless independently defined in the model:

- prime labels;
- integer factorizations;
- digit packets or shifts;
- symbolic colors;
- glyph shapes;
- animal names;
- letter positions or acronym associations;
- visual resemblance to earlier NEXAH material.

A vertex label may help identify a vertex. It does not create an edge, metric, angle, dimension, operator or physical relation.

Ordinary integer facts from NPF-01 remain true but irrelevant to the present geometry unless an explicit, source-bound mapping is supplied. None is supplied here.

`PRIME_LABEL_GEOMETRIC_EVIDENCE=ZERO`

`INTEGER_FACTORIZATION_ANGLE_EVIDENCE=ZERO`

`GLYPH_SHAPE_GRAPH_EVIDENCE=ZERO_WITHOUT_DECLARED_MAPPING`

`LABEL_EQUALS_STRUCTURE=NO`

# Minimal Machine Reconstruction

The frozen evidence supports a branched, not strictly linear, machine:

```text
REGISTERED ENTITY/SOURCE + ID + REVISION
  -> declared STATE
  -> {STRUCTURE/GEOMETRY branch | OBSERVATION/MEASUREMENT branch}
  -> typed REPRESENTATION and/or VIEW with frame, scope and loss
  -> declared OPERATION RULE + criterion + prerequisites
  -> optional EXECUTION EVENT
  -> typed ASSESSMENT/OUTCOME
       {preserved, transformed, different, ambiguous,
        unresolved, undefined, abstained, error}
  -> RESULT OBJECT and TRACE (neither implies the other is complete)
  -> HISTORY + PROVENANCE
  -> optional INTERPRETATION / KNOWLEDGE-STATUS record
  -> declared normative criterion
  -> HUMAN DECISION
```

Arrow audit:

- Entity/source does not determine one state; state identity must be declared.
- Observation is one route to a representation, not a compulsory stage for geometry sources.
- A view does not become a new object merely by differing.
- An operation rule and executable conditions do not attest an event.
- Comparison needs a declared criterion; it is not universal.
- Outcome, result and trace are separate; failures and undefined outcomes are legitimate.
- Trace is not provenance, evidence or truth by itself.
- Interpretation and knowledge status remain downstream records.
- A criterion does not make a decision; Human Authority does.

This recovers a coherent typed architecture but not one deployed end-to-end machine.

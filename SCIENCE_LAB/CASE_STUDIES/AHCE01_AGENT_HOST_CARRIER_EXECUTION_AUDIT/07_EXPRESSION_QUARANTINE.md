# AHCE-01 — Expression Quarantine

| Token | Status |
|---|---|
| BACTERIUM | Domain label only; no syllabic or symbolic inference. |
| VIRUS | Domain label only; no common-agent identity inferred. |
| INFECTION_ALPHA | EXPRESSION_ONLY |
| BRAUN | EXPRESSION_ONLY |
| BRAIN | Domain/expression word; not AI. |
| AI | Technical domain label; not consciousness, agency, or authority. |
| R / REST / ROST / BLACK_RUST | EXPRESSION_ONLY |
| RADIATION | Physical exposure variable only when explicitly measured/sourced. |
| ROTATION / TRANSMISSION / TRANSITION / TRANSLATION / TRANSFORMATION | Separate terms; lexical resemblance supplies no operator identity. |

```text
WORD_RESONANCE_NE_FORMAL_IDENTITY=YES
BRAIN_NE_AI=YES
BRAUN_BRAIN_RESEMBLANCE=EXPRESSION_ONLY
BIOLOGICAL_INFECTION_NE_SOFTWARE_EXECUTION=YES
CANCER_NE_EXTERNAL_INFECTION=YES
VIRAL_INFORMATION_NE_HOST_EXECUTION=YES
```

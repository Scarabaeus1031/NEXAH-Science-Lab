## Implemented core observed

The HTML sources establish that the folder contains more than presentation
material:

- `udf_player.html`: browser player for a JSON-defined visual/audio object;
- `udf_player_multi.html`: local file loading, deterministic seed mode, 2D
  rendering and Web Audio;
- `udf_player_pro.html`: JSON loading, 2D and Three.js-based 3D rendering, and
  UDF export controls;
- `udf_player_rules_animated.html`: embedded rule example with animated canvas
  and Web Audio;
- three `.udf.json` examples;
- one NXA-axis JSON and one SCARAB-field JSON.

These are prototypes. The intake found no standalone `.xva`, `.scrb`, `.nxa`
or `.scarab` binary/container implementation in this source root, no frozen
cross-format schema, no general converter and no efficiency benchmark.

## Historical claim boundary

The Fact Sheet describes an all-in-one generative audiovisual format and the
planning documents propose new NXA, SCARAB, XVA, UDF and `.q` roles. This
intake preserves those statements as historical design intent. It does not
adopt uniqueness, universality, storage-efficiency, scientific, physical or
commercial-readiness claims.

The durable Builder finding is narrower:

> The folder contains working browser prototypes for declarative,
> seed-addressable experience generation and an early attempt to separate
> content records, rendering rules, metadata, states and control-plane
> addressing.

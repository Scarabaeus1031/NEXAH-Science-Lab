# PTF-01 Scope and Non-Overlap

## Purpose

PTF-01 binds four existing strands without identifying them:

1. the exact `111 x 111` Janus fallback carrier and quotient from JGQ-01;
2. the `12321` owner-declared coupling-key package;
3. line, circle and oval as explicitly defined representations; and
4. Translation Fidelity as an audit of retention, loss and recoverability.

The proposed contribution is a transparent teaching and conformance fixture.
It is not a new theorem, a new Translation Fidelity research claim or evidence
for a physical interpretation.

## The bounded connection

PTF-01 asserts only a shared audit pattern:

```text
source state
  -> declared transformation
  -> quotient / collision
  -> representation
  -> retained and lost relations
  -> keyed return where permitted
```

It does not assert that palindrome arithmetic, CRT, QRT, the 8-state cube,
historical staircases or any physical system are identical to the Janus grid.

## Exact meaning of `3+1`

For this fixture only:

- `3` means three encodings of the same quotient-orbit identifier;
- `+1` means a binder carrying provenance, the declared operator and inverse,
  and the side label needed for exact source reconstruction.

The binder is operational information, not a fourth visual view. A different
historical `3+1` use remains a different object until an explicit map is
provided.

## Exact meaning of the staircase

The PTF-01 staircase is an ordered information path:

```text
S0  full oriented state in X_n
S1  Janus orbit under J_n
S2  quotient record Q_n with side removed
S3  one of three declared view encodings
+1  binder/return channel carrying the missing side and inverse contract
```

This staircase is a documentation and test order. It is not a temporal,
causal or physical transition law.

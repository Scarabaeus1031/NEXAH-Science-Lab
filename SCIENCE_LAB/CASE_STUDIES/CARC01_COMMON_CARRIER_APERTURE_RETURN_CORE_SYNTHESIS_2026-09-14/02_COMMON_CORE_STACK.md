# Common core stack

## The synthesis

The visuals become coherent when four different layers are no longer asked to do the same job.

| Layer | Owns | Does not own |
|---|---|---|
| OLS semantic layer | meaning of OBSERVE, REPRESENT, COMPARE, SELECT, TRANSFORM and VALIDATE; declarations, profile activation and failure states | storage schema, pixel colors, domain equations or runtime success |
| CRIC execution-record layer | carrier, view/aperture, address map, Q/T/R operators, observations, reconstruction, residual, ILAU decision and execution receipt | universal theory, Human authority or arbitrary spatial trace semantics |
| NRRC complete-trace layer | optional complete `Trace → ILAUAudit → Residual → ReturnTest` record with frame, provenance and claim ceiling | automatic applicability to every carrier; a new OLS profile; production adoption |
| cartographic/display layer | Neon, glyph, layer and color encoding; THE EYE presentation | ontology, semantic status, comparison criteria or scientific authority |

## The common record path

```text
CarrierState
  ├─ Frame
  ├─ View / Aperture
  └─ Persistent Address Map
          ↓
       Q / CUT
          ↓
       T / TRANSFORM
          ↓
       R / RECONSTRUCT OR RETURN
          ↓
       Observation(s)
          ↓
       Typed Residual(s)
          ↓
       ILAU Audit
          ↓
       Bounded Decision + Receipt
          ↓
       THE EYE projection for Human review
```

## Where the matrices belong

- A grid or matrix is a declared frame/address system, not the carrier itself.
- A layer is a view, representation or sampling stratum, not automatically a new state.
- An aperture is a selection boundary operating within a declared frame.
- A slice is an aperture plus its orientation, scale, index domain and loss policy.
- A color is cartographic metadata. ILAU status must remain separately encoded.
- `Q°` may name an orientation parameter only after its frame, unit, sign convention and operator role are declared. It is not yet a shared primitive merely because several visuals place it on an axis.
- A Prime is useful as an exact node/address value in one profile; this does not make primality the ontology of every node.

## Why the earlier material felt like loose ends

The corpus contains many strong local plates but often omits at least one of these bindings:

1. stable carrier/state identity;
2. frame and aperture identity;
3. persistent address across views;
4. exact operator contract;
5. representation map and loss policy;
6. residual metric and tolerance;
7. ILAU universe/criteria;
8. return route and receipt;
9. provenance and claim ceiling.

The repeated shapes and colors were therefore visually related before they were contractually composable. CARC-01 names the common spine without declaring the domains identical.

# Final GAVP-01 Decision

Existing AREV-01, OSR-01 and ETRI-01 types are sufficient and materially useful for every tested change. A reflection re-embeds the same graph. Adding `H/PH` produces a new registered graph. The resulting angle partition is a derived relation, not the augmentation operation itself. Observation, measurement, readout and view remain a separate provenance chain.

The strongest control is order dependence. Abstract augmentation can be embedded before or after structural registration only under a compatible embedding extension. The perpendicular-foot augmentation is geometry-dependent and requires an embedding and Euclidean metric first. Transform and view operations commute only for an explicitly equivariant view rule. Operation order therefore cannot be erased.

No new primitive is required. Operation rule, application event, result object and ordered provenance already express the necessary distinctions. `G+` is acceptable only as a locally defined augmented-graph alias; `G°` adds no formal value, `D` remains underdefined, and the existing source-typed `View` is sufficient.

# NEXAH Shadow-Lens Test 01

## Result

The shadow does not change the graph. It changes the **perceived object**: depth direction, junction emphasis, visual occupancy and the suggestion of motion.

## Controlled variables

- Fixed: node coordinates, edge topology, line widths, colors and frame.
- Varied: shadow offset, blur radius and opacity only.
- Not tested: human participants, historical claims, physical motion or a new mathematical relation.

## Findings

1. **Geometry retained:** every version uses the identical graph layer.
2. **Hard offset:** creates a raised-wire or cut-out effect because the duplicate contour is spatially separable.
3. **Soft offset:** produces the strongest “living” impression: blur expands the occupied field while displacement supplies a depth direction.
4. **Centered glow:** increases importance/salience but supplies little directional depth.
5. **Long shadow:** makes the static graph feel displaced or in motion, although no node moved.
6. **Junction amplification:** several shadow fields overlap at the central node, darkening it more than ordinary edge sections. The center therefore appears active.

## NEXAH classification

| Layer | Classification |
|---|---|
| Carrier | Fixed graph raster |
| Transformation | Blur + opacity + translation |
| Retained (I) | Node positions, edge connections, color identity |
| Added (A) | Shadow pixels, apparent elevation, directional cue |
| Lost (L) | None in the source graph; local contrast may be obscured |
| Unresolved (U) | Strength of the effect for independent observers |
| Decision | HOLD on perceptual/general claims; PASS on deterministic rendering mechanism |

## Bottom line

The image “lives” in a precise but limited sense: a static second carrier—the shadow—is derived from the first, transformed and displaced. The visual system interprets the gap between carrier and shadow as depth, and overlapping shadows as local intensity. This is a real rendering mechanism, not evidence that the underlying graph itself moves or contains a new physical law.

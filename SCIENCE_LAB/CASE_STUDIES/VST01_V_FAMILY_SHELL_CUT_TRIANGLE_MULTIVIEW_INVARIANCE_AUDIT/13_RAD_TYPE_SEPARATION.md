# RAD Type Separation

| Token/type | Meaning |
|---|---|
| `RAD_wheel` | a wheel/gear word or object only when registered mechanically |
| `RAD_radial` | relation aligned with or measured from a center/radius |
| `rad_radian` | dimensionless angular-measure unit defined by arc length over radius |
| `R_radius` | positive radius parameter in registered circle geometry |

These roles are distinct:

- `RAD_WHEEL_EQUALS_RADIAL=NO`
- `RADIAL_EQUALS_RADIAN=NO`
- `RADIUS_EQUALS_RETURN=NO`

The relation `theta=arc_length/R` is used only for an actual circle arc and declared radius. Shared spelling provides no mathematical relation.

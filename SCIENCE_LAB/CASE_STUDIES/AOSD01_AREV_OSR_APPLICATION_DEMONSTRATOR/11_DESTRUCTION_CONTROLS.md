# Destruction Controls

| Collapse | Result |
|---|---|
| state = view | rejected |
| graph = embedding | rejected |
| embedding = angle | rejected |
| angle = readout | rejected |
| observable = measurement event | rejected |
| measurement event = value | rejected |
| value = readout | rejected |
| readout = view | rejected |
| display = source | rejected |
| ratio = state | rejected |
| ratio = geometry | rejected |
| same readout = same state | rejected |
| same view = same source | rejected |
| mnemonic = object | rejected |
| geometry = measurement | rejected |

All four cases remain valid when case names, node labels, sensor names, carrier elements and mnemonic labels are replaced by neutral IDs. Only explicit typed relations carry the result.

`DESTRUCTION_CONTROLS=15_OF_15_COLLAPSES_REJECTED`

`NEUTRAL_RELABEL_SURVIVES=YES_ALL_FOUR_CASES`

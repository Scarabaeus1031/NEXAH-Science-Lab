## Closed result

The combined AREV-01 and OSR-01 grammar applies without a new primitive type to exactly four bounded cases:

1. the same graph under two embeddings;
2. automotive speed/rpm measurement;
3. partition selection and ratio display;
4. a calendar knuckle mnemonic.

The cases remain different. The grammar succeeds because graph, embedding, observable, event, value, readout and view retain distinct identities and provenance.

`ViewSource` must identify `EmbeddingSource`, `MeasurementSource` or `CompositeSource`. Equal views or displayed numbers do not identify equal sources.

This package is a local application/interface demonstration. It creates no implementation, product, operator, ontology, discovery or activation.

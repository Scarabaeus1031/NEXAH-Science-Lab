# QRO-01 — AHCE Cross-check

| Distinction | QR result |
|---|---|
| CARRIER != INFORMATION | Print/file bears the representation; payload is decoded content. |
| INFORMATION != AGENT | Text/bytes do not acquire agency. |
| INFORMATION != EXECUTION | Decoded content may remain inert. |
| DECODER != PAYLOAD | Decoder is a technical process/artifact; payload is its output. |
| EXECUTION_ENVIRONMENT != PAYLOAD | Runtime/hardware is not decoded content. |
| EXECUTION_ENVIRONMENT != EXECUTION | An available runtime does not attest an event. |
| RESULT != TRACE | A payload/result can be present without a complete process trace. |

Mapping a biological `HOST` directly to a computer/runtime is rejected. At most, both are **ANALOGICALLY_COMPATIBLE_ONLY** as typed interaction contexts; their mechanisms and requirements differ materially.

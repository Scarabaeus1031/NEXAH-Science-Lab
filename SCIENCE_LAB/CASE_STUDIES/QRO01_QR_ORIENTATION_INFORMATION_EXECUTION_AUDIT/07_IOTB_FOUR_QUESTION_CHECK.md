# QRO-01 — IOTB Four-Question Check

| Question | Independently answerable? | QR record |
|---|---|---|
| WHAT IS IT? | YES | A particular print/file/captured image/decoded payload, each with distinct ID/type. |
| HOW IS IT ORIENTED? | YES | Presentation pose plus recovered canonical sampling frame. |
| WHAT HAPPENED TO IT? | YES | Capture, location, normalization, sampling, correction, decoding, interpretation and optional execution events. |
| WHERE DID IT COME FROM? | YES | Carrier provenance, file/print origin, capture source and transformation derivation. |

```text
SAME DECODED PAYLOAD != SAME QR INSTANCE
SAME DECODED PAYLOAD != SAME ORIENTATION
SAME DECODED PAYLOAD != SAME PROCESSING TRACE
SAME DECODED PAYLOAD != SAME PROVENANCE
RECONSTRUCTABLE != ATTESTED
```

`IOTB_FOUR_QUESTION_MODEL_SURVIVES=YES`

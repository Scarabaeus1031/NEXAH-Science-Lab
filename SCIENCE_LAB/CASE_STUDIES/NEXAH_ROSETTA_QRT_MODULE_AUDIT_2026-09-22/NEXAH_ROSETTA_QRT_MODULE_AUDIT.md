## Canonical operator boundary

The Core glossary supplies the controlling admission rule:

```text
An operator requires declared input, output, parameters, edge cases and
composition. A visual arrow, verb or resemblance is not an operator.
```

The Core concept registry gives `Aperture` and `Boundary` stable vocabulary
identities. It does not define `Cut`, `Flip`, `Return`, `Inverse`, `QRT`, `QRR`,
`NTO` or `TNO` as controlled executable operators. Those labels gain meaning
only in narrower, explicitly cited packages.

### Bounded procedure.QRT

The received seven-position demonstrator binds:

```text
X = [A B C D E F X]
Q = declare the D4 hinge/cut
T = reverse the declared right suffix
R = apply the inverse and align persistent addresses
Delta = compare X-prime with X
```

In that fixture, the suffix reversal is an involution and `Delta=0`. The later
prime-ring transfer test reuses the same grammar on 50 addressed records and
has a mismatch count of zero. This establishes a bounded test grammar, not a
universal QRT operator, ring geometry or biological mechanism.

`record.QRT=(quadrant, relation, time)` is a different local record. `QRTp` is
a separate noncanonical typed interface; `QRTP` is its legacy filename alias;
`QRPT` is deprecated/unbound; `QRTZ` remains a document/visual-family label.

### AXIS08-QRR-01

For `x=(x1,...,x8)` and `s=w7+w8 != 0`, the tested package defines:

```text
q78   = (w7*x7 + w8*x8) / s
delta = x7 - x8
Qw(x) = (x1,...,x6,q78)
Rw(x) = delta

x7 = q78 + (w8/s)*delta
x8 = q78 - (w7/s)*delta
```

`(Qw,Rw)` is invertible; `Qw` alone has a one-dimensional kernel. The residual
is an explicit loss certificate. This is standard linear algebra tested within
the declared AXIS08/IEEE representation-fidelity scope. It is neither
`procedure.QRT` nor a Rosetta Aperture topology.

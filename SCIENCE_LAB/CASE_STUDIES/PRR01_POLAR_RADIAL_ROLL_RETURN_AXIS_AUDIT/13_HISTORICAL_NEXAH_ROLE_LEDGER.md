# 13 — Historical NEXAH Role Ledger

This ledger classifies every requested term family found in the bounded search scope. A family can have multiple statuses because occurrences differ; no occurrence is promoted merely by sharing a word.

| term family | recoverable use | classification | boundary |
|---|---|---|---|
| STICK | pillar/axis/connector and historical visual name | VISUAL_REPRESENTATION / UNDERDEFINED | not `j`, shaft, or motion |
| AXIS | coordinate/reference/rotation axes and visual axes | STANDARD_MATH where defined; VISUAL_REPRESENTATION otherwise | not object/shaft/event |
| POLE | geometric/reference pole or visual endpoint | STANDARD_MATH / WORKING_NOTATION | context required |
| `R` | radius in EMP-03; overloaded elsewhere | STANDARD_MATH in registered formulas; UNDERDEFINED otherwise | not intrinsically Return |
| `2R` | diameter in circle geometry | STANDARD_MATH / GEOMETRIC_SHORTHAND | not two operators |
| RAD / RADIAL | radial coordinate/direction or historical label | STANDARD_MATH when typed; WORKING_NOTATION/EXPRESSION otherwise | not rotation |
| ROLL | rolling/phase/visual rope language | STANDARD_MECHANICS only with contact model; UNDERDEFINED otherwise | not radial/transport identity |
| FORWARD | path/body/transmission-relative direction | STANDARD_MECHANICS / WORKING_NOTATION | frame dependent |
| BACKWARD / REVERSE | opposite declared machine/path state | STANDARD_MECHANICS / WORKING_NOTATION | not inward by definition |
| RETURN | EMP-03 involution and broader historical labels | IMPLEMENTED_OBJECT/RECORDED_RELATION for `J_R`; CONTEXT_DEPENDENT otherwise | not universal inverse/history erasure |
| COUPLING | phase/geometric/historical relation; mechanical foreign control | UNDERDEFINED or WORKING_NOTATION locally; STANDARD_MECHANICS in foreign control | not identity/shaft |
| SHAFT | no matching local source occurrence in bounded search | NOT_FOUND_LOCALLY; STANDARD_MECHANICS foreign control | not backfilled |
| CARDAN / KARDAN | no matching local source occurrence in bounded search | NOT_FOUND_LOCALLY; STANDARD_MECHANICS foreign control | no K semantics |
| WHEEL | diagrams/vehicle examples/historical wheel labels | VISUAL_REPRESENTATION or STANDARD_MECHANICS by context | count not dimension |
| DRIVE | machine/visual language | WORKING_NOTATION / UNDERDEFINED | not an operator by word |
| CONTACT | EMP/tangent or mechanical contact role | STANDARD_MATH / STANDARD_MECHANICS when defined | not transport |
| TRANSPORT | historical explanatory claim or standard movement process | UNDERDEFINED historically; STANDARD_MECHANICS only with mechanism | no universal operator |
| PRP | acronym/return-family references without one recovered canonical expansion | UNDERDEFINED | no backfill |
| POLAR / POLARPASS | polar geometry and archived suite name | STANDARD_MATH plus ARCHIVED_EVIDENCE/WORKING_NOTATION | suite claims not adopted |

The only locally recovered, source-bound Return formula is EMP-03’s `J_R(d)=R²/d`. Historical images and broad PolarPass claims retain their prior evidence classifications.

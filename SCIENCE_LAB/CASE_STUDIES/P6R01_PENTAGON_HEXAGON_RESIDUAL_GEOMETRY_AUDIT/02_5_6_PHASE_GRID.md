# 5/6 Phase Grid

The following arithmetic is definition-independent:

- pentagon central step: `360/5 = 72 degrees`;
- sixfold central step: `360/6 = 60 degrees`;
- difference of those step sizes: `12 degrees`;
- `lcm(5,6)=30`;
- `360/30=12 degrees`.

Thus `theta_k=12 degrees*k`, `k=0,...,29`, is a common sampling grid.

This does not establish:

- a physical motion;
- thirty distinct configurations;
- a common `D30` symmetry;
- any special significance of 5, 6, 7, 12, or 30.

Without a defined `H`, the grid does not produce overlap regions.

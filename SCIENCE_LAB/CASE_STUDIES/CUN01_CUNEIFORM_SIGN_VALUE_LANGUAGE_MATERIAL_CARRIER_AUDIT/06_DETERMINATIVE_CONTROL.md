# 06 — Determinative Control

Oracc defines Akkadian determinatives as specifying the semantic set to which a noun belongs. CDLI describes determinatives as unpronounced logograms that help select among values. DCCLT's bounded example explains that the IB sign used for the divine name Urash is preceded by the determinative for gods; the Met exercise identifies the first sign as indicating a divine being.

## Finding

```text
DETERMINATIVE_FUNCTION_SUPPORTED=YES
DETERMINATIVE_FUNCTION_EQUALS_SOUND=NO
DETERMINATIVE_FUNCTION_EQUALS_LEXICAL_MEANING=NO
DETERMINATIVE_REDUCES_READING_AMBIGUITY=YES_CONTEXT_DEPENDENT
```

A determinative contributes classification/context in the attested occurrence. It need not be pronounced as an ordinary syllable and is not identical to the lexical meaning of the following name. This is a writing-system relation, not an automatic mapping to `GATE`, `FILTER`, orientation operators or ORION.

# 07 — Lexical List / Scribal Learning Control

DCCLT documents sign lists and word lists as long-lived scribal teaching and scholarly reference practices. Its sign-list schema distinguishes:

- pronunciation gloss;
- sign form;
- sign name;
- Sumerian lemma/word;
- Akkadian translation.

The Old Babylonian curriculum trained sign execution, syllabic values and vocabulary. Later bilingual lists placed Akkadian translations beside Sumerian entries. This is documented meta-representation practice, without claiming that ancient scribes held modern linguistic theory.

```text
DOCUMENTED_META_REPRESENTATION_PRACTICE=YES
SIGN_EQUALS_VALUE=NO
VALUE_EQUALS_WORD=NO
WORD_EQUALS_TRANSLATION=NO
```

## Human syllable hypothesis

DCCLT supports syllabic sign values and documented polyvalence. It also gives one bounded first-millennium scholarly example: names of Marduk were segmented and their syllables treated as Sumerian words for Akkadian explication. This supports the existence of a hermeneutic technique in specified scholarly texts, not a general Babylonian worldview.

```text
ANCIENT_SYLLABLE_USE=SUPPORTED
ANCIENT_POLYVALENCE=SUPPORTED
ANCIENT_HERMENEUTIC_WORDPLAY=SUPPORTED
```

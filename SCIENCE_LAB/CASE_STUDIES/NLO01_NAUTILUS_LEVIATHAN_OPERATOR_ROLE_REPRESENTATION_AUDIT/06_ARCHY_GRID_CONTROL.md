# Archy / Grid Control

No standalone `ARCHY` label is visibly attested. `TERRA ARCHIVA` is a different phrase and was not normalized to Archy.

VIS-07 is a node-and-line concept map, and other boards contain grids, crossings, folds, fields, and network prose. None defines a graph `G=(V,E)` with an explicit node set, edge set, adjacency, weights, directions, paths, or update rule.

Thus visual relational structure is recoverable, but not a formal graph model.

- `GRID != PATH`
- `GRAPH != TRAJECTORY`
- `EDGE != CONSTRAINT`
- `NETWORK != WEB_METAPHOR`
- `CROSSING != ESCAPE`
- `NAVIGATION != FREE_MOTION`

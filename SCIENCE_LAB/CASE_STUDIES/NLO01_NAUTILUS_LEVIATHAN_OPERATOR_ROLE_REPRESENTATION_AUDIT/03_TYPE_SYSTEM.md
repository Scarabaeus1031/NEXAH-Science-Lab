# Type System

The audit preserves:

`SYMBOL != FORM != ROLE != OPERATOR != EXECUTION != TRANSFORMATION != CARRIER != MEDIUM != PATH != FIELD != RESULT != INTERPRETATION`

| Type | Minimum bounded meaning |
|---|---|
| `SYMBOL` | documentary mark or label |
| `FORM` | recoverable visual/geometric morphology |
| `ROLE` | contextual function assigned within a model or board |
| `OPERATOR` | typed mapping with domain, codomain, rule, invariants/changes, and failure condition |
| `EXECUTION` | event applying a rule to an input |
| `TRANSFORMATION` | specified change relation |
| `CARRIER` | object/system that bears or transports something under a model |
| `MEDIUM` | environment in which interaction/motion occurs |
| `PATH` | ordered geometric route |
| `FIELD` | quantity assigned over a domain |
| `RESULT` | output/outcome of an execution |
| `INTERPRETATION` | contextual reading not identical to object or rule |

The images support `SYMBOL`, `FORM`, and documentary `ROLE` assignments. They do not support promotion to `OPERATOR`, `EXECUTION`, or a reproducible `TRANSFORMATION`.

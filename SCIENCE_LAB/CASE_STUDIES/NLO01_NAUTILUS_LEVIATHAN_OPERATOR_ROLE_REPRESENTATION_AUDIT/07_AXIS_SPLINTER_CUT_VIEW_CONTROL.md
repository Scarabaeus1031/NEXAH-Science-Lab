# Axis / Splinter / Cut / View Control

The corpus visibly contains axes, spines, folds, fields, triangular forms, panels, radial lines, and map-like views. It does not materially attest the full transformation chain:

`FIELD -> SELECTION -> CUT -> PROJECTION -> VIEW`.

Individual arrows and captions document intended transitions but lack typed transformation rules, source/target objects, executions, or traces.

Preserved boundaries:

- `AXIS != CUT`
- `CUT != PROJECTION`
- `PROJECTION != SHADOW`
- `SHADOW != OBJECT`
- `VIEW != DIMENSION`
- `TRIANGLE != PYRAMID`
- `2D_DEPICTION != 3D_OBJECT`
- `MULTIPLE_VIEWS != HIGHER_DIMENSIONAL_STATE`

`SPLINTER` is not visibly attested as a label; pointed shapes are insufficient to infer vector or operation.

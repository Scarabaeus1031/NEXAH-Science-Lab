# A0-BL-047 — Double-Pentagon `4+1 -> two 5+1` split

Status: `CLOSED / OWNER_ACCEPTED_TYPED_EXTENSION_FAMILY_WITH_NONCANONICAL_PAIRING`

This package formalizes the proposal as a family of typed edge subdivisions:
four zone nodes plus one seam/binder form a labelled C5; each `+1` branch
subdivides one declared edge to make C6. It enumerates every selector rather
than choosing a visually attractive alignment.

All eight gates pass with lock `10/10`, byte-identical Primary/Replay and both
verifiers `15/15`. The extension family and exact contraction Return pass; the
cross-correspondence remains noncanonical without a separately sourced edge
orientation. See `02_RESULT_ASSESSMENT.md` and `RUN_CONTRACT.md`.

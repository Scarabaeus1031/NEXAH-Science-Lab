# I–L–A–U Ledger

## I — retained

- Explicit graph nodes, edges, P/S/R roles and branch identities.
- Frozen coordinates, dimensions, transforms, score components and thresholds.
- Incidence, cycle rank, oriented area, winding, separation and normalized return distance.
- Deterministic random controls, 1,000-trial counts and exact replay hashes.
- Separation of data, image and normalized-local coordinates.

## L — lost

- Historical generation intent and absent source code for historical visuals.
- Continuous intermediate states and undocumented marker-selection decisions.
- Semantic meaning when a drawing is reduced to an abstract point/edge graph.
- Metric information under arbitrary projective or raw image-coordinate reuse unless the transform is retained.

## A — introduced

- The synthetic graph family and the exact D coordinates.
- Five equal Grammar Score components and the 0.80 gate.
- Raster resolutions, noise, closure-gap tolerance and P-shift schedule.
- Random generators, seed, graph densities and post-hoc assignment search.
- The abstraction that visible strokes may be treated as graph incidence at all.

## U — unresolved

- Historical origin of any point–split–return appearance.
- Whether a historical author intended P, S, C or R as formal roles.
- External usefulness of the grammar.
- Any relationship to “Elevator”, “Needle Cushion”, Crown, 5→7, 6+1, Q-Split or Return terminology.
- Every physical, astronomical, chemical, biological, cryptographic or other cross-domain interpretation.

## Operator residues

- `5→7` is retained only as a declared operator adding branches `new_1` and `new_2`; it is not a release law.
- `6+1` is retained only as a branch-count change. Its seventh branch fails the Return component.
- P carries coordinate, node, stem and pivot identity only.
- Correct image→data inversion reproduces the data-space classification. Raw anisotropic image coordinates flip orientation and rescale area but did not create the primary failure; the decisive failure is post-hoc nonselectivity.

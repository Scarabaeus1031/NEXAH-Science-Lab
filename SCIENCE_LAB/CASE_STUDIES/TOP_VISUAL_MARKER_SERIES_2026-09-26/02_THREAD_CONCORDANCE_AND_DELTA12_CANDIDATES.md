## The exact Delta12 object

The registered interaction contrast is

```text
Delta_12 R
  = R(B1+B2) - R(B1) - R(B2) + R(0).
```

It asks whether the joint effect of two declared changes differs from the sum
of their separate effects. It is therefore stricter than a general residual,
disagreement, overlap or difference between two perspectives.

A candidate is admissible only when all four states use the same readout and
are comparable under one declared composition rule. If the interventions alter
the meaning of the readout, the four-state contrast is not identified.

## Candidate matrix

### C1 — Frame transformation x lossy time-only projection

```text
B1 = change coordinate frame
B2 = discard spatial coordinates and retain a time-only record
R  = prediction or reconstruction error for the same declared event pair P,Q
```

This is a clean synthetic benchmark because the underlying relativistic result
is already known. A nonzero `Delta_12` would describe the joint bookkeeping
cost of frame change and projection, not a new time effect. The candidate can
test whether TOP exposes a loss that ordinary full-frame treatment already
avoids.

**Classification:** `FORMULATABLE_BENCHMARK / LOW_DISCOVERY_VALUE`

### C2 — Source/context omission x counterrecord/condition omission

```text
B1 = remove source, mandate, time window or causal context
B2 = remove counterevidence, uncertainty or recommendation conditions
R  = false-closure, causal-overreach or decision-error score
```

This is the strongest practical utility candidate in the thread. It tests
whether two individually bounded omissions interact to create a conclusion
that neither omission creates alone. It can be instantiated with frozen,
copyright-safe historical press or advisory packets and compared with strong
journalistic or advisory practice.

**Classification:** `HIGH_PRACTICAL_RELEVANCE / PARKED_PENDING_NEW_FREEZE`

### C3 — Glyph reuse x namespace loss

```text
B1 = reuse a glyph across two domains
B2 = remove namespace or type metadata
R  = symbol-resolution, inverse-record or handoff error
```

Examples include `K` as kaon versus `kappa` as a model channel and `tau` as a
particle versus proper time. ORI-02 already provides the closest internal
precedent. A new execution would need to show value beyond a strong typed
baseline.

**Classification:** `FORMULATABLE_CONTROL / EXISTING_PRECEDENT / LOW_PRIORITY`

### C4 — Hidden physical channel x observation restriction

```text
B1 = include or exclude a specified invisible channel in the physical model
B2 = include or exclude a specified detector or reconstruction restriction
R  = conservation residual, parameter bias or event-classification error
```

This could be meaningful for a named decay or scattering process. Generic
language about an electron emerging from neutrino interaction is insufficient:
the interaction, initial state, final state, detector response and conservation
rules must be fixed first.

**Classification:** `DOMAIN_RELEVANT / NOT_YET_IDENTIFIED`

## What does not yet qualify

- backflow, Ghost Grid or residual as presumed physical entities;
- Matryoshka, Möbius, prime, `pi`, `phi`, `sqrt(2)` or Kappa symbol chains;
- dark matter, dark energy, proton, neutron and electron correspondences;
- any visual overlap whose four comparable records and readout are absent.

These may generate questions, but visual similarity is not an interaction
measurement.

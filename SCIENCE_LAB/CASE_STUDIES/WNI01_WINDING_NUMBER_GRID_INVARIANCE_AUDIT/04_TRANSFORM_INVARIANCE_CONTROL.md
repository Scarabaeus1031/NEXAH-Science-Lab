# Transform invariance control

Curve and reference were transformed consistently. Results cover C0–C5; C6 remains invalid.

| Transform | Rule | Observed result |
|---|---|---|
| Identity | (C'=C,p'=p) | All expected values recovered |
| Translation | (C'=C+a,p'=p+a), (a=2-0.7i) | W preserved for C0–C5 |
| Rotation | (C'=e^{0.73i}C,p'=e^{0.73i}p) | W preserved for C0–C5 |
| Positive scale | (C'=2.3C,p'=2.3p) | W preserved for C0–C5 |
| Reflection | (C'=\bar C,p'=\bar p) | Signed W reversed: +1↔-1, +2→-2, 0→0 |

Translation, rotation, and positive scaling are orientation-preserving homeomorphisms here. Reflection is orientation-reversing. It preserves (|W|) while reversing sign.

C4 confirms that the rule is not limited to simple circles. C5 confirms it with a reference close to the curve. No visual resemblance criterion was used.

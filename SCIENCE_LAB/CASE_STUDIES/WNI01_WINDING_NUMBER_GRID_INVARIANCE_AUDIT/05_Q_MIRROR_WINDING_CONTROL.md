# Q-Mirror winding control

The frozen historical map is

    Q(z) = 1/z, for z ≠ 0.

It is holomorphic and locally orientation-preserving on ℂ excluding {0}; it is not a planar reflection. Polar coordinates satisfy r → 1/r and θ → -θ, but those coordinate changes do not establish a generic reflection rule.

## Exact rules

For comparison about 0, when C avoids 0:

    W(Q∘C, 0) = -W(C,0).

For finite p ≠ 0, when C avoids both 0 and p, with p_prime = Q(p):

    W(Q∘C, Q(p)) = W(C,p) - W(C,0),

because Q(z)-Q(p) = -(z-p)/(zp).

## Controls

- C0: +1 about 0 becomes -1 about 0.
- C1: -1 becomes +1.
- C2: +2 becomes -2.
- C3: 0 remains 0.
- Unit circle with p=0.4: W(C,p)=1, W(C,0)=1, and W(QC,Qp)=0, exactly the difference rule.
- C4 passes through the Q singularity 0; its Q-image is UNDEFINED.
- If p=0, Q(p)=∞; the same finite transformed reference is unavailable. Comparing the image about 0 is a different declared observable.

Thus the Q rule is recovered precisely and reference-dependently; no unconditional W → -W rule is asserted.

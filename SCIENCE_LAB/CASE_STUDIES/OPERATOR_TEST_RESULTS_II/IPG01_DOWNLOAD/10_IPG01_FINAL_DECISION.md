## Primary result

**A_IDENTITY_PROVENANCE_GENERATION_FORM_DISTINCT_FORMAL_LAYERS**

The synthetic model successfully separates object identity, specification,
class membership, bounded equivalence, similarity, provenance and generation.
I1, I2 and I3 are “the same model” only in the precise sense of shared
specification/class; they remain distinct concrete objects. I5 proves that
identical observable fields do not establish common provenance.

The decisive controls pass: time order without derivation produces no
generation, while an explicit COPY edge creates a new generation without any
visible field change.

## Plain-language answer

“Same design,” “same class,” “looks similar,” “comes from the same source” and
“is the same object” are genuinely different statements. Generation is not an
appearance or an order number; it is a position in an attested derivation graph.

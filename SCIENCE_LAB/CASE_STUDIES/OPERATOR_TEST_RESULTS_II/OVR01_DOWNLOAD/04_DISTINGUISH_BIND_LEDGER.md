# OVR-01 — Differentiate / Bind Ledger

`BREAK` is not added: the frozen survivor set contains no adequately defined operator of that name.

| Effect on distinguishability | Retained terms | Bounded reading |
|---|---|---|
| Increase | BRANCH, COPY | Only when outputs/new instances remain separately addressable and provenance is declared. |
| Preserve/reorient | REFLECT, ROTATE, TRANSLATE, SCALE | Usually preserve carrier cardinality; observation may still alias. |
| Reduce | PROJECT, OBSERVE | May be many-to-one and lose state/orientation information. |
| Bind/relate | BIND, CONVERGE | Make relations/targets addressable; may reduce distinctions if sources are not traced. |
| Context-dependent | TRANSFORM, REPEAT, NORMALIZE, CORRECT | Effect follows the concrete map and record policy. |

`LESS SYMMETRY ⇒ MORE ORIENTATION INFORMATION` is not generalized beyond ASY-01's bounded model.

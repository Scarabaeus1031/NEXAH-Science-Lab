# 02 — Base Symmetry Report

The centered unit disk is invariant under every planar rotation about its
center. Its rotational symmetry group is `SO(2)` (or `O(2)` if reflections are
also included). Therefore all four registered rotations produce the same static
set:

```text
R_0(S0)=R_90(S0)=R_180(S0)=R_270(S0)=S0.
```

No registered orientation can be recovered from S0 alone.

```text
BASE_OBJECT=UNIT_DISK_CENTERED_AT_ORIGIN
BASE_ROTATIONAL_SYMMETRY=SO2_CONTINUOUS
S0_ORIENTATION_IDENTIFIABLE=NO
```

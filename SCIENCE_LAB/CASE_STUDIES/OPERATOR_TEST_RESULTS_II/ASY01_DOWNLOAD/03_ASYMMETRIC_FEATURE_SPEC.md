# 03 — Asymmetric Feature Specification

Feature B is geometry only:

```text
attachment angle = 0 degrees
radial interval  = [1.00,1.25]
tangential width = 0.12
feature axis     = outward radius
```

The union S1 has no non-identity rotational symmetry: any nonzero rotation
moves the unique protrusion to a different boundary location. Its rotational
symmetry group is therefore the trivial group `C1`.

Replacing label B by neutral F leaves every set, symmetry and measurement
unchanged: `BEAK_SEMANTIC_DELTA=NONE`.

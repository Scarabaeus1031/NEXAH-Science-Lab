# 11 — ASY-01 Final Decision

## Primary result

**A_ASYMMETRY_SUPPORTS_ORIENTATION_NOT_MOTION**

The unique protrusion reduces rotational symmetry from continuous `SO(2)` to
trivial `C1`, allowing every registered rotation of S1 to be recovered. Removing
the feature reverses the effect; duplicating it opposite the first restores
`C2` symmetry and leaves orientation identifiable only modulo 180°.

The static asymmetric object is the decisive counterexample to any motion
claim: it has identifiable orientation and zero velocity. Motion appears only
after application of a separately defined dynamic operator.

## Plain-language answer

A small asymmetric feature can tell an observer how a static object is oriented.
It cannot tell the observer that the object is moving. Orientation is recoverable
geometry; motion is change generated by a dynamic operator.

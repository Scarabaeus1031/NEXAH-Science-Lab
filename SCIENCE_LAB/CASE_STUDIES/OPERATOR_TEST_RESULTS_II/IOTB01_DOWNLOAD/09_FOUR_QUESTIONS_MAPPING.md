# 09 — Four-Questions Mapping

| Question | Primary fields | Necessary boundary overlap |
|---|---|---|
| WHAT IS IT? | identity, class, specification, observable state | class may be reconstructed from state; identity requires ID |
| HOW IS IT ORIENTED? | orientation, symmetry, handedness | orientation is an observable aspect but not motion |
| WHAT HAPPENED TO IT? | operator execution and trace | endpoint state constrains but does not attest history |
| WHERE DID IT COME FROM? | provenance and generation | a derivational execution may also appear in the trace |

The mapping is defensible precisely because it is not perfectly independent.
The overlaps are typed: observation may expose orientation; a derivation may be
an executed operator; a trace may support provenance. None of these overlaps is
an identity of fields.

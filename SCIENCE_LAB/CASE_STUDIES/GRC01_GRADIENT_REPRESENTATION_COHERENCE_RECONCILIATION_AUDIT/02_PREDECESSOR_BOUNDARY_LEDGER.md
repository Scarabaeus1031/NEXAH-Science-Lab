| frozen boundary | GRC-01 application | preserved |
|---|---|---|
| `OBJECT != REPRESENTATION` | a field image is not the scalar field or system | YES |

| `CHOSEN_ORIGIN_IS_INTRINSIC=NO` | translation changes coordinates, not necessarily the modeled point | YES |
| `LOCAL_FRAME != GLOBAL_OBJECT` | a local gradient direction does not identify global geometry | YES |
| `CURVE != TANGENT` | one local derivative does not reconstruct a trajectory | YES |
| `LOCAL_STRAIGHT != GLOBAL_STRAIGHT` | local linear behavior is not a global path claim | YES |
| `FORM != VALUE` | visual form and numerical/semantic value remain distinct | YES |
| `REPRESENTATION != FUNCTION` | a plotted gate-like form does not establish gate function | YES |
| `OBSERVED_SIMILARITY != IDENTITY` | similar attractor panels do not identify dynamics | YES |
| `LOCAL_EQUALITY != GLOBAL_IDENTITY` | local alignment does not imply system equivalence | YES |
| `COUPLING != IDENTITY` | correlated quantities remain separately typed | YES |
| `RECONSTRUCTABLE_PATH != ATTESTED_PATH` | an inferred or drawn path is not a recorded execution trace | YES |
| `TRACE != ACTION` (RSC-01) | a plotted trajectory is not its generating event/process | YES |

No predecessor is edited or strengthened. GLF-01 provides the central rule: classify covariance correctly rather than demand false component invariance. SFM-01 and RSC-01 prevent image form, label, trace, process, and value from collapsing.

# 03 — Historical Pipeline Reconstruction

## Neutral typed chain

`samples {x(t_i)}` → `estimated scalar field ρ̂(x; method, parameters)` → `local derivative ∇ρ̂` → `comparison with empirical velocity or model vector field` → `declared local relation metric` → `thresholded candidate region`

This is a coherent generic schema. It is not a single proven repository pipeline.

| arrow | classification | assumptions | loss / dependence | repository status |
|---|---|---|---|---|
| samples→density estimate | A as statistical construction; B only with code/run | estimator, domain, measure, bandwidth/grid | time order commonly lost; representation and parameter dependent | not recovered for supplied visuals |
| density→gradient | A if differentiable/approximated; B in separate archive lineage | metric/coordinates, spacing, boundary scheme | scalar offset lost; discretization dependence | implemented only in separate synthetic-field lineage |
| gradient↔flow comparison | A once both vectors and metric are defined | common tangent space/frame, nonzero norms | relation summary loses vector detail | no matching historical implementation recovered |
| comparison→“coherence” | A as a declared alignment score; E as broader coherence | exact formula and edge policy | convention/metric dependent | formula not recovered for supplied visuals |
| metric→candidate region | A/B only with explicit criterion | threshold, conjunction, sampling, calibration | continuous values collapsed; sensitive to parameters | exact criterion/run not recovered |
| candidate→transition/gate | E/F without independent event definition | external labels or operational contract | interpretation exceeds threshold map | unsupported for supplied visuals; prior Gate result negative |

## Reconstruction decision

The conceptual chain is reconstructable, and selected components exist elsewhere in the repository. End-to-end historical custody is incomplete. Therefore:

`HISTORICAL_PIPELINE_RECONSTRUCTABLE=PARTIAL`

The surviving structure is standard/generic under neutral labels. No NEXAH-specific mathematical gain is established.

# Compare and Invariant Control

A comparison requires revisioned operands, compatible types/representations,
registered criterion, equality/equivalence/tolerance relation, event identity,
order and provenance.

```text
difference ≠ meaning ≠ importance ≠ error ≠ residual ≠ decision
```

For `X0` and `X1`, test separately:

| Question | Required relation |
|---|---|
| State equality | Named state fields and equality criterion |
| Representation equality | Same representation/frame and value rule |
| Measurement equality | Observable, units, uncertainty/tolerance and events |
| Equivalence | Explicit equivalence relation |
| Invariant property | Property + applicable transform/comparison |
| History equality | Ordered event/state lineage criterion |

The word “same” is invalid without:

```text
SAME WHAT?
UNDER WHICH RELATION?
IN WHICH FRAME?
AT WHICH TIME?
WITH WHICH PROVENANCE?
```

An invariant is a preserved property under a declared relation, not object
identity. A difference acquires importance only through a separate objective or
criterion.

# Observation / Evidence Control

```text
state -> observation map -> observation/measurement event
      -> measurement value -> readout -> trace/view
      -> evidence record/bundle -> claim assessment
```

Every arrow is dependency or production, not identity.

| Record | What it establishes | What it does not establish |
|---|---|---|
| Observation event | A registered procedure occurred | Explanation or truth |
| Measurement value | Event-bound typed result | Source identity or normative value |
| Readout | Display/aggregation of values | State or knowledge |
| Trace | Provenance-bearing downstream representation | Unique source/path |
| Evidence record | Material offered for a scoped claim | The claim itself or truth |

A trace becomes evidence only when an evidence record cites it for a proposition,
scope and method. The same trace may be irrelevant to another claim. Evidence
can be incomplete, conflicting or compatible with multiple explanations.

# Point / Path / Trajectory Control

A defensible trajectory record contains ordered point/state references, a
declared representation, compatible frames/coordinates, timestamps or parameter
order, interpolation status where used, and provenance.

```text
P0, P1, ..., Pn + order/time + representation + provenance -> trajectory record
P0 alone -/-> trajectory
```

| Comparison | Result |
|---|---|
| Same endpoint vs same path | Not implied |
| Same geometric path vs same timing | Not implied |
| Same timed path vs same physical cause | Not implied |
| Same final point vs same event history | Not implied |

Two sequences may both end at `(2.0, -0.5)` while traversing different points.
Two observations may traverse the same ordered coordinates at different rates.
Even equal timed coordinates can be generated by different source histories or
models. Their provenance remains distinct.

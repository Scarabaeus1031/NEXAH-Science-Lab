# Geometric Type Ledger

| Type | Bounded meaning | Not identical to |
|---|---|---|
| `VISUAL_V_SHAPE` | apparent two-arm morphology | registered ray pair |
| `COMMON_ORIGIN_RAY_PAIR` | two identified rays sharing one vertex | axis, V label |
| `AXIS` | registered reference line | ray, motion, cut |
| `RAY` | half-line from a vertex in a direction | axis in general |
| `SEGMENT` | bounded straight connection | ray, trajectory |
| `MEASURED_ANGLE` | estimated image-plane relation with method and uncertainty | invariant |
| `ANGULAR_RELATION` | comparison among admitted angles | operator |
| `ANGLE_INVARIANT` | relation satisfying all invariance criteria | repeated motif |
| `TRANSFORMATION` | specified mapping between registered objects/views | projection label |
| `OPERATOR` | typed formal mapping | visual transformation claim |

Also preserved:

- `SAME_IMAGE_MOTIF != SAME_GEOMETRIC_OBJECT`
- `SAME_GEOMETRIC_SHAPE != SAME_ANGLE`
- `SAME_ANGLE != SAME_TRANSFORMATION`
- `PROJECTION != ROTATION`
- `VIEW_CHANGE != STATE_CHANGE`

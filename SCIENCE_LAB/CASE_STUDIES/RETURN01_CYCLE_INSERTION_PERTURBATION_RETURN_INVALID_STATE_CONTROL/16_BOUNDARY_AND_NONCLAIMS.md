# Boundary and Nonclaims

RETURN-01 does not establish:

- a universal cycle or return law;
- recurrence as a physical law;
- a hidden calendar code;
- meaning for `29.02.1974` beyond invalidity under declared Gregorian rules;
- a relation between leap years and C3;
- a relation between 120°/240° and calendar dates;
- a relation between Outerborn and leap days;
- a physical wobble mechanism;
- a new theory of time, memory or causation;
- a portal, timeshift or cosmological return.

Mandatory boundary:

`SAME ABSTRACT GRAMMAR != SAME PHYSICAL MECHANISM`

Further nonclaims:

- invalid is not rare or special;
- undefined is not zero;
- return is not repeat, reset, restart, reconstruction or erasure;
- no predecessor was reopened;
- no new operator, OLS primitive, RID gap, Rust source, implementation or research activation was created;
- ORION v1 was not modified.

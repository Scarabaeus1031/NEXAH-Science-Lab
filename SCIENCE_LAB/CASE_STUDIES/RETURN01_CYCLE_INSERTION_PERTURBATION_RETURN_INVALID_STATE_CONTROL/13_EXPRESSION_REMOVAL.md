# Expression Removal

After removing stone, heart, wobble, diagonal, fall, fly, still point, thorn, Outerborn, timeshift, portal, retained rest and retained relation, the following ordinary formal objects remain:

- state space and typed state;
- transition rule and event;
- finite cycle;
- rule-governed insertion;
- perturbation record/residual;
- periodic phase and offset;
- declared return criterion;
- validation outcome and abstention;
- ordered history and provenance;
- representation map;
- bounded region and admissible crossing.

These are already expressible by frozen state, rule, event, result, trace, history, provenance, validation, ambiguity and abstention records.

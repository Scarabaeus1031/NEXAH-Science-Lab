## Reduction criterion

A candidate remains a common type only if predecessor evidence independently requires it across the documentary comparison and merging it would lose a tested distinction.

## Reduced documentary schema

```text
MARK(s) ──compose/realize──> FORM
FORM ──recognized under a system as──> UNIT
(FORM or UNIT) + REQUIRED CONTEXT ──maps to──> VALUE
```

This is shorthand for records and relations:

- not a universal law;
- not a causal model;
- not an operator;
- not a complete domain model.

## Non-core placement

- `CARRIER`: domain extension where physical support matters.
- `SIGN`: domain-specific unit identity/term, required in CUN-01 but not universally.
- `FEATURE`: grammatical/semantic domain extension; not identical to a marker.
- `INFORMATION`: broad relation-dependent description, not a precision-improving type.
- `CONTEXT`: required mapping field/constraint.
- `ATTESTATION`: evidence-layer field.
- `MEANING`: not in the ten-item start stack; remains a domain extension distinct from value.
- `VALUE_TYPE`: classification field distinguishing phonetic, numeric, name-related, orthographic or other domain values; not a separate object layer.

The bounded Croatian Glagolitic control confirms this placement: the same letter/sign identity can participate in several typed value relations without making value type identical to a concrete value.

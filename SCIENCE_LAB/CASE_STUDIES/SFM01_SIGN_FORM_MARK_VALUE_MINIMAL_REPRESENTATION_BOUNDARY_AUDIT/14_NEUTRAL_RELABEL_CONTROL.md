# 14 — Neutral Relabel Control

```text
CARRIER=A
MARK=B
FORM=C
UNIT=D
SIGN=E
VALUE=F
FEATURE=G
INFORMATION=H
CONTEXT=I
ATTESTATION=J
```

After removing all domain and project labels, the retained structure is:

```text
B(s) compose/realize C
C is recognized by a system as D
(C or D) constrained by I maps to F
J records evidence for claims about these records
```

`A`, `E` and `G` remain available as domain extensions; `H` remains a broad description rather than a core type. The reduction survives without ancient scripts, language examples, article names, `SIGN`, `FORM` or NEXAH terminology in the explanatory labels.

`NEUTRAL_RELABEL_SURVIVES=YES`

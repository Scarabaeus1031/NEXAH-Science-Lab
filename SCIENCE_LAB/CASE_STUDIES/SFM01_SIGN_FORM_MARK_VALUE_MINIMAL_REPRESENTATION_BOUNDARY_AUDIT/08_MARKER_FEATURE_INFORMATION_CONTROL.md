# 08 — Marker / Feature / Information Control

GRB-01 establishes that an overt grammatical marker is not the grammatical feature itself. A form or unit may *serve the role* of marker in a specified construction.

Therefore:

```text
MARKER_STATUS=ROLE
MARKER_EQUALS_FEATURE=NO
```

`FEATURE` remains a domain extension: definiteness is grammatical; cuneiform semantic classification and pronunciation values belong to other domain descriptions. Combining these into one permanent core feature type would lose useful distinctions.

`INFORMATION` can describe what a relation or record carries, but it does not discriminate value, feature, meaning, evidence or context.

```text
FEATURE_EQUALS_INFORMATION=TOO_BROAD
INFORMATION_STATUS=TOO_BROAD
```

No physical substance, universal information theory or new superclass is asserted.

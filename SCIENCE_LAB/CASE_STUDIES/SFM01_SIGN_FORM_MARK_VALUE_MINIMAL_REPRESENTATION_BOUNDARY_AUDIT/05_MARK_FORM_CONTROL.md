# 05 — Mark / Form Control

CUN-01 provides the decisive physical control: wedge impressions are material marks that compose a sign form. GRB-01 supplies a second composition control: several visible characters can participate in one recognized orthographic unit.

`MARK` denotes an occurrence/component record. `FORM` denotes an organized or recognized configuration/realization. A single mark can participate in a form, but participation is not type identity.

```text
MARK_EQUALS_FORM=NO
MARK_FORM_DECISION=MARK_FORM_DISTINCTION_REQUIRED
MULTIPLE_MARKS_CAN_COMPOSE_ONE_UNIT=YES
```

The distinction is documentary and may be implemented differently by each domain. It is not a metaphysical claim about all marks.

# 07 — Form / Value / Meaning Control

CUN-01 establishes polyvalence and explicitly rejects `SIGN_FORM=SIGN_VALUE` and `SIGN_VALUE=MEANING`. VOR-01 likewise separates written string/grapheme, pronunciation/phoneme, lexical item and meaning.

The reduced schema may record:

```text
(FORM or UNIT) + LANGUAGE/SYSTEM + CONTEXT -> VALUE
```

but only as a documentary mapping schema:

```text
NOT_A_UNIVERSAL_LAW
NOT_AN_OPERATOR
NOT_A_CAUSAL_MODEL
```

```text
SIGN_EQUALS_VALUE=NO
UNIT_EQUALS_VALUE=NO
ONE_FORM_CAN_HAVE_MULTIPLE_VALUES=YES
VALUE_EQUALS_MEANING=NO
```

`MEANING` remains a domain extension because not every value is itself a semantic interpretation: values may be phonological, syllabic, logographic, grammatical or classificatory.

## Croatian Glagolitic reinforcement

The source-bound `MISLITE` control adds numeric value and letter name to the separation. Its phonetic value `/m/`, Glagolitic numeric value `60`, Cyrillic numeric value `40`, letter name and lexical meaning of that name are not interchangeable. This reinforces `FORM != VALUE` and `VALUE != MEANING` while showing that `VALUE_TYPE != VALUE`.

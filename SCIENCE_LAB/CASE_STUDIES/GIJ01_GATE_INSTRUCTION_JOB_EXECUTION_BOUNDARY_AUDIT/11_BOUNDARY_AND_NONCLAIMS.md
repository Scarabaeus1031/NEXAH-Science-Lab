# GIJ-01 - Boundary and Nonclaims

GIJ-01 supports only a bounded documentary execution-boundary model.

It does not establish:

- semantics in the letters GIJ, GTI, GTA or GIT;
- lexical order as temporal, causal or execution order;
- a new NEXAH operator;
- a new universal execution architecture;
- that all information is instruction;
- that instruction, environment, rule or authority implies execution;
- that dispatch or attempt implies event entry;
- that execution implies success or a useful result;
- that result equals trace;
- that trace equals provenance;
- that a technical environment is a biological host;
- that Git or GitHub implements NEXAH;
- any Rust implementation or conformance result;
- any ORION capability;
- a scientific discovery or externally validated application.

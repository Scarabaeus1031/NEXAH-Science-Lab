# CRIP-01 Specification

## Mode and scope

`BOUNDED_CROSS_REPRESENTATION_INFORMATION_PRESERVATION_AUDIT`, dated 2026-08-30.

CRIP-01 tests what survives, changes, is lost, is introduced, or remains undefined when a registered object is represented in another way. It does not recover a hidden historical system and does not validate the scientific language attached to historical artifacts.

## Frozen boundary

TITAN-00, SWM-01, RID-01, NEXUS-01, OTC-01, RPR-01, RRR-01, GAVP-01, ETRI-01, WFR-01, WNI-01, P6R-01, and C12S-01 remain frozen. In particular, C12S-01 remains closed with `B_USEFUL_RECONSTRUCTION_OF_STANDARD_MATHEMATICS`; `6+I+6` remains historically attested but formally undefined and unmapped to the clock model.

## Method

For each candidate:

1. register the source and object;
2. type each representation;
3. require object identity before comparison;
4. recover or explicitly declare the transformation;
5. declare the tested relation;
6. classify it as `PRESERVED`, `TRANSFORMED_BY_DECLARED_RULE`, `DIFFERENT`, `LOST`, `UNRESOLVED`, or `UNDEFINED`;
7. record loss, view additions, trace, and provenance.

## Strong positive control

The primary source-backed control is a scalar array generated by `qgr_fieldmap_notebook.py` and rendered from the same arrays as a 2D heatmap and a 3D surface. The code is evidence of representation lineage only; its historical physics framing is not validated.

## Stop rule

After the required files, decision, and validation: `STOP`. No implementation, new research, successor audit, or predecessor modification is authorized.

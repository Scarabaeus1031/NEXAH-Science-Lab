# 05 — Mandelbrot / Julia Domain Boundary

For the quadratic family `f_c(z)=z²+c`:

- the Mandelbrot set `M` is a subset of parameter space `C=ℂ`, classifying parameter values through the critical orbit;
- for fixed `c`, the Julia set `J_c` is a subset of the dynamical `z`-plane;
- the two planes may both be represented by complex coordinates, but equality of carrier type does not identify their registered mathematical roles.

Consequently:

`PARAMETER_SPACE_EQUALS_DYNAMICAL_PLANE=NO_BY_REGISTERED_ROLE`  
`MANDELBROT_SPACE_EQUALS_JULIA_PLANE=NO`  
`MANDELBROT_SET_EQUALS_JULIA_SET=NO`  
`PARAMETER_EQUALS_GENERATED_OBJECT=NO`  
`MEMBERSHIP_OF_c_IN_M_EQUALS_POINT_MEMBERSHIP_IN_J_c=NO`

A rendered resemblance between subsets or images in these planes is representation evidence only. It does not establish set identity, a map, transport, quotient, or causal relation.

# 12 — IJQ Next-Test Interface

MJTR-01 quarantines `i`, `j`, `k`, quaternion `Q`, `ℍ`, quaternion Julia sets, slice dynamics, and Q1–Q6 mappings. It performs no extension from `c=a+bi` to `q=a+bi+cj+dk`.

The current ledger is nevertheless sufficiently explicit to state a purely documentary interface for any separately authorized future test:

- declare parameter domain and value type;
- declare state domain;
- type the parameterized rule with domain/codomain;
- distinguish exact generated object from numerical representation;
- register observation and compatibility-set definitions;
- keep rule, event, result, orbit, and trace separate;
- require provenance independent of visual labels.

This interface does not assert that a quaternion extension is valid, useful, implemented, or warranted.

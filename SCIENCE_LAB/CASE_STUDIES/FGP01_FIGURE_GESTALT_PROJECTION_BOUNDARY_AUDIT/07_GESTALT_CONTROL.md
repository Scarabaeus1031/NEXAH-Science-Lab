# Gestalt Control

Bounded operational use only:

> Gestalt is an organized grouping attributed to a Figure under a declared observer/model/criterion.

A defensible derived record contains `figure_ref`, observer or model reference, criterion/rule reference, grouped element references, organization assertions, alternatives/ambiguity, applicable context/time, uncertainty and provenance.

This record can be composed from existing View, Relation/Partition, ComparisonCriterion, Ambiguity and Provenance facilities. It is useful for reviewability but adds no primitive.

- `FIGURE != GESTALT`: a fixed configuration may admit several groupings.
- `GESTALT != OBJECT`: grouping does not identify its source.
- `GESTALT != INVARIANT`: invariance requires a separately tested criterion/domain.
- `GESTALT != INTERPRETATION`: organization is an attributed configuration; interpretation is a downstream claim about it.

Classification: `B_DERIVED_OBSERVER_RELATIVE_RECORD_USEFUL`. This is not a Gestalt-psychology or perception theory.

# Structure / Instance / State Control

Neutral example:

- `S`: triangle structure—three vertex roles, three adjacency relations, cycle/constraint declaration.
- `G1@rev1`: one registered graph instance with vertices `a,b,c` realizing `S`.
- `G1_STATE(t0)`: coordinates/attributes at `t0` under a declared frame.
- `G1_STATE(t1)`: later coordinates/attributes under the same registered instance lineage.

`S != G1`; the constraint/type description is not its realization. `G1 != G1_STATE(t0)`; identity and revision lineage are not a state value. `G1_STATE(t0) != G1_STATE(t1)` when values differ, while the registered instance may remain `G1`.

Structure-to-instance is **declared realization/conformance**, not identity or Platonic instantiation. Instance-to-state is **time/revision-qualified attribution**, not material embodiment. Same instance may support multiple states; changed state does not automatically establish changed entity identity.

# GLF-01 — Global / Local / Frame Audit

## Status

`CLOSED / BOUNDED_FORMAL_REPRESENTATION_AND_INVARIANCE_AUDIT`

GLF-01 tests what survives when a global object is described through a chosen origin, cut, parameterization, partition, labeling or local frame. Its controls are a line/interval, the circle `S^1`, smooth and nonsmooth curves, regular polygons `P_n` for `3 <= n <= 10`, and one bounded calendar representation.

## Decision

`B_STANDARD_MATHEMATICS_SUPPORTS_PARTIAL_GLOBAL_LOCAL_TRANSFER_WITH_EXPLICIT_CUT_FRAME_DEPENDENCE`

Standard mathematics cleanly distinguishes an object from its coordinates and representations. Counts, parity, angle values, topology and symmetry structure survive appropriate changes. First labels, seams, coordinate values, month positions within a chosen year origin and seasonal partitions do not. A tangent or local frame preserves local first-order information but does not determine the global object.

This is not a NEXAH validation, theory, operator, ontology or physical claim. VOR-01, CUN-01, GRB-01, SFM-01 and RSC-01 remain frozen and were not modified.

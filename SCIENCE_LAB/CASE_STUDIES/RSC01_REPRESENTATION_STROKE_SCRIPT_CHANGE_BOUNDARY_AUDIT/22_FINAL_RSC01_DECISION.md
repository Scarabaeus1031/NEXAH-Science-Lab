# 22 — Final RSC-01 Decision

## Primary result

`B_SFM_SURVIVES_WITH_DOMAIN_SPECIFIC_PROCESS_AND_RELATION_EXTENSIONS`

The SFM four-type documentary reduction survives as a useful static description: physical traces instantiate marks; recognized configurations are forms; writing systems recognize units; and context maps units to values. The controls falsify only the stronger claim that these four types alone form a complete cross-domain model.

Chinese brush-calligraphy production requires explicit process, event, temporal-order and provenance records when the question is how a trace was made. A trace can retain partial execution evidence, but it is not the action and does not fully reconstruct the event. Vietnamese script history preserves `SCRIPT != LANGUAGE` while also showing that script change changes representational properties. Vietnamese kinship/address usage requires an explicit relation among participants and discourse role; `VALUE` survives as the output of that mapping, not as an intrinsic property of the lexical unit.

These extensions are ordinary domain terminology. They are not new types in a NEXAH core, new operators, an ontology or a scientific claim delta.

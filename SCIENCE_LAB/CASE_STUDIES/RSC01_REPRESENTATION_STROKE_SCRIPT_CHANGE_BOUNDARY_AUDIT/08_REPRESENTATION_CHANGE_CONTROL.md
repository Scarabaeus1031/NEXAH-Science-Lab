# 08 — Representation-Change Control

## Neutral test

Let `L` be a language variety and `G1`, `G2`, `G3` distinct representation systems. The historical evidence supports:

```text
REPRESENT(G1,L,context_1)
REPRESENT(G2,L,context_2)
REPRESENT(G3,L,context_3)
```

It does not support:

```text
G1 = G2 = G3
context_1 = context_2 = context_3
all units and values transfer losslessly
L is unchanged in every historical respect
```

## What can survive a script change

- Some language identity and textual content can remain recognizable across representations.
- Source-ledger/dictionary work can document particular correspondences.
- A language need not become a different language merely because its dominant script changes.

## What does not automatically survive

- form inventory;
- component structure;
- encoding model;
- visual trace;
- orthographic segmentation;
- all phonological or semantic distinctions;
- provenance, genre and historical context.

Therefore cross-script correspondence is `PARTIAL`: supported for bounded records, not established as a complete bijection. Neither preservation nor loss is assumed globally.

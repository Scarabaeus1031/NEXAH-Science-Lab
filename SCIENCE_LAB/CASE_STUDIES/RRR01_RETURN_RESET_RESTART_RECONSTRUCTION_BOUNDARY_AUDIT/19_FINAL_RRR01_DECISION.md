# Final RRR-01 Decision

Existing state, operation-rule, event, result, execution, history and provenance types fully explain the return family. No new primitive or canonical interface subtype is required. Ordinary return language is context-dependent and must name both the field and equality/equivalence criterion that returned.

The controls consistently separate state from history. The PRR involution and a double reflection restore their registered values/embedding while adding two events. A reset can restore one value while leaving other fields and the record unchanged. A restart creates a new execution. A repeat creates a distinct event. A reconstruction can reproduce a state representation without becoming the original event. A zero readout does not identify a zero state or empty history.

Equal endpoints likewise do not identify paths or provenance, and equivalent orientations need not be equal numerical representatives. The decisive comparison `X0 --A--> X1 --B--> X0` versus bare `X0` therefore reports state equality but history inequality.

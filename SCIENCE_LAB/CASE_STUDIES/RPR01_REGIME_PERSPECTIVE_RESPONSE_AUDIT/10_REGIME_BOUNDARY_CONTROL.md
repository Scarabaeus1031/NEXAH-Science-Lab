# Regime Boundary Control

An environmental change is not automatically a regime transition. A `REGIME_BOUNDARY` is a declared boundary in parameter/condition space under an explicit classification criterion.

| Boundary kind | Valid use | Bifurcation? |
|---|---|---|
| Mathematical threshold/stability loss | Rosensweig onset under stated model | Yes only when demonstrated |
| Continuous response interval | changing flame/clock/biological response magnitude | Not necessarily |
| Categorical environment change | 1g apparatus vs orbital microgravity protocol | Operational category, not automatically bifurcation |
| Observer-defined classification | analyst labels response classes | Documentary boundary only unless externally validated |

Thus `REGIME_CHANGE ≠ BIFURCATION`. Return to a prior regime does not imply return to the same state because history, adaptation, hysteresis or irreversible change may remain.

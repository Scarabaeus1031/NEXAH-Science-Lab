# View vs Frame vs Regime Matrix

| Change | What changes | What need not change | Minimum evidence |
|---|---|---|---|
| View | Projection, readout, rendering or selected presentation | State, frame, regime, identity | Same source/state ref; distinct view rule/source |
| Frame | Coordinate/reference basis used to express quantities | Physical state, regime, identity | Transform and frame refs; preserved invariants |
| Regime | Declared environmental parameters, governing boundary conditions, available cues or constraint class | Identity; response may be negligible | Before/after regime records and criteria |
| State response | System state/trajectory/behavior changes under conditions/history | Identity; form may remain in same class | State transition/event and provenance |
| Realized form change | Geometry/morphology/behavioral class changes | Identity; may be continuous or qualitative | Form/state comparison under declared basis |

Control A: `X → P1(X), P2(X)` may change only representation.  
Control B: `(X,R1) → F1`, `(X,R2) → F2` changes regime and may change response/form. Neither formula alone proves causality; domain evidence supplies the mechanism.

`FRAME` is independently typed. A frame can be part of an experimental regime declaration when the apparatus makes it physically operative, but a mere coordinate-frame change does not itself change the physical regime.

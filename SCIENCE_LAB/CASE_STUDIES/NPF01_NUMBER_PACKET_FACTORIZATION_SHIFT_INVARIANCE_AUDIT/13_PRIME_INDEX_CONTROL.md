# Prime Index Control

Prime indices use the standard ascending list beginning `2,3,5,7,11,13,...`.

| Prime seed | Prime index |
|---:|---:|
| 2 | 1 |
| 3 | 2 |
| 5 | 3 |
| 11 | 5 |
| 13 | 6 |
| 23 | 9 |
| 29 | 10 |
| 31 | 11 |
| 41 | 13 |
| 43 | 14 |

The index is an exact ordinal in this conventional ordering. It is not a factor, digit property, packet position, or semantic code. Immediate prime adjacency was checked only as needed to verify these indices; no new prime candidates were admitted.

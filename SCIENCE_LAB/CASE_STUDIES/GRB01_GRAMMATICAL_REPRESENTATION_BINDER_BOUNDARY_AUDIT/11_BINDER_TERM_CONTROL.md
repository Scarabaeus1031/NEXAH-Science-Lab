# 11 — BINDER Term Control

Starting classification:

`BINDER_EVIDENTIAL_STATUS=USER_SUPPLIED_META_TERM`

Standard terminology covers the selected cases:

| Case | Adequate standard description |
|---|---|
| English `th` | digraph / composite symbol |
| German `ch` | digraph or context-dependent letter sequence |
| German `sch` | trigraph / composite symbol |
| Croatian `dž/lj/nj` | official `dvoslovi`, alphabet letters represented by two characters |
| Dutch `ij` | two-letter sequence with context-dependent letter-like behavior |
| article/definiteness | grammatical marker versus grammatical/semantic feature |
| no overt article | contextual, discourse, morphological, lexical or construction-specific analysis |

`BINDER` does not improve precision because it would group structurally different conventions under one new label.

```text
BINDER_FORMAL_NEED=NO
STANDARD_LINGUISTIC_TERMINOLOGY_SUFFICIENT=YES
NEW_BINDER_OPERATOR_CREATED=NO
```

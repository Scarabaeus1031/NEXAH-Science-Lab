## Central conclusion

The operationally valid core is not glyph equality. It is typed transport:

```text
value + representation + marker + frame + directed cut
  -> reproducible rollover, orientation and boundary state
```

`0/o/°` can be used as distinct carrier or boundary forms. `6/9` can be used
only as font-qualified direction markers. The directed Iota cut gives the
strongest result: joint rotation preserves the `I/O/M` classification, while
reversing the cut swaps `I/O` and preserves the boundary.

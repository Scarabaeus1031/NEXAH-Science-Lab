## Priority open tests

### ORI-TEST-001 — Level-0 false-claim suite

**Question:** Can an ORION implementation accept exact `Z_365` truths and reject
local/global, observable/invariant, and invertible/noninvertible confusions?

**Required:** reviewed finite fixture, expected outputs, deliberately false
claims, independent implementation.

### ORI-TEST-002 — EXP-JANUS-19 evidence recovery

**Question:** Do authentic raw rows, code, configs, and run outputs still exist?

**Required:** provenance search only. Do not regenerate from boards. Outcome may
be `recovered`, `not found`, or `ambiguous`.

### ORI-TEST-003 — EXP-JANUS-19 exact replay

**Question:** If recovered, do the two CSVs reproduce exactly from the claimed
900 rows and five-fold pipeline?

**Falsifier:** any unexplained mean/SD, subset, fold, or row-count discrepancy.

### ORI-TEST-004 — Grouped/nested validation

**Question:** Does the persistence-dominant result survive group-wise splits
and nested subset selection?

**Controls:** trajectory/field grouped CV, nested selection, fixed holdout,
permutation of groups rather than individual correlated rows.

### ORI-TEST-005 — Shifted-field frozen model

**Question:** Does the frozen compact predictor retain performance on a
predefined field/parameter shift?

**Required:** no refitting, registered shift, raw predictions, baseline and
failure thresholds.

### ORI-TEST-006 — Feature semantics

**Question:** Are `lambda` and `tau_M` independently useful, redundant, or an
undocumented ratio?

**Controls:** separate ablations, ratio-only model, leakage check, units and
definition audit.

### ORI-TEST-007 — Memory metric reproduction

**Question:** Does `tau_M` follow the reported contraction relation on raw
trajectories?

**Controls:** threshold sweep, window sweep, norm change, censoring analysis,
stable/neutral/unstable regimes, surrogate trajectories.

### ORI-TEST-008 — Gate freeze and replay

**Question:** Can the EXP-18D gate rule be reconstructed from a discovery set
and applied unchanged to retained test fields?

**Controls:** geometry matching, quantile perturbation, label shuffle,
field-wise split, multiple-testing correction.

### ORI-TEST-009 — Mobility/transfer/memory event chain

**Question:** Do individually defined events occur in the proposed order more
often than matched or surrogate crossings?

**Controls:** reversed paths, time shuffle, event-boundary shift, failed
crossings, matched non-gate paths.

### ORI-TEST-010 — Navigation intervention

**Question:** Does a frozen policy using candidate features improve transition
success or cost?

**Baselines:** random, position-only/radial, local gradient, matched non-gate,
reference-model control.

### ORI-TEST-011 — Representation benchmark

**Question:** Which source structures survive Cartesian, invertible coordinate,
projection, graph, and NEXAH representations?

**Required:** execute `07_ORION_INVARIANCE_BENCHMARK.md` only after separate
registration.

### ORI-TEST-012 — Destructive-metric sensitivity

**Question:** Does every proposed invariant fail when its source structure is
destroyed?

**Controls:** label shuffle, time shuffle, wrong operator, phase scrambling,
edge rewiring, destroyed topology.

### ORI-TEST-013 — Shell stability

**Question:** Does the shell persist under window, resolution, coordinate, and
parameter shifts with a declared matching rule?

**Boundary:** persistence of a region is approximate robustness, not exact
invariance.

### ORI-TEST-014 — Transition-kernel residual

**Question:** Does any residual directionality remain after a fully specified
null kernel and uncertainty analysis?

**Falsifier:** residual compatible with the registered null.

### ORI-TEST-015 — XXI finite census

**Question:** Do the reported word/wheel symmetry-class counts reproduce under
a machine-readable group action?

**Required:** full enumeration, class representatives, Burnside/checksum where
appropriate, independent replay.

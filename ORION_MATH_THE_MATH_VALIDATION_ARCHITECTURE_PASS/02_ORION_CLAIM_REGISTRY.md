# ORION Claim Registry

Status: `CONSERVATIVE EXTRACTION FROM THE SOURCE ARCHIVE`

## Registry rules

- `Source` identifies an archive report/experiment family, not an authority transfer.
- `Code available` and `Raw data available` refer to the supplied source archive.
- `Reproducible` means reproducible today from the supplied artifacts, not merely plausible or exactly calculable from a separately restated definition.
- `Known mathematical result` distinguishes standard mathematics from archive-specific empirical assertions.
- Allowed status values are used exactly as requested.

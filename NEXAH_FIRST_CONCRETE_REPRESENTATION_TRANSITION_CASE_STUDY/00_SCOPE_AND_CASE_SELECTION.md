# Scope and Case Selection

## Selected case

**Study-3 baseline-versus-one-step-delay transition-fidelity chain** from `NEXAH_TRANSLATION_FIDELITY_EXPERIMENT`.

The bounded scientific object is the frozen set of 20 synthetic four-state systems (ten base/counterfactual pairs) and the derivation of decoded transition structure from their two-dimensional observations through either the original feature view (`R0_baseline` in the experiment) or the one-step delay view (`R3_delay`).

## Why this case

This case has the strongest available combination of:

- frozen protocol, runner, results, manifest, and byte-identical replay;
- explicit float arrays, state labels, indices, cluster correspondence, transition matrices, certificates, and aggregate metrics;
- deterministic operators with disclosed oracle assumptions;
- two documented paths from the same source data to the same target representation types;
- an already observed material divergence between those paths.

It is selected for evidentiary strength, not visual appeal. There is no visual representation in the actual analytic chain, and none is invented here.

## Boundaries

This is a read-only reconstruction and analysis of existing artifacts. Existing result fields are extracted and recomputed only as consistency checks; the frozen experiment is not rerun. No V3 change, validator, new experiment, T02 change, ORION change, canonical NEXAH change, or new scientific claim is authorized.

The closed Ledger V3 vocabulary is used only later as a documentation crosswalk.

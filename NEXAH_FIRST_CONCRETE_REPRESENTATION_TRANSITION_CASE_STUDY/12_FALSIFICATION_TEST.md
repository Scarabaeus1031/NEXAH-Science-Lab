# Falsification Test

## Could ordinary documentation yield the same science?

**Yes, substantially.** A competent researcher reading the frozen protocol, runner, result JSON, Results report, adversarial analysis, and Git history can recover the central empirical account: baseline decoding is exact on the fixed matrix, delay decoding is materially worse, coarse component summaries can remain equal while richer certificates change, and the outcome is implementation-qualified.

The source artifacts already disclose the state-count oracle, alignment rule, hashes, replay, metrics, and negative delay result. The representation-transition analysis does not create a new result.

## What the explicit analysis adds

It adds a compact, criterion-bound localization that ordinary narrative spreads across several files:

1. T03 retains current observations exactly and is invertible by projection.
2. T03 simultaneously changes the metric geometry used by the downstream decoder.
3. The first material state-identity loss is at the many-to-one decode/alignment stage, not at current-observation recoverability.
4. Transition counting and certificate projection add further distinct losses.
5. Coarse C0 agreement and rich-certificate disagreement apply to different target objects and must not be conflated.
6. Oracle alignment introduces semantic correspondence; it is not preservation produced by clustering alone.

These are useful methodological distinctions, but all are derivable from existing code and results. They reorganize and clarify the evidence rather than extend it.

## Falsification outcome

The strong proposition that a NEXAH representation architecture uniquely reveals otherwise unavailable science is not supported by this case. The weaker proposition—that explicit transition accounting reduces ambiguity about where preservation, loss, and analyst assumptions occur—is supported as methodological clarity.

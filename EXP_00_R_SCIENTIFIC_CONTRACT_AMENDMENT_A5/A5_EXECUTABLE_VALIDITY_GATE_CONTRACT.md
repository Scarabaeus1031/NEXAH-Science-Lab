# A5 Executable Validity-Gate Contract

Every gate below is classification-blocking. Inputs must be manifest-bound JSON artifacts; a missing field is false. Predicates use exact set equality, exact strings/integers/Booleans, finite binary64 checks, and stated numeric inequalities. A false predicate after authorization yields `INVALID EXPERIMENT`; before authorization it yields `IMPLEMENTATION_FAILURE` and makes authorization unreachable. Dependencies must pass first.

| Gate | Inputs and required fields | Exact Boolean derivation | Dependencies |
|---|---|---|---|
| SOURCE_CONFIG_INTEGRITY | authoritative V1 files; A1–A4 machine files; A5 manifest | recomputed V1 composite equals frozen digest AND each external SHA-256 equals its anchor AND every A5 manifest member hash matches | none |
| CONFIG_BINDING_COMPLETE | every stage artifact: config ID, V1 digest, A5 machine hash, source-manifest hash | every artifact has all four fields and each exactly equals the sealed expected value; one and only one configuration ID occurs | integrity |
| TRAIN_TEST_ISOLATION | split/provenance ledger: train/test seeds, fit rows, target/standardizer/support sources, access events | train=`5000..5029`; test=`6000..6029`; disjoint; target/standardizers/support/representation fits use TRAIN only; model fits use TRAIN_OOF only; final metrics use TEST only; no TEST state/outcome read precedes authorized evaluation stage | binding |
| INFORMATION_PARITY | T/F parity records with seeds, state variables, actions, raw-table hash, sampling, horizon, target/objective/action hashes, access flags | exact equality across T/F for seeds, observed `[x,y,z]`, raw training table hash, sampling `0.05`, horizon `1.0`, action set/order, target/objective/evaluation hashes; future-test access false; analytic-field access false | isolation |
| REPRESENTATION_DISTINCTNESS | representation provenance | families equal exact `{finite_horizon_knn_outcome,query_local_affine_ridge_field}`; T response is terminal objective and has no derivative labels; F response is finite-difference derivative minus `B*u` and has no terminal-objective response; neither imports/calls the other or shares fitted response/score cache | parity |
| NO_ANALYTIC_FIELD_LEAKAGE | dependency/AST provenance and access ledger | no learned representation imports/calls `exp00r.rossler` or analytic derivative; analytic-field-access flags all false; only plant/outcome evaluator may use ground truth | distinctness |
| SUPPORT_VALIDITY | representation support and joint row ledger | T OOS `<=0.10`; F OOS `<=0.10`; joint coverage `>=0.80`; unsupported means whole-ranking abstention/no imputation; joint member iff both support; at least 20 test seeds each contain at least 20 joint rows where both carriers are nonzero | leakage |
| N5_RUN | 12 coordinate records and population bindings | exact 12 frozen matrices; one execution each; every required tau finite under frozen constant convention and `>=0.99`; same original fixed population; no transformed abstention, refit error, or population change | support |
| NULL_FAMILY_COMPLETENESS | null artifacts | exact families `{N1,N2,N3,N4_T,N4_F}`; each exact IDs `0..199`; every required statistic finite; no missing/extra/retry/redraw/row drop; correct carrier mapping and fixed population/config | N5_RUN |
| BOOTSTRAP_VALIDITY | bootstrap artifact | exact IDs `0..499`; cluster unit `TEST_SEED`; seed `20260808`; 30 draws with replacement from exact 30 test seeds per replicate; both-carrier finite coefficients; frozen linear quantile rule; no redraw | support, binding |
| PER_SEED_ATTRIBUTION_COMPLETENESS | per-seed artifacts | each carrier has exact seed IDs `6000..6029`; finite directions; frozen zero convention; at least 21 values `>=0`; exact dominance artifact complete | support |
| SYMMETRIC_CARRIER_ATTRIBUTION_COMPLETE | primary carrier artifacts | exact carriers T/F; identical population row hashes; both finite coefficient/gain; all four score/margin controls present; mandatory diagnostic registry complete | support |
| ALL_12_SENSITIVITIES_COMPLETE | sensitivity artifacts | predicate in A5 sensitivity contract and machine `sensitivities.completeness` is true | binding, support |
| PROVENANCE_COMPLETE | expected-artifact ledger | exact artifact types/IDs exist once, SHA-256 matches, canonical row/population/config/environment/authority fields present and mutually consistent, all mandatory diagnostics present | all producing gates |
| NO_POST_ACCESS_SCIENTIFIC_MUTATION | append-only event ledger | freeze/manifest event precedes any registered-access event; all later artifacts retain the same hashes; no scientific-choice/config/source/threshold mutation event follows access | integrity |
| P1_P5_MECHANICALLY_COMPUTED | gate/P/null/bootstrap/sensitivity inputs | P1–P5 exactly equal machine predicates; no manual Boolean inputs; Rössler label produced only after every prior validity gate passes | all prior gates |

`ANALYTIC_FIELD_LEAKAGE prohibition` is represented by the positive gate `NO_ANALYTIC_FIELD_LEAKAGE`. Canonical-row provenance and seed-dominance identity are required subpredicates of `PROVENANCE_COMPLETE` and `PER_SEED_ATTRIBUTION_COMPLETENESS`; failure propagates identically.

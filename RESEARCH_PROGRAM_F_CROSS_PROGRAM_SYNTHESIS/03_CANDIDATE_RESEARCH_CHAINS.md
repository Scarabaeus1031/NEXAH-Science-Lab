# Candidate Research Chains

## Candidate 1 — Finite orthographic-projection identifiability

| Field | Record |
|---|---|
| Exact research question | For four declared orthographic observation maps, which source curves are observationally indistinguishable and which views separate them? |
| Existing source object | Rödelheim Observatory Lab 0.4 deterministic four-thread model and test record |
| Mathematical formulation status | Projection formulas and sources exist; equivalence scope and tolerance require protocol freeze |
| Evidence status | C-46 `SUPPORTED` within the finite synthetic case; no external reproduction |
| Benchmark availability | Existing Lab 0.4 is a finite control case; rank/null-space and pairwise partition baselines require no new dataset |
| Implementation status | Existing JavaScript model and nineteen-check test suite record |
| External-review readiness | Ready after protocol, source snapshot, hashes, and result record are frozen |
| Expected bounded contribution | Finite identifiability classification or counterexample showing view-dependent collapse with retained source identity |
| Critical blockers | Analytic-versus-sampled criterion; equality/tolerance; canonical source snapshot; independent review gate |
| Risk of overclaiming | Moderate; finite collapse may be recast as general information theory, physical identity, or universal representation behavior |
| Estimated work sequence | authority → protocol definition → source/hash freeze → analytic classification → internal verification → result record → external review gate |

Disposition: `PRIMARY CANDIDATE`.

## Candidate 2 — Estimation under a time-varying observation schedule

| Field | Record |
|---|---|
| Exact research question | For one fixed state-space model and estimator, does a deterministic time-varying observation matrix change estimation error or recovery relative to an exposure-matched static schedule? |
| Existing source object | Program A minimum Moving Mask design; no frozen benchmark instance |
| Mathematical formulation status | Model family and variables exist; exact matrices, estimator, exposure rule, and recovery metric are absent |
| Evidence status | C-47 `UNVALIDATED`; no run evidence |
| Benchmark availability | Standard intermittent-observation benchmark family available; none selected or frozen |
| Implementation status | None authorized |
| External-review readiness | Not ready; internal protocol and result must precede external result review |
| Expected bounded contribution | Positive, negative, or inconclusive estimator result for one matched synthetic schedule comparison |
| Critical blockers | owner, repository, exact model, estimator, schedule, exposure rule, thresholds, seeds, environment, review gate |
| Risk of overclaiming | High; exposure confounding, threshold flexibility, source/mask conflation, and single-benchmark generalization |
| Estimated work sequence | authority → preregistration → implementation gate → frozen run → verification → result → external review |

Disposition: `SECONDARY DESIGN CANDIDATE`.

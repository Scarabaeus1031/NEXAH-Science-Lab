# Contribution Boundary

## A. Established literature and methods

- linear projections and their kernels;
- injectivity and identifiability on a declared source set;
- equivalence classes induced by an observation map;
- multi-view geometry and state distinguishability;
- numerical tolerance analysis;
- deterministic replay and independent reproduction.

These are not NEXAH contributions.

## B. Existing repository implementation or evidence

- four deterministic source curves with persistent IDs;
- four explicit orthographic projections;
- post-projection mask and record-status separation;
- recorded A/B collapse at `90°` and distinction at `0°`;
- mirror counterviews at `180°` and `270°`;
- nineteen deterministic implementation checks;
- C-46 supported finite result;
- explicit scientific and provenance boundaries.

This is existing evidence, not a proposed contribution.

## C. Proposed new protocol

A documentation-only protocol would bind the existing finite object to:

- one continuous or sampled scope;
- one equality or tolerance rule;
- one view-specific source partition procedure;
- one baseline and verification set;
- four terminal result classes;
- one independent review package.

The protocol itself is not a scientific contribution.

## D. Possible bounded contribution

An externally inspectable finite identifiability classification showing exactly which declared source distinctions are preserved or collapsed by each of four observation maps, including a reproducible counterexample to the inference that projected coincidence implies source identity.

The contribution exists only after a frozen valid result and independent review. A negative or inconclusive result remains useful if it exposes a mismatch between the current implementation claim and the frozen criterion.

## E. Claims not permitted

- a new theory of information or representation;
- a novel projection, inverse, or multi-view method;
- a general observability or identifiability theorem;
- novelty, discovery, or priority;
- physical identity, coupling, astronomy, cosmology, or source-space motion;
- universal topology, orientation geometry, or operator algebra;
- empirical or cross-domain generalization;
- validation of Q°, Moving Mask, Pattern, JANUS, Gate, OLS, or ORION;
- publication or visual form as scientific support.

Combination, terminology, provenance, and visualization are not counted as contributions.

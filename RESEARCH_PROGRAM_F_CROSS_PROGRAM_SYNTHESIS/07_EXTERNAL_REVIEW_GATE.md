# External Review Gate

## Gate state

`NOT OPEN`

Program F identifies the gate. It does not authorize contact or review.

## Required package

- ordinary scientific title and one research question;
- frozen protocol and authority record;
- exact source formulas or finite sample table;
- declared observation maps;
- frozen equivalence criterion and tolerance;
- source snapshot, file list, SHA-256 hashes, and environment record;
- analytic expected partitions and implementation outputs kept separate;
- baseline comparisons;
- one result class: positive, negative, inconclusive, or invalid protocol;
- failures, limitations, and prohibited claims;
- repository provenance appendix.

## Reviewer composition

1. one independent inverse-problems or applied-linear-algebra reviewer;
2. one independent reproducibility reviewer;
3. one repository provenance contact who supplies sources but does not decide scientific validity.

## Independence conditions

- no reviewer authored the Lab 0.4 model, protocol, or Program F conclusion;
- reviewer receives no preferred result;
- protocol, source, and metrics are frozen before review;
- external critique and repository response remain separate records;
- review is not described as endorsement or validation beyond the finite case.

## Questions permitted

- Are the source set, maps, and equivalence relation well defined?
- Are the four partitions derived correctly?
- Do code and protocol implement the same map and criterion?
- Are tolerance and sampling choices justified?
- Does the result support only the stated finite classification?
- Can the package be independently replayed?

## Questions excluded

- Is NEXAH true, novel, or useful as a whole?
- Does projection collapse imply physical identity or coupling?
- Does the result validate a general information-loss theory?
- Does it validate Q°, Moving Mask, OLS, ORION, or any application?

## Gate opening conditions

All required package items exist, Thomas approves release to review, a canonical Research/Validation owner accepts the package, and reviewer independence is documented.

## Gate outcomes

- `ACCEPTED FOR BOUNDED REVIEW`;
- `RETURNED FOR DEFINITION REPAIR`;
- `RETURNED FOR EVIDENCE REPAIR`;
- `REJECTED AS OUT OF SCOPE`.

These are review-admission outcomes, not scientific result classes.

## Stop conditions

- any package field remains mutable;
- equivalence depends on repository metaphor;
- source evidence cannot be located or hashed;
- analytic and implementation records disagree without classification;
- external opinion would be reported as scientific endorsement;
- review scope expands beyond the finite case.

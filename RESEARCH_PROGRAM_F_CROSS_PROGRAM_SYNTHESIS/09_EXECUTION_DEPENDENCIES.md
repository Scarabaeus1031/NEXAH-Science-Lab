# Execution Dependencies

## Dependency chain

```text
Thomas owner decision
→ canonical Research/Validation owner
→ protocol-design authority
→ canonical Lab 0.4 source snapshot
→ analytic-versus-sampled scope
→ equivalence and tolerance rule
→ baselines and four result classes
→ protocol review
→ separate later execution decision
→ verification and result record
→ external-review release decision
```

Program F ends before the first protocol document is created.

- new Lab identity;

## Later execution dependencies

These are recorded only to prevent premature execution:

- separately approved operation or protocol execution;
- pinned environment and replay command;
- source and output hashes;
- clean separation of analytic derivation and implementation verification;
- failure-preserving result record;
- independent verification;
- separate external-release approval.

## Rollback boundary

Program F creates documentation only. If rejected, retain the Program F folder as a historical synthesis record and authorize no downstream protocol. No source, Lab, evidence, or authority rollback is required.

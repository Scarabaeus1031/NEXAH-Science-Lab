# Scope and Blind-Review Rules

This read-only review tests Schema V2 and Samples A–D against their cited code, data, protocols, and audits. The V2 claim that seven blockers were repaired is not a premise. No schema, source, canonical repository, experiment, T02, or ORION artifact is modified.

For each case the review first reconstructed the narrow source, actual callable/pipeline, target, operational preservation/loss, uncertainty, provenance, and claim disposition from primary evidence. The supplied YAML was inspected only afterward. Historical names and intended NEXAH narrative had no evidentiary force.

Agreement targets substantive scientific identity, not textual identity. Schema conformance already established by the prior task is not treated as scientific agreement.

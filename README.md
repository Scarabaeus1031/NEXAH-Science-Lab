# NEXAH A0 · Public Human View

Bounded public projection of the A0 Human View.

- Live: https://scarabaeus1031.github.io/NEXAH-Science-Lab/
- Entry: https://scarabaeus1031.github.io/NEXAH-Science-Lab/a0-human/start/
- Source repository: https://github.com/Scarabaeus1031/NEXAH-Science-Lab

The deployed `a0-human/` tree is the deny-by-default public bundle from
NEXAHEDRON. A0 Research Desk, Backlog, Science Navigator / NSN, Mission
Control, Builder logs and non-allowlisted A0 working surfaces are not part of
this public projection.

The older `book/`, `navigator/`, `previews/`, `sources/` paths are retained as
historical preview paths during this update; the root now enters the curated
Human View.

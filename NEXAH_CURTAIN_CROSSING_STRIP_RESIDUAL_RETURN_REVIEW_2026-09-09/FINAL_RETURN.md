# Final Return

## Answer

Gate surface, event strips and residual/transition overlay are currently **visually similar, separately sourced artifacts**, not source-bound views of one observation process.

The available repository contains relevant components and documentary audits, but the required bridge is missing: no physical chain jointly binds image, generator, data, parameters, seed/determinism, coordinates, time discretization, gate rule, crossing times, strip rendering and residual reference. The referenced separate canonical checkout is absent. The early overview and both 4D-Chessboard sources are not usable test sources.

Decision: `E_INSUFFICIENT_SOURCE_BINDING_STOP`.

The mathematically valid candidate chain is retained without promotion:

`x(t) → g(x(t)) → Γ_gate → t_k → b_k → r_k`.

Exactly one highest-expected-gain integration is proposed and not implemented: an immutable `GateCrossingResidualRecord` binding every arrow, coordinate and display semantic by hashes and typed rules.

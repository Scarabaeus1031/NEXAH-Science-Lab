# A5XEF Population-Binding Contract

The complete row universe is never a model population by default. From raw support distances and sealed thresholds, both derivations construct TRAIN, TEST, JOINT_TRAIN, JOINT_TEST and NONZERO_TEST sets plus exact ordered ID lists/hashes.

Primary/null fitting uses JOINT_TRAIN; primary/null evaluation, bootstrap and attribution use JOINT_TEST. NONZERO_TEST is used only for the support-validity seed/count gate. N5-RUN retains its separately fixed original joint population including zero actions. Each sensitivity independently derives variant joint populations.

An unsupported row may remain in the raw universe but cannot enter a joint-population model. Foreign, duplicate or contradictory relational IDs invalidate. A valid support fraction never authorizes leakage.

# A5XEF Two-Implementer Audit

The reference and independent modules import only the shared immutable schema/constants. They separately implement row/population derivation, logistic fitting, controls, diagnostics, null transformations/statistics, bootstrap, N5, attribution/dominance, sensitivities, P1–P5 and classification.

On the canonical bundle their complete normalized outputs are exactly equal. The canonical fixture is allowed to produce a valid negative/partial scientific branch; it is not tuned to `REPLICATED`. The alternate namespace completes the same reference derivation without requiring `SYNTH_` identity.

Malformed and typed-failure mutations are checked independently. Equality is necessary but not treated as sufficient; the counterexample and semantic suite supply the separate contract-conformance test.

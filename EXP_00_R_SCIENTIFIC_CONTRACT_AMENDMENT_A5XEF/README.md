# A5XEF — Evidence-Binding Finalization

A5XEF is an additive, encoding-only repair of A5XE Class-B findings F40–F46. It does not alter accepted V1→A5 science, implement V3, authorize execution, or access registered evidence.

The generic raw interface accepts sealed experiment namespaces matching its type contract; fixtures use only `SYNTH_*` and `ALT_FIXTURE_*`. Raw representation scores/distances/outcomes drive populations, models, diagnostics and sensitivities. Producer scientific summaries are forbidden.

Run the bundled Python/NumPy 2.3.5 environment against `contract_validation/test_a5xef_contract.py`, then `contract_validation/validate_a5xef_contract.py`. The complete conformance run is intentionally substantial because it executes two independent 1,000-null/500-bootstrap paths and a full alternate namespace.

# Venue class and outreach boundary

## Natural class

`PUBLICATION_CLASS = TECHNICAL_REPORT`

More precisely: a versioned reproducibility/negative-results technical report
with code and frozen synthetic data. It is not currently a conceptual-discovery,
domain-research or validated-methods paper.

## Plausible routes after bounded preparation

1. **Zenodo archival release** — primary fit for an immutable report/artifact
   version with DOI.
2. **OSF Preprints** — plausible for the neutral technical note plus linked
   data/code; versions receive persistent citation identities.
3. **arXiv, likely cs.LG or cs.AI** — conditional on producing a refereeable
   scholarly contribution rather than a repository dump; arXiv explicitly
   requires topical, refereeable scientific contributions
   ([submission guidance](https://info.arxiv.org/help/submit/index.html)).

ReScience C is not a current fit: the internal replication does not reproduce a
published external paper. It would become relevant only to a separately
authored external replication project, which this audit does not authorize.

## Readiness split

```text
PUBLICATION_READY = NO
OUTREACH_READY = NO
```

The object is close enough to justify preparation, not announcement. Outreach
requires a stable external object, complete metadata and an owner-approved
claim boundary. Do not contact researchers, announce results, post publicly or
use ORION/application language as justification.

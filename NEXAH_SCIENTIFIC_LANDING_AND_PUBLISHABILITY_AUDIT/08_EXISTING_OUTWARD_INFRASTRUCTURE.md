# Existing outward and publishing infrastructure

## Repository findings

The Lab already has an outward-path working practice at
`RESEARCH_INSTITUTE_PHASE_B/13_OUTWARD_PATH_WORKING_PRACTICE.md`. It defines
`PUBLIC_CANDIDATE` as a documentation route requiring separate review; it does
not confer publication authority. The existing publishing reconciliation
created a Control Desk pipeline for ecosystem surface updates, not a scientific
publication or research-archive workflow. No second publishing governance
system is justified.

The outward-path practice should classify the proposed object as
`PUBLIC_CANDIDATE` only after the bounded preparation gate. The Control Desk
publishing pipeline should be used later for status synchronization if an owner
authorizes a release; it is not scientific review.

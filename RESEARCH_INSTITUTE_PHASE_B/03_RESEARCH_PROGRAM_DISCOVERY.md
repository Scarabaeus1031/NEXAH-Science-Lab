# Research Program Discovery

## Classification rule

`EXPLICIT` means the owning source calls the work a program or maintains a
program-level entry. `RECOVERED` means several Labs share an object family,
dependency order and question lineage in at least two sources. `NOT ADMITTED`
means thematic resemblance alone is insufficient.

## Recovered programs

### Observation, projection and finite identifiability

Evidence chain:

```text
Lab 0.2 — record classes and masks
→ Lab 0.3 — failed reconstruction under withheld information
→ Lab 0.4 — view-dependent indistinguishability
→ Program B — representation maps and identifiability
→ Programs F/G — finite four-view protocol
```

Moving Mask extends the observation condition over time. Observer Geometry
shares projection concerns but remains a broader exploratory environment.
FP/RR/OE concerns relational aggregation and belongs only at the dependency
edge, not automatically inside the finite-identifiability chain.

Classification: `RECOVERED HIGH-CONFIDENCE PROGRAM CLUSTER`, not an adopted
Program name. 【RO; M02; PB; PF; PG】

### Graph structure, reduction and navigation

Evidence chain:

```text
declared graphs
→ reachability and bottlenecks
→ state/transport graph reconstruction
→ domain aggregation
→ skeleton and spine extraction
→ preservation and robustness questions
```

Network Orientation and the power-system EXP-44 sequence share graph objects
and preservation questions. Domain validity remains separate.

Classification: `RECOVERED MEDIUM-CONFIDENCE PROGRAM CLUSTER`. 【APP; PB RQ-05】

### Finite reference-space validation

The prime comparison and wheel/product package form a sequential bounded
investigation: the second follows the first without modifying it. Both use
frozen specifications, deterministic evidence and explicit non-claims.

Classification: `RECOVERED SMALL PROGRAM`, largely closed unless a new
question is separately authorized. 【EVID】

## Program-level missing links

- the transition-geometry program lacks one current question-to-experiment map;
- the Power Systems program contains many experiment generations without one
  compact active/historical distinction at question level;
- the recovered projection/identifiability cluster lacks an owner-adopted
  program identity;
- Programs A–G have clear reports but no pointer from canonical NEXAH Research;
- the finite modular sequence has no explicit closeout index declaring whether
  it is closed or merely inactive.

# Control Desk Relationship

## Existing responsibility flow

```text
Human signal or question
→ Control Desk orientation and authority route
→ owning Research / Application / Library / repository
→ result and closeout return
→ Control Desk records state, decision and next permitted action
```

The Control Desk is operational orientation authority. It does not own
scientific truth, production assets or canonical project implementations.
【CD】

## Existing interactions

| Layer | Existing responsibility | Relationship to Control Desk |
|---|---|---|
| Mission Control | current missions, signals, states and next Human decisions | direct Control Desk responsibility |
| Research | questions, hypotheses, methods, evidence, negative results | receives authorized questions; returns result/STOP and unresolved decisions |
| Applications | domain-bounded experiments and maintained application artifacts | owns local execution and validation; Desk may route or record status |
| Library | Works, Editions, publication identity and editorial provenance | receives separately approved publication objects; no scientific promotion |
| Website / Experience | presentation and public routing | receives exact approved material through publication authority |
| OLS / ORION | semantics and certified deterministic orientation within scope | referenced, never redefined by Mission Control |

## Current evidence

- Mission Control distinguishes active missions from incoming signals and
  unresolved permanent homes.
- Registries point to authority and explicitly do not replace it.
- The Research/Validation pipeline requires a falsifiable question, protocol,
  data, baseline, units and STOP rule.
- The adopted Ecosystem Lifecycle separates question, research, evidence,
  review, adoption, implementation and publication.
- Rödelheim is a legacy embedded project home and must not expand through the
  Desk.
- SR-1 external replay is frozen; its preserved status does not reactivate it.

## Existing closeout grammar

The Desk expects mission closeout to record lifecycle phase, local state,
transition authority, reconciliation status, affected repositories, owner
decisions and next permitted action. This already supplies the operational
half of Research Institute navigation.

## Missing interface

Mission Control can state that a mission or replay is active, parked or frozen,
but it does not provide a durable scientific map of:

```text
question
→ Lab
→ scientific object
→ result
→ report
→ evidence disposition
```

That map belongs with Research, not Control Desk. Control Desk should point to
it after owner adoption; it should not duplicate it.

## Existing end-to-end flow

```text
Human question
→ Control Desk route when coordination is needed
→ Research or application-owned investigation
→ evidence and review
→ Human adoption/no-change/STOP decision
→ optional implementation
→ optional Library/publication route
→ optional Website presentation
→ maintenance or retirement
```

This flow already exists. The missing element is scientific navigation between
the owning artifacts.

# A5XR End-to-End Raw-Derivation Audit

## Independent chain

Accepted authority requires:

raw memberships/draws/ranks/outcomes/losses → support, provenance, null worlds, N5, bootstrap, attribution and sensitivities → validity → P1–P5 → Rössler label → Lorenz-v2 ceiling.

A5XR instead executes:

supplied support fractions and counts + supplied null summary columns + supplied N5 comparisons + supplied observed metrics/directions/sensitivity results → selected checks → P1–P5 → label.

## Outcome reachability

The review-owned classifier independently reaches exactly:

- `INVALID EXPERIMENT` when validity is false;
- `REPLICATED` when all P propositions and both cores pass without resolved negativity;
- `PARTIALLY REPLICATED` for a positive core without full P conjunction;
- `NOT REPLICATED` otherwise.

It is mutually exclusive and exhaustive. `IMPLEMENTATION_FAILURE` is a preauthorization state outside that four-label Rössler set.

A5XR can return replicated, partial and not replicated from selected summary changes. Raw invalidity and N5-SYNTH implementation failure raise exceptions rather than producing typed states. A valid dominance failure also raises. Therefore the canonical raw-artifact→validity→classification chain is incomplete.

Cross-system precedence independently yields invalid→`INCONCLUSIVE`, qualifying valid positive result→`PARTIAL CROSS-SYSTEM REPLICATION`, other valid→`NON-REPLICATION`. A5XR has no invalid branch in its cross-system expression.

**End-to-end raw derivation: FAIL.**

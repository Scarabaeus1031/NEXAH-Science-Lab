# Minimal Validator Authorization Boundary

## Authorization decision

`MINIMAL_VALIDATOR_SPECIFICATION_AUTHORIZED = NO`

The final gate requires append-preserving negative claim identity. Case D does not preserve or relate the actual V2 claim IDs, so the full conjunction for PASS is false. The hard-stop rule forbids another schema revision.

For clarity, the validator boundary that would have been scientifically legitimate after a PASS was limited to:

- schema conformance;
- required and unique identifiers;
- reference resolution;
- scope shape, edge/component membership, and subpath order;
- controlled epistemic values;
- record and claim lineage consistency;
- history-completeness consistency;
- evidence-reference integrity;
- declared incompleteness.

It could never decide scientific truth, causality, mathematical correctness, evidentiary sufficiency, scientific meaning of preservation/loss, novelty, NEXAH superiority, or ORION applicability.

This boundary is recorded to close the review question, not to authorize specification or implementation.

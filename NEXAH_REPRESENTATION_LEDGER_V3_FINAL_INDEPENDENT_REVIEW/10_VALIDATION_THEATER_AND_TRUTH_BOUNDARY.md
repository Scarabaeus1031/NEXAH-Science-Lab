# Validation Theater and Scientific-Truth Boundary

## False-but-valid construction

A V3 record can be made scientifically false while remaining structurally valid. For example, an author can copy a conforming record, label a scientifically unsupported distinction as preserved over `WHOLE_EDGE`, cite an existing code artifact, select `SUPPORTED`, and provide confident judgment prose. All fields and references can be well formed while the inference is false.

That outcome is expected and necessary to state plainly. V3 validates declarations; it does not inspect the world, prove mathematical correspondence, or determine whether cited evidence warrants a claim.

The V3 documentation explicitly states this boundary, and the schema separates execution, reproducibility, provenance, and claim support. It therefore does not structurally encourage interpretation as a truth oracle.

A bounded validator could check only syntax, controlled vocabulary, identifiers, references, scope shapes, and consistency rules. It could not make scientific decisions. The present review nevertheless withholds validator-specification authorization because the cross-revision identity contract is not satisfied by the Case D regression sample.

`SCHEMA VALID` does not imply `SCIENTIFICALLY TRUE`.

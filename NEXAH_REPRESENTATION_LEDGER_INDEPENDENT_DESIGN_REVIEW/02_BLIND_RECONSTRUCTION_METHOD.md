# Blind Reconstruction Method

For each case the review used this sequence:

1. Inspect the referenced callable, its actual arguments, outputs, defaults, side inputs, and frozen evidence.
2. Define the narrowest source and target that exist before applying NEXAH terminology.
3. Decide whether the edge is one operator or a composite pipeline.
4. Record only preservation/loss objects with an explicit criterion or mark them unknown.
5. Trace claim→artifact→callable→configuration→input.
6. Assign separate judgments for execution, provenance, and interpretation before attempting the schema's single status.
7. Read the previous prose record only after reconstruction and classify agreement.

Agreement vocabulary is `EXACT`, `SUBSTANTIVE_AGREEMENT`, `INTERPRETIVE_DIFFERENCE`, `EVIDENCE_CONFLICT`, and `NOT_DETERMINABLE`. Because no serialized sample instances exist, “exact” would mean substantive fields and boundaries coincide, not byte identity.

# Scope and Independence Rules

This design review treats `MINIMUM_REPRESENTATION_LEDGER_IS_VIABLE` as a claim to test. It does not modify the schema, canonical NEXAH, T02, ORION, or any source artifact. No validator, experiment, benchmark, database, UI, or runtime is created.

## Evidence rule

Reconstruction starts from source code, frozen outputs, hashes, and completed negative-result records. Existing sample prose is hidden until an independent edge description is written. NEXAH labels, historical visual names, and intended narrative are excluded from operator identity and scientific status.

## Important limitation

The preceding audit supplied one schema file but no schema-conforming serialized sample instances. Its “populated entries” are prose summaries in three Markdown files. Field-by-field comparison is therefore possible only conceptually, not by validating two instance documents. This is itself reviewed as a design defect rather than silently repaired.

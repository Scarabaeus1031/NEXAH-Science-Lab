# Lab Boundaries

## Inside

- one finite-dimensional real state space;
- one deterministic synthetic model with declared noise;
- one fixed observation system;
- one fixed history-dependent weighted estimator;
- one no-mask reference for integrity checking;
- one static mask;
- one constant-width, constant-velocity moving mask;
- an explicit information-matching rule;
- estimation error, estimator movement, reacquisition, information status, and false-confidence diagnostics already named by the handoff;
- paired baseline comparison and negative-result reporting.

## Outside

| Adjacent area | Boundary |
|---|---|
| Moving Mask | Only the declared observation-mask schedule is inside. Visual metaphor and wider mask families are outside. |
| Representation | The explicit `H_i`, `W_i,t`, and `T_i` maps are inputs. General representation theory is outside. |
| Observer | A fixed channel/observation configuration is inside. Observer invariance or observer change is outside. |
| Q° | May label the weighted estimate locally. Universal, ontological, control, or OLS status is outside. |
| Pattern of Orientation | Provenance only. The visual sequence and book assignment are outside. |
| Mathematics | Ordinary declared linear algebra and metrics are inside. New mathematics, manifolds, topology, or general theorems are outside. |
| OLS | Existing terms may describe provenance and status. No OLS definition, conformance claim, or change is inside. |
| Validation | A preregistered internal benchmark is required. External validation and generalization are outside this first Lab. |
| Applications | All biological, chemical, astronomical, biomechanical, control, and production uses are outside. |

## Source-state boundary

The mask changes the observation record. It does not change or delete the synthetic source state. This boundary is inherited from Rödelheim Labs 0.2 and 0.4.

## Reconstruction boundary

Every masked item must remain classified as directly available, reconstructed under declared assumptions, underdetermined, or unknown. Visual continuity cannot fill an unknown interval.

## Stop boundary

The Lab ends after the frozen primary comparison and result classification. No successor study opens automatically.

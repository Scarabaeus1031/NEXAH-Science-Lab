# Variables

## Classification rule

`Observed` means available in the generated experimental record or controlled protocol. It does not mean empirical measurement. The underlying state is hidden from the estimator but available to the evaluator as synthetic reference truth.

## Observed or controlled

| Variable | Meaning | Required declaration |
|---|---|---|
| `t` | sample time/index | interval, units, horizon |
| `x_t` | synthetic reference state | dimension, initial state, dynamics; evaluator-only during scoring |
| `A_t` | state-transition rule | exact fixed rule |
| `η_t` | process disturbance | law, scale, seed; realized values retained |
| `H_i` | channel observation operator | matrix, dimensions, units |
| `W_{i,t}` | mask operator | static or moving schedule |
| `p_t` | mask position | normalized definition and boundary behavior |
| `b` | mask width | fixed and identical across primary comparison |
| `v` | mask velocity | `0` for static; one fixed nonzero value for moving |
| `y_{i,t}` | visible channel record | generated by declared observation model |
| `ε_{i,t}` | observation noise | law, scale, paired seeds |
| `T_i` | translation to shared space | exact map and failure behavior |
| `w_i` / `λ_i` | fixed channel weights | values, normalization, zero-weight behavior |
| history policy | estimator access to past records | exact window or complete declared history |

## Estimated

| Variable | Meaning |
|---|---|
| `x̂_{i,t}` | local channel estimate |
| `z_{i,t}=T_i[x̂_{i,t}]` | local estimate in the shared comparison space |
| `Q°_t` | weighted relational state estimate; experiment-local label only |
| `Û_t` | declared uncertainty estimate, only if the fixed estimator provides one |

## Derived

| Variable | Meaning |
|---|---|
| `e_t = ||Q°_t-x_t||` | state-estimation error |
| error summaries | mean, median, maximum, distribution, worst-window error |
| `s_t = ||Q°_t-Q°_{t-1}||` | estimator movement; not accuracy |
| reacquisition time | time after mask release until error meets a frozen tolerance and persistence rule |
| visible fraction | available observation proportion |
| `rank(W_{i,t}H_i)` | linear information-availability diagnostic |
| contributor count | channels with valid nonzero contributions |
| weight concentration | concentration of normalized weights |
| false-confidence event | high declared confidence or low apparent movement while error exceeds a frozen threshold |
| baseline delta | paired difference between moving and static conditions |

## Unknown or unavailable to the estimator

| Quantity | Boundary |
|---|---|
| masked state components | unavailable unless reconstructable under the declared estimator/model |
| unidentifiable state directions | remain underdetermined when the masked observation system lacks information |
| external-domain behavior | unknown; the benchmark is synthetic |
| general effect across estimators | unknown; one estimator is tested |
| general effect across mask families | unknown; one static and one constant-velocity schedule are tested |
| optimal weights or estimator | unknown and outside scope |
| causal physical mechanism | absent from the synthetic comparison |

## Removed from the minimum Lab

Mask acceleration, stochastic or adversarial schedules, variable width, adaptive weights, nonlinear dynamics, multiple estimator families, and control actions are defined as later possibilities in the handoff but are not variables in the minimum Lab.

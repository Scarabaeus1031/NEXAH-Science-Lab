# Trace-to-Motion 0.1

Status: `REVISION 2 DRAFT — HUMAN ACQUISITION PROHIBITED`

Artifact class: bounded experimental object

Operational effect: `NONE`

## Purpose

Test which declared geometric and temporal relations survive when a
time-indexed planar pen movement is represented as a final un-timed trace and
when parts of the time-indexed record are hidden by a moving mask.

This experiment operationalizes one small relation among trace geometry,
motion representation and moving masks. It does not test LANIF, golf,
biomechanics, the T-bearing rope equation or a universal transition grammar.

## Research question

> Which declared relations can be reconstructed from a final 2D trace, which
> require the time-indexed source trajectory, and how does a declared moving
> mask change that reconstruction?

## Scientific objects

| Object | Definition boundary |
|---|---|
| source trajectory | a sampled function `p(t)` of pen-tip position in one calibrated 2D plane |
| final trace | the un-timed planar curve or raster `Gamma` produced from the same recorded stroke |
| representation map | the frozen procedure that converts `p(t)` to `Gamma` |
| mask | a declared time-dependent visibility region applied to source samples after capture |
| relation set | only the frozen geometric and temporal relations listed below |
| reconstruction | an explicit estimate with unavailable relations recorded as `UNKNOWN` |

The physical cause, intention, handwriting meaning and writer identity are not
scientific objects in this experiment.

## Minimum dataset design

The candidate acquisition set contains twelve single-stroke samples:

- six declared planar paths;
- each path traversed once in each direction;
- one continuous stroke per sample;
- synchronized time-indexed pen-tip coordinates;
- one final trace generated by a frozen rendering procedure;
- one calibration record for the drawing plane.

Separately drawn F/R samples are repeatability observations, not exact
reversals. Track B derives an exact computational reversal from one source so
geometry and sampling support remain identical.

No participant, device, sampling rate, path geometry, rendering rule or
tolerance is frozen by this design document. They must be fixed in an
authorized acquisition protocol before execution.

## Conditions

1. `SOURCE`: complete time-indexed trajectory available;
2. `TRACE_ONLY`: only the final un-timed trace available;
3. `STATIC_SCHEDULE`: a mask schedule frozen before Human acquisition;
4. `MOVING_SCHEDULE`: a second pre-acquisition schedule on the same source.

Schedules require a preregistered exposure and common-support contract. Equal
area or hidden count alone is insufficient. Masks change observations, not the
source.

## Variables

### Controlled or observed

- sample and paired-reversal identity;
- `t` and `p(t)`;
- drawing-plane calibration;
- representation procedure producing `Gamma`;
- mask geometry and schedule `m(t)`;
- visible-sample fraction;
- frozen registration procedure.

### Derived

- cumulative path length `s(t)`;
- tangent direction `theta(t)` where defined;
- planar curvature estimate `kappa(t)` under one frozen method;
- crossings and declared transition points;
- registered geometric error;
- direction and order reconstruction;
- transition-point localization error;
- segment precision and recall;
- fraction of relations reported `UNKNOWN`.

### Explicitly absent

- stored energy;
- released energy;
- force, torque or pressure;
- body axes;
- semantic meaning;
- causal intent.

## Frozen relation set

| Relation | Expected availability |
|---|---|
| planar incidence and intersection | source and final trace, subject to rendering tolerance |
| un-oriented curve geometry | source and final trace after registration |
| total path length | source; approximate from final trace |
| local curvature magnitude | source and final trace under a frozen estimator |
| traversal direction | source only unless the final trace carries separately declared directional evidence |
| temporal order | source only in the paired-reversal control |
| masked sample status | masked conditions only |
| source identity | retained in every record; never inferred from geometry alone |

## Revision 2 validation tracks

### Track A — Pipeline conformance

Deterministic transformations must satisfy identity, schema, rendering,
provenance, geometry-diagnostic and status contracts. This is technical
conformance, not external representation evidence.

### Track B — Direction identifiability

Direction recovery uses one trajectory, its exact computational reversal,
direction-free packets and an independent evaluator or frozen classifier.

### Track C — Mask-schedule comparison

Only pre-acquisition schedules may be compared. Availability, conditional error
and common-support error remain separate. Causal attribution to motion is
prohibited until separately identified.

## Candidate measurements

- symmetric registered curve distance under one frozen metric;
- relative path-length error;
- curvature-profile error after declared arc-length normalization;
- direction classification accuracy on paired reversals;
- temporal-order score where an order estimate is attempted;
- transition-point localization error;
- segment precision and recall;
- visible fraction and exposure match;
- `UNKNOWN` rate;
- false-reconstruction count: a hidden relation asserted without support.

No metric becomes authoritative until its exact calculation, tolerance and
failure behavior are frozen before acquisition.

Nearest-neighbour distance requires an order-sensitive reversal-invariant
comparison plus connectivity, closure and self-intersection checks. V1's
four-of-six rule and terminal H3 thresholds are removed.

## Protocol skeleton

1. freeze device, coordinate frame, sampling, calibration and Owner-approved population;
2. freeze rendering, registration, geometric markers, metrics and justified tolerances;
3. capture source trajectories and final traces without changing the declared
   paths after inspection;
4. preserve source truth separately from reconstruction inputs;
5. generate `TRACE_ONLY`, `STATIC_MASK` and `MOVING_MASK` records from the same
   source identities;
6. verify schedules predate Human data and report all exposure variables;
7. reconstruct only the frozen relation set;
8. classify every unavailable relation as `UNKNOWN` rather than filling it by
   visual continuity;
9. score against withheld source records;
10. report track-specific values and `UNKNOWN`, `INVALID` or `BLOCKED`; no aggregate class exists.

## Falsification and negative controls

| Claim | Condition counting against it |
|---|---|
| Track A | a deterministic contract, topology, schema, rendering, hash or status check fails |
| Track B | an independent procedure recovers direction under a justified criterion without leakage |
| Track C | data-dependent schedules or absent common support block comparison; schedule difference is not motion causation |

The relevant track is `BLOCKED` if truth leaks, registration changes, schedules
are data-dependent, common support is absent, independence fails or records are
missing.

## Evidence and interpretation boundary

- the recorded trajectory and final trace are observations;
- generated masked records are experimental representations;
- metric outputs are measurements under the frozen protocol;
- interpretations about handwriting, living systems, golf, energy or universal
  orientation remain outside the result;
- a successful reconstruction does not show that the source cause or meaning
  was recovered.

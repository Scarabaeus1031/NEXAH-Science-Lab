# Independent Review Checklist — Revision 2

Status: `DRAFT — REVIEWER UNASSIGNED`

The reviewer must not be the protocol, acquisition, analysis or primary
validator author.

## Track separation

- [ ] Track A is technical conformance only.
- [ ] Track B uses one source and its exact computational reversal.
- [ ] Human F/R drawings are not exact reversals.
- [ ] Track C is a schedule comparison, not a causal motion claim.

## Direction test

- [ ] target, allowed inputs and responses are explicit;
- [ ] truth and packet assignment remain sealed;
- [ ] forbidden metadata and leakage channels are tested;
- [ ] `UNKNOWN`, invalid and contamination behavior are explicit;
- [ ] decision rule has an approved rationale.

## Schedule comparison

- [ ] schedules predate Human data and are source-independent;
- [ ] F/R members share schedules unless an approved reason exists;
- [ ] area, count, gaps, endpoints, markers, curvature proxies and support are reported;
- [ ] availability, conditional error and common-support error remain separate;
- [ ] missing common support blocks comparison.

## Geometry, qualification and decisions

- [ ] marker detection does not search near an expected answer;
- [ ] `u`, `tau` and `s` are not equated;
- [ ] order and topology supplement nearest-neighbour distance;
- [ ] repeated grid, held-out calibration, scale and drift checks exist;
- [ ] device accuracy, precision, timing, contact and smoothing are qualified;
- [ ] thresholds follow an error budget and sensitivity design;
- [ ] no four-of-six rule remains;
- [ ] attempts and acquisition order were frozen in advance;
- [ ] self-conformance is not called independent validation;
- [ ] blockers cannot be bypassed by a generated report.

Decision: `ACCEPTABLE FOR OWNER DECISION`, `REVISION REQUIRED`, or `REJECT`.

# Compatibility

Producers and consumers must declare supported NRRC versions independently. Unknown versions fail closed. ORION and THE EYE compatibility remain future, separately authorized work.

Downstream systems must preserve the full authoritative graph or declare a hash-bound projection. They may narrow a claim ceiling but never raise it. A2 v1.1 remains unchanged; NRRC neither extends nor replaces it.

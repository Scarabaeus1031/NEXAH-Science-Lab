# Extensions

Unknown undeclared fields reject. The core permits only a `declared_extensions` object whose keys match a registered namespace pattern and whose values state exact version and opaque JSON payload. P4A registers no extension namespaces.

Recognition, semantics and compatibility require a later governed registry entry with owner, version, activation and loss policy. Storage never creates semantics.

Deferred and unimplemented: `FlowRecord`, Tear Flow, Trade Flow, currency, biological exchange, FIELD ART, medical, economic and physics interpretation.

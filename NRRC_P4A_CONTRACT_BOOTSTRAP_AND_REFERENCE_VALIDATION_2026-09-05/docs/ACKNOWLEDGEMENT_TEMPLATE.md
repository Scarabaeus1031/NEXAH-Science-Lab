# Cross-repository acknowledgement — unsigned template

Status: `TEMPLATE_ONLY · PENDING · NO ACCEPTANCE`

```text
ACK_ID:
OWNERSHIP_PATH:
REVIEWER_OR_OWNER_ROLE:
REVIEWED_NRRC_VERSION: 0.1-candidate
REVIEWED_SCHEMA_SHA256:
REVIEWED_PACKAGE_MANIFEST_SHA256:
BOUNDARY_CONFIRMED:
COMPATIBILITY_STATEMENT:
EXCLUSIONS:
DECISION: [ACKNOWLEDGE | REJECT | DEFER]
DATE:
RECORDED_CONFIRMATION:
```

Blank or unsigned fields mean `PENDING`. An acknowledgement confirms one boundary and does not transfer NRRC ownership, create joint authority, authorize implementation or constrain Human claim authority.

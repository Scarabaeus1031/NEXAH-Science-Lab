# A5XR Null and N5 Derivation

Each null family is matched to an exact accepted metadata record: family, 0–199 range/count, population, frozen support, canonical actions/RNG, required statistic identities, randomization unit and family rule. Missing/extra family, changed count/population/action/RNG/rule/statistic or nonfinite compressed value fails.

N5 validates the exact A4 matrix registry, order, determinant, tier/stage, both refits, transformed B/target/paths/support, inverse registration, fixed population, Kendall comparisons, minimum aggregation and `.99` threshold. SYNTH and RUN failure mappings remain unchanged.

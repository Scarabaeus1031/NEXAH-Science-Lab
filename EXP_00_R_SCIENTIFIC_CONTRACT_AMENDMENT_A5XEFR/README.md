# A5XEFR — minimal F47 registered-interface closure

A5XEFR is an additive, encoding-only successor to A5XEF. It adds a typed execution/evidence identity envelope supporting fixture evidence and a future registered-evidence interface while leaving the A5XEF scientific evidence object and both scientific derivations unchanged.

The included registered-mode bundle contains generated synthetic rows only. It is labeled `SYNTHETIC_REGISTERED_INTERFACE_CONFORMANCE`, cannot claim a registered scientific result, carries no authorization, and is used solely to prove interface and derivation invariance.

This package does not implement V3, create authorization, access registered data, or execute EXP-00-R.

# A5XE Identity and Population Contract

All artifacts join to one canonical synthetic seed/row universe. The derivations recompute T/F OOS, joint support, both-nonzero counts, carrier labels, bootstrap clusters, null recipients/donors, N5 queries, attribution rows and sensitivity populations from foreign keys.

Exact-set and referential checks prohibit unrelated identifiers from satisfying a count. A contributing-seed count is never accepted separately from its exact seed set and rows-per-seed mapping. Bootstrap seeds, attribution seeds, null rows and N5 queries must exist in the eligible parent population.

Every sensitivity uses the accepted 12-member registry, exact path/values, canonical one-path config patch, exact contributing seed set, exact 50 TEST rows per synthetic seed, exact row IDs and reconstructed carrier outputs. Missing/extra/duplicate records or mismatched counts fail.

Only `SYNTH_00..SYNTH_29` are used. Numeric registered ranges appearing in frozen config identity are not enumerated or accessed as data.

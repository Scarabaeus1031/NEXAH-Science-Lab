# Revision Scope

Schema v2 repairs only the seven blockers identified by the independent design review. It does not add a database, graph runtime, UI, ontology, inference engine, uncertainty propagation, experiment orchestration, T02, or ORION.

The revision is grounded in the v1 schema, the independent review, and the same four difficult cases. Source conflicts and unavailable provenance remain explicit. No historical artifact or canonical NEXAH file is changed.

`schema-valid != scientifically verified`

V2 can constrain record form, internal references, controlled states, and revision rules. It cannot establish scientific truth, causal interpretation, task relevance, or the correctness of a preservation/loss claim.

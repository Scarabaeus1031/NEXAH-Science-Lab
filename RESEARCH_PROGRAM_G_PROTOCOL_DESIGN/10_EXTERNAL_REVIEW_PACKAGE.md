# External Review Package

## Review state

`NOT OPEN`

This document defines a future package. It authorizes no contact or release.

## Review question

Does the frozen protocol and evidence support the reported finite view-specific identifiability classification under the four declared orthographic observation maps?

## Reviewer profiles

1. inverse-problems or applied-linear-algebra reviewer;
2. scientific-reproducibility reviewer;
3. provenance custodian available for source questions but excluded from scientific judgment.

## Required review package

- signed authority and scope statement;
- Protocol 1.0 and all frozen definitions;
- immutable independent replay archive;
- originating run package;
- independent replay run package, if completed;
- validation reports;
- replay comparison report;
- bounded result;
- complete deviation and failure records;
- non-claims;
- provenance appendix separated from scientific materials;
- SHA-256 manifests for every package.

## Review order

1. conflict-of-interest and independence check;
2. protocol completeness review;
3. mathematical-object and criterion review;
4. input and hash review;
5. implementation-conformance review;
6. evidence review;
7. terminal-decision review;
8. replay comparison review;
9. interpretation and non-claim review;
10. bounded review decision.

## Permitted reviewer decisions

- `ACCEPT BOUNDED RESULT`;
- `RETURN DEFINITION DEFECT`;
- `RETURN CONFORMANCE DEFECT`;
- `RETURN EVIDENCE DEFECT`;
- `RESULT INCONCLUSIVE`;
- `REJECT OUT-OF-SCOPE CLAIM`.

These are review decisions, not protocol terminal outcomes.

## Permitted review findings

- whether definitions are complete and ordinary scientific language is sufficient;
- whether matrices, input, discrepancy, tolerance, and partitions are consistent;
- whether implementation conforms to protocol;
- whether evidence supports the terminal class;
- whether replay agrees under the frozen comparison;
- whether interpretation stays within the finite object.

## Prohibited review request

- assess NEXAH as a whole;
- determine novelty or priority;
- validate continuous curves or untested views;
- infer physical identity, coupling, dynamics, or astronomy;
- validate information-loss, reconstruction, OLS, ORION, Q°, Moving Mask, or applications;
- recommend protocol changes while preserving the same result record.

## Review evidence separation

Reviewers receive scientific protocol and evidence first. Repository provenance is an appendix and may be opened only for source-chain verification. Historical narrative must not guide pair classification or terminal outcome.

## Release conditions

- valid authorized execution exists;
- all frozen files and hashes exist;
- evidence package is complete;
- terminal result is mechanically traceable;
- independent replay is complete or explicitly absent;
- absence of replay is visible and not described as reproduction;
- Thomas and the scientific owner approve external release;
- reviewer independence is documented.

## Review STOP conditions

- mutable package;
- missing failure or deviation record;
- expected-result leakage into the pre-execution replay package;
- reviewer conflict not resolved;
- repository terminology required to understand the science;
- scope expansion;
- external opinion presented as endorsement beyond the bounded question.

# Independent Task-owner Requirements

A qualifying owner is an accountable domain party able to specify operational
requirements without reference to ORION/NEXAH or expected estimator performance.
For the primary candidate this could be a spacecraft AOCS/GNC team, star-sensor
qualification laboratory, mission instrument engineer or formally applicable
project requirements authority.

The owner must:

- own or be delegated responsibility for the external task;
- name the reference frame, operating modes and population;
- provide sources for tolerance, latency, reliability/continuity and failure
  handling;
- distinguish attitude knowledge from achieved pointing/control error;
- define natural outage/reacquisition conditions;
- set ordinal or quantitative consequences for use, invalidation and remeasurement;
- state whether a one-axis precursor has decision value;
- evaluate whether the fiducial-camera analogue is sufficiently representative;
- identify the strongest incumbent solution and meaningful increment;
- approve, reject or revise before component selection and data collection.

ASTM, ISO, ECSS and NASA publications are requirement sources, not signatures for
this project. No named team or authorized individual has agreed to own the task.

```text
INDEPENDENT_TASK_OWNER_IDENTIFIED = NO
SIGNED_EXTERNAL_CONTRACT_EXISTS = NO
```

An informal expression of interest does not close the gate. Identity, role, date,
version and explicit approval are required later; this audit cannot fabricate them.

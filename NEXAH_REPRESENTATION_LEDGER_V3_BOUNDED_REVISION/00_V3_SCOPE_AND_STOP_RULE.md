# V3 Scope and Stop Rule

V3 is the one final bounded revision authorized by the V2 blind re-review. It changes only assertion applicability, epistemic-status duplication, and cross-revision claim identity/history. All other V2 structures and scientific boundaries remain intact.

No validator, runtime, database, UI, ontology, experiment, benchmark, T02/ORION integration, or scientific claim is added. V3 can proceed only to one final independent review. Failure there ends schema development and reduces the ledger to structured documentation/provenance.

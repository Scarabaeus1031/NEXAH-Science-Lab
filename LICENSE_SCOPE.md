# NEXAH Science Lab — License Scope

The NEXAH Science Lab Release Candidate 1 uses separate licenses for separate
artifact classes. A file's scientific or evidentiary status is not changed by
its license.

## Executable source code

Executable source code is licensed under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

This includes Python, JavaScript and MJS files, together with executable HTML
instruments and their implementation dependencies. The full Apache License 2.0
text is provided in [`LICENSE`](LICENSE).

SPDX identifier: `Apache-2.0`

## Documentation, reports, figures and original artwork

Repository documentation, scientific reports, figures and original repository
artwork are licensed under the
[Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).

This includes Markdown documentation and original NEXAH images, including the
RC1 poster artwork. Attribution should identify the artifact, the NEXAH Science
Lab and, where recorded, its owning source package.

SPDX identifier: `CC-BY-4.0`

## Machine-readable datasets and numerical results

Machine-readable datasets and derived numerical results are dedicated to the
public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

This includes CSV and JSON result records when they function as datasets or
derived numerical outputs. JSON schemas, configuration files and executable
model definitions remain governed by the license appropriate to their role.

SPDX identifier: `CC0-1.0`

## Third-party material

Material identified as third-party remains subject to its original rights and
license. Inclusion in this repository does not replace or broaden those terms.
Where no compatible publication right is recorded, the material is not covered
by the grants above.

## No authority or evidence effect

These licenses authorize reuse of covered artifacts. They do not grant
constitutional authority, change Program status, promote Field Notes, alter an
Evidence classification or widen any scientific claim.

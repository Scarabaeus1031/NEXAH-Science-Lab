# Archive, Arena, Atlas and Observatory Routing

This is a conceptual routing decision only. No file is moved, renamed, hidden or deleted.

## Routing rule

| Destination | Admission rule | Exclusion |
|---|---|---|
| ACTIVE | Current capability with a named user, input, transformation, output and maintained entry point | Historical traces, duplicates, unsupported dependencies |
| ARENA | Public-facing candidate whose central value is experiential or communicative and whose nonclaims can be made visible | Scientific-evidence claims based on appearance |
| ATLAS | Stable reference, genealogy or curated relation map used to orient across material | Executable capability claims without an entry point |
| OBSERVATORY | Bounded experimental instrument or negative result with protocol, controls and inspectable output | Open-ended symbolic search or unsupported ontology |
| ARCHIVE | Superseded, duplicate, incomplete or historical trace retained for lineage | Active navigation by default |
| SCIENCE LAB | Reproducible research package with declared question, inputs, method, result and claim boundary | Field Art presented as evidence |
| THE EYE | Sealed comparison/result projections conforming to an approved profile | Arbitrary files, invented metrics or complete-record ownership |
| NEXAHEDRON | Human-facing interaction and presentation with public operability | ORION semantics, Library ownership or hidden inference |

## Five Arena/Atlas candidates

1. selected NEXAH public Atlas visual fields;
2. Rödelheim coordinate and rhythm plates with status labels;
3. OEIS LOGIK rope/seam/return genealogy as bounded visual vocabulary;
4. selected HTML Orientation demonstrations after dependency/footer review;
5. selected Builder/GLB visual mechanisms with explicit toy/reconstruction status.

## Five archive families

1. Builder Lab archive engines and generated bulk;
2. historical BTC result without a dedicated source/entry point;
3. screenshots and derived export counterparts;
4. duplicate/superseded HTML variants and missing-source documentary placeholders;
5. speculative Field Art and unresolved cross-domain visual analogies.

Historical retention is not rejection. Archive placement protects provenance while preventing obsolete or underdefined material from competing with current usable entry points.

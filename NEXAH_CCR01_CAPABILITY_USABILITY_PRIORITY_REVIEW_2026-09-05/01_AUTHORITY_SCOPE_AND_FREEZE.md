# Authority, Scope and Freeze

## Authorized review

This package implements NEXAH-CCR-01 as a read-only ecosystem review. It may inspect current repositories, packages, interfaces, sites, tests, manifests, registries, reports, HTML instruments, representative visual artifacts and Desk records. It may group evidence into capability families and recommend conceptual routing.

## Frozen surfaces

The review grants no authority to change:

- NEXAH production code or governance;
- Orientation Language Specification 1.0;
- canonical ILAU;
- ORION Core, Runtime or Gateway;
- THE EYE contracts, comparator or projection;
- NRDL or NRRC;
- NEXAHEDRON source or deployment;
- closed Science Lab tests or conclusions;
- existing manifests, registries or source custody.

## Required separations

```text
TH_ORIENTATION_PRACTICE ≠ NEXAH_FRAMEWORK
NEXAH_FRAMEWORK ≠ NEXAH_SOFTWARE_PRODUCT
CONCEPT ≠ IMPLEMENTATION
DOCUMENTED_METHOD ≠ RUNNING_SOFTWARE
VISUAL_EXPLAINER ≠ SCIENTIFIC_EVIDENCE
TESTED_COMPONENT ≠ INTEGRATED_CAPABILITY
PUBLIC_PAGE ≠ OPERABLE_PUBLIC_FEATURE
OWNER_USE ≠ EXTERNAL_VALIDATION
CARTOGRAPHY ≠ ONTOLOGY
INSIDE ≠ OUTSIDE
```

`TH_ORIENTATION_PRACTICE` names the Human's relational practice of framing, comparing, following residuals and deciding. `NEXAH_FRAMEWORK` names transferable semantics, governance, documented methods and workflows. `NEXAH_SOFTWARE_PRODUCT` requires executable components, discoverable entry points and operation without chat-history reconstruction.

## Evidence rules

- A capability requires a definable user, input, transformation and output.
- A path is a location, not automatically an entry point.
- M4 requires bounded executable and test evidence.
- M5 requires an actual internal integration, not an architecture diagram.
- M6 requires a discoverable public route that a visitor can operate.
- M7 requires external use or evaluation evidence. None was found.
- Historical tests establish only their recorded scope and date.
- Public HTTP checks establish reachability only.
- Hashes identify inspected local bytes; they do not establish authority by themselves.

## Review actions performed

- read-only file discovery and focused text inspection;
- local repository revision/status inspection;
- SHA-256 calculation for cited local evidence;
- aggregate file-type counts for representative corpora;
- non-mutating HTTPS reachability checks for declared public routes;
- documentary compression and scoring.

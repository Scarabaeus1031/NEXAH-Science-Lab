### Why these answers are bounded

NEXAH is not only a thought model because installable packages, deterministic processors, validators, tested comparison components and public interactive interfaces exist. It is a working research environment because its lab packages preserve protocols, negative results, hashes, replays and decision gates.

It is not yet a complete integrated product. The public Human Workspace does not expose the strongest ILAU/residual comparator, the certified ORION Core does not own the historical Runtime/Gateway path, THE EYE is not public, and NRRC remains a local candidate. The system also does not accept arbitrary inputs and automatically choose a capable model or tool. Manual Human routing remains essential.

## Product truth

Today NEXAH is a governed orientation ecosystem with a public editorial experience, a bounded Human Workspace, tested software components and a substantial research laboratory. The public product is narrower than the ecosystem. What already works includes typed record processing, network and benchmark analysis, certified ORION structural stages, sealed comparison demonstrations, contract validation, public curated cases and a memory-only Human orientation session.

The Owner–AI dialogue still supplies much of the cross-repository routing, status interpretation, capability selection and claim discipline. An external visitor can use the public library, atlas, reference cases and Human Workspace. A technical user can separately install or run documented repositories. They cannot yet move from one declared comparison need through the strongest machine comparator to a durable, explained, public result using one discoverable route.

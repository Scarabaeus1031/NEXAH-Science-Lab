# ORION Relation Engine Map

## Present identity

ORION is a certified deterministic **structural orientation core** with separately retained historical/experimental machinery. It is not a general scientific reasoner, Human decision maker, universal relation engine, or currently adopted Rust machine.

## Certified V1 chain

```text
accepted immutable Markdown
→ Structural Representation
→ UNDERSTAND inventory/summary/statistics
→ structural and declared Relations
→ Navigation
→ Structural Orientation Map
→ Expression Contract/Construction/Conformance

```

This chain is implemented, tested, canonically serialized, provenance-preserving, and replayable within its fixed scope.

## Relation and decision boundaries

ORION can represent declared/structural relations and navigate registered routes. It does not infer causal truth, validate scientific support, choose Human action, or gain authority from output certification. No registered historical transition operator currently creates a target representation; planning and execution remain distinct.

# Observer and Representation Map

The later audits converge on two typed pipelines that may meet at a view only with explicit source typing.

```text
source object → graph → embedding(frame, metric) → geometric view
system state → observable → observation event → measurement/value → readout → measured view
```

Composite views require dual provenance. A visible angle belongs to an embedding and metric, not to an abstract graph. A readout is produced by a measurement pipeline and is not the state itself.

RUN01–04 adds the bounded reconstruction chain:

```text
carrier
→ constraint subsets
→ partial observations/projections
→ inverse-image/fiber intersections
→ ambiguous | localized/identifiable | inconsistent
```

This establishes a useful typed architecture for bounded synthetic cases. It does not establish universal reconstruction, physical causality, or application usefulness.

Return is a contextual family, not one universal operator. State return, inverse, reset, restart, repeat, reconstruction, equivalence return, and history return remain distinct. Equal endpoint state does not erase path, event, trace, or provenance.

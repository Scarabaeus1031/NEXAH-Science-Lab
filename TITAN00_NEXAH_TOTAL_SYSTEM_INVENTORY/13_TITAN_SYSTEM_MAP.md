# TITAN System Map

The prompt's linear scaffold is too simple. The evidence supports a governed assembly with parallel authority boundaries:

```text
                         HUMAN AUTHORITY
                      adoption / activation / STOP
                              │
      ┌───────────────────────┼────────────────────────┐
      ▼                       ▼                        ▼
 NEXAH governance       OLS 1.0 semantics       Science Lab evidence
 provenance/status      contracts/composition   tests/negative results
      │                       │                        │
      └──────────────┬────────┴───────────┬────────────┘
                     ▼                    ▼
              RID-01 machine        ORION V1 certified
              contract/schema       structural core
                     │                    │
           validator/adapter gap ─────────┘
                     │
              bounded execution gap
                     │
             replay/integration gap
                     │
          Human view / LYRA / demonstrator
          (separate expression boundaries)
```

OLS does not sit “above” ORION as executable code, and ORION does not sit “above” evidence as scientific authority. RID supplies a candidate interchange spine between already distinct responsibilities. Governance remains orthogonal and controlling.

Primary classification: `G_HETEROGENEOUS_MIXTURE_REQUIRING_COMPONENTWISE_CLASSIFICATION`.

Secondary classifications:

- OLS: formal semantic language specification without mandatory executable semantics.
- ORION certified V1: substantially integrated bounded structural system.
- RID-01: machine contract without implementation.
- broader ORION runtime/LYRA/gateway: implemented components without adopted integration.

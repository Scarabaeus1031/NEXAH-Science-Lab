# Expression and LYRA Map

## Current roles

- Certified ORION Expression constructs a bounded communicative artifact from certified structural material. It does not interpret meaning.
- LYRA source implements bounded deterministic translation/explanation patterns, but later baseline records exclude LYRA execution from certified V1.
- HTML demonstrators, visual atlases, glyph systems, Janus imagery, Q°, FIELD/FORM, animals, mirrors, ropes, spirals, colors, and number annotations are expression, historical, or curatorial material.
- ILAU may be used only as an explicit application codebook; no letter-derived semantics are accepted.

## Quarantine rule

Expression recurrence may motivate navigation or communication but supplies no independent scientific validation, operator definition, type identity, or runtime capability. `EXPRESSION_ONLY` does not mean useless; it means its value is creative, explanatory, mnemonic, or archival rather than evidential or executable.

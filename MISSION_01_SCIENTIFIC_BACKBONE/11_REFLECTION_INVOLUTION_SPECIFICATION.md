# Reflection Involution — Bounded Mathematical Specification Candidate

Status: `SPECIFICATION CANDIDATE — NO OPERATOR PROMOTION`

Date: 2026-08-06

Operational effect: `NONE`

## 1. Purpose and identity boundary

This note freezes a standard reflection involution and separates it from three
existing uses of the JANUS name:

1. the complementary-perspective visual principle;
2. the speculative Janus Bridge;
3. `RESEARCH-JANUS-DCO`, the directional-coherence research measure.

The reflection defined here is not the Janus DCO, not a transition detector,
not the attractor label `C2`, and not a new OLS primitive. The neutral working
name is **Reflection Involution**. Application-specific instances must use a
scoped name, for example the Track-B Reversal Involution `R_B`.

## 2. Exact involutions

On the interval `U = [0,1]`, define

```text
J_ref(u) = 1 - u.
```

Then

```text
J_ref composed with J_ref = id_U
Fix(J_ref) = {1/2}.
```

On `X = [0,1] x Y`, define

```text
J_ref(x,y) = (1-x,y).
```

Then

```text
Fix(J_ref) = {1/2} x Y.
```

A finite-width channel is not the fixed set. If a tolerance region is needed,
it must be declared separately, for example

```text
B_epsilon(Fix(J_ref)) = {(x,y) : |x-1/2| <= epsilon}.
```

`epsilon`, units, coordinate normalization and boundary inclusion are required
parameters. The label `MZ channel` has no additional mathematical content.

## 3. Symmetric and antisymmetric components

Let `V` be a real vector space and let `f : X -> V`. Define

```text
f_plus  = (f + f composed with J_ref) / 2
f_minus = (f - f composed with J_ref) / 2.
```

The exact identities are

```text
f = f_plus + f_minus
f_plus  composed with J_ref =  f_plus
f_minus composed with J_ref = -f_minus.
```

Therefore `f` is reflection-invariant exactly when `f_minus = 0`. This is the
standard `+1/-1` decomposition for the action generated by `J_ref`, whose
group is isomorphic to `C_2 = Z/2Z`. This group identity has no relation to the
NAVIGATION_ENGINE regime label `C2`.

## 4. Typed map-invariance test

The expression `f(M_A) = f(M_B)` is not accepted without types and a common
comparison basis. Declare at minimum

```text
M_A : S -> Y_A
M_B : S -> Y_B
phi_A : Y_A -> V
phi_B : Y_B -> V,
```

where `S` is the declared common source support and `V` is the common feature
space. Exact map invariance means

```text
phi_A composed with M_A = phi_B composed with M_B
```

pointwise on `S`. An approximate test additionally requires a norm, tolerance,
aggregation rule, missing-data rule and common-support contract.

Define

```text
I_AB = features passing the declared map-invariance test
I_J  = features passing the declared reflection-invariance test
I_ABJ = I_AB intersect I_J.
```

The short label `IJ` may be used only after `A`, `B`, the reflection action,
feature space and equality criterion have been bound in the surrounding
record.

## 5. Optional normalized reflection score

For a nonzero feature record `D` on common support, one possible bounded score
is

```text
A_J(D) = ||D - D composed with J_ref||
         / (||D|| + ||D composed with J_ref||)

S_J(D) = 1 - A_J(D).
```

Under a norm, `S_J` lies in `[0,1]`. A valid implementation must declare:

- the feature record and common support;
- the reflection pairing;
- the norm and normalization;
- missing-value and interpolation behavior;
- uncertainty or resampling procedure;
- null and simpler baseline comparisons;
- failure and insufficiency statuses.

Required zero-denominator behavior:

```text
both records zero -> DEGENERATE_ZERO, unless a different rule is preregistered
only one zero      -> S_J = 0
no common support -> INSUFFICIENT_SUPPORT.
```

A score is not evidence of map invariance unless the map-invariance test is
executed separately.

## 6. I-L-A-U comparison record

For a declared pair of representations, the audit record contains:

```text
objects
source support
maps and feature extractors
reflection action
I: retained under the map change
L: lost under the map change
A: introduced by the declared cut or method
U: not reconstructable from the compared records
confidence and tolerance
decision relevance
evidence references
```

Membership in `I`, `L`, `A` or `U` does not follow from geometric position
relative to the fixed set. Each classification requires an explicit comparison
or provenance rule.

## 7. Non-claims

This specification does not establish:

- a physical symmetry;
- a privileged observer or universal midpoint;
- a finite-width fixed set;
- a transition mechanism;
- equivalence between representations;
- identity with Janus DCO;
- identity with NAVIGATION_ENGINE `C2`;
- an OLS, Constitution or ORION change.

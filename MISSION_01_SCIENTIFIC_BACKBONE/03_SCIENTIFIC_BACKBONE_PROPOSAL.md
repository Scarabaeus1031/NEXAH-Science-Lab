# Scientific Backbone Proposal

## Backbone

```text
SOURCE MATERIAL
    │
    ▼
OBSERVE → REPRESENT → COMPARE → ORIENT → EXPLAIN
              │           │
              │           └─ supported / unsupported / boundary statements
              └─ states / relations / transitions / evidence / uncertainty

Optional profile capabilities:
SELECT · TRANSFORM · VALIDATE · RECORD · APPROVE

Optional scientific measurements:
Gate Instability Measure · Janus Directional Coherence Measure
```

This is a responsibility diagram, not a causal law or mandatory software pipeline.

## Minimal scientific object model

The operator layer is small because most recurring nouns are not operators.

| Object | Minimal meaning | Status |
|---|---|---|
| source | identifiable material before admission | FOUNDATION |
| observation | admitted source material with preserved status | FOUNDATION |
| representation | typed construction distinct from reality | FOUNDATION |
| state | declared condition of an identified item | FOUNDATION |
| relation | declared association within context/representation | FOUNDATION |
| transition | declared change between states | FOUNDATION |
| path | ordered composable transition sequence | WORKING concept; common contract missing |
| boundary | scoped limit, failure, censoring, cut, unknown, or validity edge | WORKING records; common taxonomy missing |
| evidence | declared support material with provenance/status | FOUNDATION |
| uncertainty | known unresolved status or limitation | FOUNDATION |
| orientation | situated bounded understanding | FOUNDATION |
| report | inspectable operator output | WORKING in Kernel/applications |

## Mathematical carrier

Use the existing representation-indexed state-transition proposal:

```text
R                         declared representations
X_r                       states expressible in representation r
T_r ⊆ X_r × X_r           scoped transition relation
Π_r                       observed or allowed ordered paths
B                         explicit boundary records
E, U                      evidence/provenance and uncertainty
F_(r→s)                   partial, possibly lossy representation maps
C, q                      context and orientation query
O(N, q) → Report          bounded orientation evaluation
```

Do not introduce a universal manifold, transition space, boundary space, field, metric, probability kernel, or geometry until its required structure is declared and tested.

## Separation of responsibilities

| Question | Owner |
|---|---|
| What was admitted? | OBSERVE |
| How is it structured? | REPRESENT |
| What differs under which basis? | COMPARE |
| What is supported here? | ORIENT |
| How is it communicated without status inflation? | EXPLAIN |
| Which declared alternative was chosen? | SELECT |
| What declared form/state was changed? | TRANSFORM |
| Did a subject meet declared criteria? | VALIDATE |
| What was preserved in history? | RECORD |
| What governed status changed under whose authority? | APPROVE |
| Where is local structural support weak? | Gate Instability Measure |
| Where do adjacent directional estimates align or mismatch? | Janus DCO |

## Claims retained

- NEXAH can preserve typed observations, representations, states, relations, transitions, paths, evidence, provenance, uncertainty, and boundaries.
- The Kernel can produce evidence-bound orientation reports in maintained application scopes.
- Discrete transition structure and representation-specific geometry are implemented in bounded demonstrations and validation campaigns.
- The Gate score detects local-instability structure within its reconstruction assumptions.
- Directional coherence is a testable local trajectory measure.

## Claims rejected or frozen

- one universal operator alphabet beyond OLS 1.0;
- one grammar for visual Moves;
- universal biological, chemical, cognitive, or social mechanisms;
- a universal transition geometry or Markov process;
- Gate score as a transition detector;
- JANUS as one identity spanning visual principle, bridge, transition reconstruction, and local-flow measure;
- Atlas Q–S–P–J–H–N as the canonical semantic backbone;
- recurrence, visual similarity, publication, or provenance as proof.

## Freeze proposal

Freeze the following for one research cycle:

1. Ten OLS primitive names and IDs.
2. The five-stage universal order and its non-implications.
3. Library Registry IDs, while reclassifying them as controlled visual concepts in documentation.
4. The corrected Gate interpretation.
5. The three JANUS identities.
6. The representation-indexed mathematical carrier as `candidate v0.1`, without adding new “spaces.”

No new operator may enter during the freeze. A candidate must instead show that no retained operator can express its input, output, behavior, and failure conditions without loss.

## Admission test after the freeze

A new canonical operator would require all of the following:

1. Distinct input and output contract.
2. Observable behavior not reducible to an existing operator or composition.
3. Declared owner and authority boundary.
4. Failure and insufficiency behavior.
5. At least two independent implementations or reconstructions.
6. Tests against a simpler existing-operator explanation.
7. Counterexamples and a falsification condition.
8. No naming collision with a concept, declaration, motif, algorithm, or outcome.

Current biological and chemical candidates fail tests 2, 5, and 6. Janus DCO fails 5 and 6. Gate Instability passes 1–4, is partly supported on 5, and remains application-scoped.

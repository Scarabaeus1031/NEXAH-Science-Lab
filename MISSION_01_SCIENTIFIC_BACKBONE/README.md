## Result

The smallest operator backbone already exists.

It is the ten primitive operator contracts published in OLS 1.0:

```text
OBSERVE → REPRESENT → COMPARE → ORIENT → EXPLAIN

SELECT · TRANSFORM · VALIDATE · RECORD · APPROVE
```

The first row is the complete canonical universal process. The second row contains profile-owned primitives and is not automatically part of that process.

Two additional numerical research operators should remain outside the semantic backbone:

- Gate Instability Measure — implemented, partially supported, `WORKING`;
- Janus Directional Coherence Measure — exploratory, `SPECULATIVE`.

No new biological or chemical primitive operator is justified by the reviewed evidence. The recurring domain processes are realizations or test cases for existing operators, not additions to the vocabulary.

## Maturity rule

- `FOUNDATION` — canonical contract or indispensable established layer.
- `WORKING` — implemented and testable within a declared scope; not universal.
- `SPECULATIVE` — coherent hypothesis or prototype without adequate validation.
- `DUPLICATE` — function is already covered by a retained operator or is not an operator.
- `OBSOLETE` — superseded label or architecture; preserve as history.
